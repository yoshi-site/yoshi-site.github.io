　 第二章　　　　　舞と流鏑馬　

　引っ越し　

　朝早く起きた明とあすかは、身軽な半袖のＴシャツとジーンズに身を固めた。明は事前に新居に置いていた引っ越し用の衣服を使用できるものの、あすかは作業着まで持参できないため、着替えが到着する夕刻まで明の物を借用する。したがって、男物の服装となった。前にファスナーが付いていたり、寸法が大きかったりして違和感を覚えるが、ここはそんなことを言っていられない。

　二人はあたかもダンスでもするかのように、軽快なステップを踏んで地下の駐車場に向かった。一昨日まで住んでいた横浜のアパートの駐車場はわずか数台が止められる広さであり、外部の駐車場は離れていた。しかも、そこは使用料が高く、自家用車を所有するのはとても無理だった。新しい住居には各世帯に用意されている駐車スペースがあるため、引っ越しする前に明は中古の自動車を購入しておいた。通勤は電車で事足りるとして、あすかの買い物や休日のドライブに都合が良い、と考えてのことである。

　引っ越しにも役立つ、であろうその車を明が運転し、二人はマンションを出発した。ブルブルという振動音は中古車のせいか大きめで、発進してからの加速も鈍い。そんな些細なことは、この場ではどうでもよい。「自動車は人や荷物を乗せて走れば立派」が明の苦しい主張だ。

　きのう電車で通った横須賀線脇の県道二十一号線を、逆方向に走ることになる。そこは道幅が狭く、スピードを抑える。窓を開けると風が入り込み、あすかの髪がさわさわとなびいた。その髪をあすかが気持ち良さそうに撫でる。暑くも寒くもない爽快な気候である 梅雨 ( つゆ ) の中休みに、二人は時々目を合わせて風の香りを楽しんだ。

　やがて明のアパートに到着し、二人は引っ越しの準備に取りかかった。既にまとめてある小さな荷物は玄関の外に集め、未着手の書物を紐で縛ったり箱詰めにしたりする。歴史を研究するための参考書が多く、古文書や原文で書かれた文学作品、それに、戦記物もある。一枚では吹けば飛ぶ軽さの紙という物は、数百ページまとまると重さを感じ、数冊束ねれば腰が痛くなるほどの重量となる。

「しっかり体勢を整え、ゆっくり持ち上げるとぎっくり腰にならないよ」

　と言って明があすかに注意する。

　そのうち同じ大学で講師を勤めているという明の友人が二人来て、手伝ってくれた。どちらも半袖シャツにジーパンを穿き、活動的な格好だ。若いだけあって力があり、高さが三十センチにもなった本の二束を、左右の手で軽々と持って玄関まで運ぶ。人数は揃ったといえ、あまりにも本が多い。友人の二人は「何でこんなに多いんだ！」とぼやいて運び、やけくそになった者は降ろす際にドタッという音がするほど高い位置で手を離した。

　予定した十時になると運送業者のトラックが到着し、重い物を運搬することに慣れている業者が、大物の家具類、洗濯機、冷蔵庫などを手際良く積み込んだ。さすが力持ち、大きい物が短時間で姿を消した。

　さあ次は本の積み込みだ。これはリレー式に行った。玄関前の本の束を明が持ち上げ、友人に渡す。受け取った友人は、トラックの荷台に乗っている業者に渡す。業者は荷台の隙間を探し、そこへ押し込む。この繰り返しだ。独身の明の家具や電気製品は限られ、圧倒的に本のボリュームの方が 勝 ( まさ ) っていた。これが大学の講師というものか。

　この間に、あすかは部屋を掃除した。あまり汚い状態で去ると敷金の戻しが減るので、ここは少しでも稼ぎたい。まず床に掃除機をかけて汚れた所を布で拭き、壁や棚の汚れも落とす。更に雨戸や窓ガラスにも手を付け「立つ鳥後を濁さず」の格言どおり、あすかは綺麗に仕上げた。

　あすかと明の友人たちは明が運転する車に乗って出発し、運送業者の車が後を追う。明の新居がどの位置にあるか運送業者はあやふやのため、明が自分の車で先導する形だ。それは良いとして、信号のタイミングが悪いと離れ離れになる。幸か不幸か、四人も乗った明の車はスピードが遅く、二台の車はずっと接近して走行できた。

　車が鎌倉のマンションに着き、みんなで荷物を三階の部屋に運び込む。小さい二階建てのため、エレベーターが設置されていなかったこれまでのアパートに対し、新居は四階建てでもエレベーターが備え付けられている。先のことになるが、十キログラムムの米袋を運ぶにはこれは重宝だ。エレベーターと慣れたせいもあり、搬入作業はあっという間に終わった。

　大きい荷物は部屋の決められた場所に置き、置き場所が思案中の物は隅に仮配置する。本は箱に入れたままにし、どこの書棚に入れるかは明の頭の中にあるので、これは本人の後日の仕事とした。すっきりした物、仮に置いた物によって空白の部屋が埋まり、新居は住人のいる部屋らしくなった。「枯れ木も山の賑わい」という諺がある。それは失礼な言い方、どの家具も本も明は大事に使ってきた物なので愛着がある。

　荷物を運び終わった運送業者は請求書を明に渡し、礼を言って帰った。そこには金額と振込み先が書いてある。二トン車一回の輸送で済んだことにより、思ったより安価に上がった。振込先の銀行は近くに支店があり、これも楽なことだ。

　残った四人で、仮配置した引き出しや衣服ケースを正式な位置に移動する。明が事前に部屋の寸法と物の寸法を測ってメモしていたことが効き、運び入れた物が短時間で綺麗に収まった。指示された部屋にきちんと入れた後に「寸法を間違えた」と言われて移し替えるのでは、がっかりだ。全て予定の場所に配置され、全員ほっと息をつく。

　引っ越しの際に使い古したタオルで雑巾を作ったあすかが腰を下ろし、膝を付いて床を磨くとゴシゴシという音がした。この新しい家が自分たちの住居と思うと、表情は希望に満ちて明るく、単純作業が楽しくなる。磨けば磨くほど光る家に、あすかは愛情を込めて手を動かした。

　どうやら本日の作業がやっと終了し、時計を見るともう午後の一時だ。そこで、明が友人を誘う。

「おかげで片付いた。さあ、昼食を摂りに一緒に行こう！」

　助っ人の奮戦に大いに助けられた、と思っているあすかは、昨晩の自分を思い出した。

「お疲れ様でした。重い物を何回も運んだので、お腹 空 ( す ) いたでしょう？」

　助っ人の二人が、打ち合わせていたことをもっともらしく言った。

「ごめん、用があるんだ。食事はまたの機会に頼むよ」

「それに、明は彼女と一緒にいたいから、きょうは帰る」

　これだけの荷物を出し入れしたとなれば、重労働もいいところだ。空腹の友人たちが無理をしている、と明は思った。

「遠慮しなくていいんだぜ」

　「引っ越しを手伝ってくれたら、フィアンセを披露するよ」と明に飴をちらつかされて友人たちは来た。親友の嫁さんとなると興味が湧くもので、快く迎えてくれるかどうかによって遊びに行きやすいかどうかが決まる。半日あすかと付き合った彼らは、満足げに言った。

「明の嫁さんになる人、結婚式の前に拝ませてもらって良かったよ」

「さすが明が決めただけのことはあるな」

　褒められて嬉しいあすかは、恥ずかしそうに俯いた。もしここで友人たちに失望されると明の立場が弱くなり、明との友情にひびが入るだろうし、友人はこの家に遊びに来にくいだろう。これで先々の交際もうまくいく、と思い、あすかも安心した。

　別れの際、友人の一人が、持って来た綺麗な箱を明の前に出して言った。

「これ、とりあえず新築祝いのワイン。整理が落ち着いたら二人で飲んで」

　引っ越しを手伝い、お祝いの品までくれる友人たちに、明は頭を下げて恐縮する。

「悪いな。じゃあ後で御馳走する」

　二人は嬉しそうに言った。

「うん、そのときはよろしく」

「期待してるぜ！」

　楽しみを取っておくことにした友人たち、若い割には気を利かせた友人たちは、ワインを置いて自宅へ帰った。

　手料理　

　マンションが完成時に通じてある電気、ガス、水道は、一週間前にここに来て手続きをしており使用可能な状態だ。部屋の照明が点灯するのは確認したし、汚れた手を洗えたので水道も使える。ノブを捻るとガスが点火したので、これもオーケーだ。回線が来ている固定電話は、あす接続の処置をしてもらう予定となっており、それまでは携帯電話で事足りる。

　新居で一息入れた明は、パロットグリーンのシャツとサックスブルーのズボンに着替えた。一方のあすかはどうする？しばらくすると、着替えの入った箱が宅配便で届いたので、あすかは早速ダンボール箱を開封し、コーラルピンクのシャツと、パーシモンオレンジ色のスカートに着替えた。これでようやくあすかは本来の女に戻れ、本日の工程が全て終了したことになる。

　慌ただしい行動が止まり、二人だけになると新居にいる実感が湧いてくる。目をきょろきょろさせたあすかが、まだおぼろげな部屋の構造や壁の色をじっくりと確かめた。こうして見るとなかなかセンスの良いマンションなので、あすかは満足だ。あすかがここを大いに気に入ってくれたことで、明は決断が正しかったことを自画自賛する。

　空間がいくらかの物で埋められた部屋の中で、待望の新居を実感するあすかが両腕を組んで言った。

「さすがにきのうと違う」

　いっとき明は、物語の主人公に変身だ。

「帰国したロビンソン･クルーソーになった気分」

　あすかが胸を張り、その物語に相乗りする。

「わたし、三月の区切りのいいところで中学校の教師をやめ、今、花嫁修業中なの。だから、わたしの料理、無人島から帰国した空腹の人に試していい？」

　料理を作ってくれることは嬉しいとして、どうやら明は実験台に乗るらしい。食材の鮮度の見極めが未熟なコックに腐った物を食べさせられると、食中毒を起こす恐れがある。梅雨期の湿度は高く、今は尚更危険、そう考える明は迷惑な顔をした。

「ほう、毒見ってこと？」

　昔、城主が食事をする前には毒味役が先に同じ物を口に入れ、異常がなければそこで初めて城主が箸を付ける習慣になっていた。ご主人様が食事を摂るころには、作った料理は冷めるであろう。いい目にあうのは毒味役の方だ。もっとも本当に毒が入っていた場合、毒味役は悲惨な目に遭うが。

　この役を明が「引き受ける」と言う。ということは、自分の調理が下手で、人間に有害な物を宛がう、と明は思っているのか？婚約者には信頼をおいてよいはずなのにこの態度とは、せっかくサービスをしてやろうとしたあすかは口を尖らせる。

「失礼ね！毒かどうかは後で言って」

　「どうにでもなれ！」と心の中で呟き、明は諦めた。

「はいはい、あす生きていることを願い、目を瞑って食べまーす。もっとも毒だったら、感想を述べる口もおじゃんになるけど」

　続く冷やかしに 業 ( ごう ) を煮やしたあすかが、とどめを刺す。

「まあ冷たい！じゃあ、ほんとに毒、盛っちゃおうかな」

　せっかく理想の相手と出会い、結婚式の日取りが決まったのにここで死んでは浮かばれない。苦労して終えた新居への引っ越し作業も、水の泡となる。手を合わせ、明はしきりに 擦 ( こす ) った。

「勘弁、勘弁、死ぬには早すぎる。僕ちゃんには、すてきなフィアンセがいるんだ」

　無邪気な恋人が褒めてくれて嬉しいあすかは、人ごとのように茶化す。

「じゃあ、許してあげる。そのすてきなフィアンセのためにね。･･････さあーてっと、ちょっと買い物してくる」

　毒殺という恐怖が解消された明は、手を向けて親切に教えてやる。

「スーパーはここを出て左にある。一緒に行こう！」

　初めての土地や不慣れな土地は、案内してもらった方が良い、と思うが、あすかは片手を立てた。

「大丈夫、一人で行ける。何作るか、秘密だもの」

　何やらあすかに 魂胆 ( こんたん ) がある、と思い、明は再びおどおどした。

「ほんとに毒が入りそうだ。やばいな！」

　あすかは笑い、言った明も笑った。「悪いことをするぞ!」と前置きをして悪事を働く者はいないだろう。まじめな人間を偽って普段は生活し、毒を盛るときはこっそりやるものだ。毒は話だけに留まり、これで冗談合戦にけりが付いた。

　あすかは持っているお金で買い物をするつもりだったが「自分の生活のためだから」と言って明がお金を渡した。それを受け取り、あすかは一人でマンションを出た。きのうは暗くなって新居に着き、周囲がどんな環境か、どんな店が近くにあるか調べられなかった。きょうはまだ空が明るく、周囲の情報を得るには絶好のチャンスと考えてのあすかの行動である。

　近くのスーパーマーケットで食材を買い求めて来たあすかが、東側に窓があり、大きな換気扇が付いている新しい台所に入った。流し台はぴかぴかのステンレス、その左の作業台は腐食せず見た目もきれいな白い大理石、キャビネットは木目のシステムキッチンだ。そこであすかが調理を始めた。

　あすかはまな板に野菜を載せ、包丁を少し斜めから入れる。さっと下ろして切った一片を離すべく、右に寄せる。台所に響くトントンという軽妙な包丁さばきの音は、かわいいキツツキのようでもあり、アンネンポルカを演奏する弦楽器のピチカートのようでもある。愛する人に料理を作っているためか、それとも、鍛えた腕前を発揮できる、と考えたのか、あすかのきびきびした動作が続く。

　次はステーキだ。フライパンに注いだ食用油がピチピチと小さいジャンプをし、雨音に似た音はそれよりずっと陽気で元気が良い。隣のガスコンロでブツブツと煮立っている鍋の蓋は、嬉しさを表すかのように頬を緩ませている。台所でこれだけの合唱が聞けるとは、楽しいものだ。

　やがてでき上がった料理を、明も手伝ってテーブルに並べた。料理は豚肉の味噌焼き、ナスの油炒め、キューリにアワビとショーガを入れたサラダ、茹でたそら豆、それとホウレンソウの味噌汁だった。肉には大根卸しも添えられている。あすかの得意な、しかも、覚えたての料理である。

　明は友人たちが引っ越し祝いに置いていってくれたワインを小さい冷蔵庫から抜き取り、栓を開けた。「整理が落ち着いたら二人で飲んで」と言われたが、少し残っている整理は四捨五入の助けを借りて達成とする。あすかが帰る来週では手遅れになるため、飲むのは今のうちだ。飲兵衛ではないとしても、明はこう理由付けしてワインの開封を決意した。

　さてワイングラスはあるか？食器棚を見ると、前にウィスキーを購入した際に酒屋に頂いた販売促進用の物が、仲良く並んで二つあった。早速チューリップ型のグラスに瓶の先を近づけ、ワインを注ぐ。ワインが小さい滝となってグラスの滝壺に注がれ、グラスは熟成した渋い赤紫色の液体で充満させられた。長期間 蟄居 ( ちっきょ ) 生活を強いられた葡萄から発散する香りが漂い、葡萄にとって苦難となった年月は味わう人にとって美味に繋がる。

　グラスを持ち上げ、明が元気よく 音頭 ( おんど ) を取る。

「我が家の最初の夕食、最初のお客様に乾杯！」

　普通に考えれば、明が言ったことは正しい。厳密に考えるあすかが、目を見開いて異を唱えた。

「わたし、お客様？」

　このあすかの疑問に、明は思わず失笑した。ある時刻を境目として、呼称も変化するのだ。

「いけない。結婚するまで他人と言っていたので間違えた。きのうの夜からここの住人だ」

　まだ住民票の登録がされていないのに、フライングを承知のあすかが満足げに言う。

「そうですとも。･･････わたしの夫に乾杯！」

　断面を凹の形に作った舌の溝に二人がワインを流し込むと、それが喉と食道というスロープを滑降して胃袋の滝壺に落ちた。忘年会、新年会など、外でお酒を飲むときはかなりの量が入り、上司が「今夜は無礼講だ」と言っても緊張するもので、意識はそれなりにしっかりしている。それが、自宅となると、精神の防御壁が崩壊するリラックスした状態に陥るため、アルコールの吸収が早まった二人はすぐに頬が赤くなった。

　次に明が料理を口に入れた。さあ、問題の反応はいかに？不安な面持ちであすかが明の顔を 覗 ( のぞ ) き込む。

「どう？」

　頬を緩めて明が絶叫する。

「おいしーい！･･････結婚したら、こんなの毎日食べられるのかな？」

　短時間で多くの人数分作る必要があるのでやむを得ないことだが、大学の学生食堂で食べている料理は今一の物もある。一方レストランの料理は注文した人のために作ってくれるが、ごてごてとした味の料理もある。あすかの料理は淡白でも濃厚でもなく、明の口にちょうど良い味加減であった。

　「毒見」と言い口を尖らせていた態度と打って変わった明を、渋い顔をしたあすかが疑う。

「あら、お世辞がうまい」

　婚約前には気に入られたいあまり、男はおだて一辺倒で迫るものだ。その例に 違 ( たが ) わず、明も「見目麗しきあすか様へ」とか「聡明なあすか様」とかいう文を連ねたラブレターを送った。それに釣られて婚約したわけでないとしても、あすかは映画のヒロイン気分で陶酔した。しかし、結納という区切りが付けば、状況は変化する。

「違うぞ！今更お世辞言ったって、手遅れだ」

　つまり、婚約したとなれば、お世辞は卒業して 本音 ( ほんね ) で言いたい、というのが明の主張だ。

　あすかが優しさを顔に戻して言った。

「あなたが『おいしい』と言うんなら、何でも作ってあげる。わたし、料理が得意よ」

　これぞ我が女房、と思う明は、箸を持ったまま両手を合わせる。

「おーっ！嬉しい」

　明とあすかは笑顔で食べた。夫婦生活のメリットは、手作り料理を二人で仲良く食することである。いくら金持ちといえ、外食だけでは栄養のバランスが崩れるだろうし、家族の絆は強まらない。家族の和は家庭の食卓から、それがこの場でリハーサルとして実践された。

　食事が済み、明も手伝って後片付けをする。食べ終わった皿を流し台へ運び、明がザーザーと流れる水道の水で皿を洗う。水が飛び散る勢いだ。

「水は少しでいいのよ」

　と早速主婦の経済観念を働かせたあすかが注意すると、明は水量を落とした。

　明が皿を洗い、それを横のあすかに手渡すとあすかが布巾で拭くので、リレー競走のバトンを渡すようにタイミングよく仕事が繋がる。何だか引っ越しの延長に取られそうだが、こうして明が手伝ってくれるとあすかは助かるし、愛情も増す。この共同作業は手料理と同様、家族の信頼関係を強固にした。

　後片付けが終わり、ゆっくりお茶を飲んでいる明があすかに礼を言った。

「ご苦労さんでした。引っ越しの手伝いの他に、夕食まで作ってくれてありがとう。疲れただろう？」

「ううん、ちっとも。･･････これ嘘ね。不慣れなので、あー疲れた！」

　と言い、あすかは両腕を伸ばした。荷物を持ったり床を拭いたりしたあすかの手は、疲れもあって頭の少し上までとなった。その手を見て、自分のためにあすかが無理をしていた、と明は思い、悪びれた気持ちになる。

「ふゝ、痩せ我慢はもうおしまいにしな」

　明はあすかの後ろに行き、肩に手を当てた。親指とその他の指の間隔を縮めたり広げたりして、疲労している者の肩を挟む。マッサージの音自体はしないのだが、指が服の上を滑るスースーという音はする。この音を聞いているうちに、凝ったあすかの肩が 解 ( ほぐ ) れていった。

　肩の次は首筋に移り、女の細くて白い後ろ首の上部を指で押して数秒後に離す。その都度血液がスムーズに流れ、あすかの頭がすっきりした。マッサージで気持ちよくなったあすかの目が、とろけてくる。

　十分くらいした後、あすかが向きを変えた。

「ありがとう。交代よ」

　明は引っ越し前にダンボール箱をかき集めてきては、物を詰め込む作業をしていた。そんな筋肉を酷使する作業が一週間続いていたことにより、明の肩は 凝 ( こ ) ってかちんかちんだ。これを毎日行っている運送業者は、よほど慣れている、と予想する明は、彼らを崇めた。

　こういう症状にはマッサージが有効となるで、あすかが明の肩を 揉 ( も ) んだ。あすかのマッサージのやり方は力学的な力より、愛情という馬力を使用して行う。愛する人の柔らかい手によって天国にいる気分になれるマッサージを受けると、明の目がうっとりして細くなる。それほどあすかの処方は、抜群の効果があった。

　揉み終わると、あすかは後ろから両手で明を抱き締め、目を瞑った。明は振り返り、自分の胸にきたあすかの手を愛撫する。何も話さない、何も話す必要もない。そのままの形で愛の巣の昼が過ぎていった。

　マインドコントロール　二　

　同じ日の夕方、教えられた簡単な仕事を終えた直人と亜矢が、霊玉の催眠術によるマインドコントロールを受けていた。体一つでこの家に来ている二人の着ている物は前日と同じであるが、梅雨期は晴れても気温がほどほどなので不潔という感じはない。店の仕事が忙しいのか「二人の着替えを用意してやる」と定子が言ってくれたことは、先延ばしとなっている。

　新人が入ってきた場合、磯部と霊玉が教育係の先生となる。仕事の仕方を教えるのは磯部の役目となっており、商品の置き場所、商品の移動、受注、発注、それと従業員の生活規則を叩き込む。一方の霊玉には、悪事を正義と思わせるよう洗脳する使命が与えられている。これは極めて特殊な役目であり、霊玉が得意の仕事だ。

　座っている直人と亜矢に向かって霊玉が手を回す度に二人の意識が薄れていく。一度霊玉の手にかかった者は二回目には即座に言いなりにされ、自我という反抗心が踏み潰される。それほど霊玉の催眠術は速効性があり、かつ、強力だ。

　落ち着いた低い声で霊玉が直人に問う。

「お前のもっとも崇拝する方は、どなたじゃ？」

　直人が自信を持って答えた。

「はい、岩本勝様です」

　上出来だった。霊玉は亜矢にも質問をする。

「お前のもっとも崇拝する方は、どなたじゃ？」

　穏やかに亜矢が答えた。

「はい、岩本定子様です」

　次に霊玉が怖い顔をして、別の答えを求める。

「お前のもっとも憎む人は、誰じゃ？」

　恨みでもあるかのような強い口調で直人が言い切る。

「はい、 松谷 ( まつたに ) 保 ( たもつ ) です」

「なぜ憎むのか？」

　歴史の映像をさんざん見せ付けられた亜矢の口には、反抗心が籠められている。

「鎌倉の商いを乱しています」

　ここまでは上々、霊玉の声が急に軟らかくなり、核心を突いてきた。

「お前はその悪人を成敗できるな？」

　手を握り締めた直人が断言する。

「はい、旦那様のために」

　仕事を仕込むにはその方法を叩き込むとともに、罰則を教えて恐怖心を抱かせることも有効と考える霊玉は、声を高めた。

「お前たちが旦那様を裏切った場合、どうする？」

　霊玉が両手で呼び込むしぐさをすると、直人と亜矢は座ったまま向きを変えて直視し合った。こういうときはキスしたものだが、そんな甘い感情はこの場では捨て去られる。二人は頭を下げ、同時に唱えた。

「こうしてお詫びします」

　近づいた二人は互いに両手を相手の首に当て、手の形が決まると力を込めて締めていく。それが危険な行為と疑う気持ちなど二人には湧かず、糸に吊るされた操り人形のように霊玉の意のまま手を動かした。

　苦しい二人がもがき出すと、ウーウーと 唸 ( うな ) る声が交互に聞こえる。息が詰まり、顔の血の気が引いたときには、やや上を向いた目に見えるのは、茶色の天上、それも歪曲した天上だ。尚も締め続ける二人は、しばらくすると失神寸前となった。

　この日も定子が、善良な魂を抜かれて無表情になった二人を見ていた。定子の着ている和服は、ラピスラズリ色にペパーミントグリーンの神秘的な模様が施されていて「崇拝する方は岩本定子様です」と答えたことにふさわしい衣装である。ただし、その神秘さは、霊玉の怪しげな神秘とは異なるものだ。

　なぜか亜矢の方に向ける定子の視線が長く続く。清純な美しい顔に魅せられたのか？男の場合それはあるとしても、年配の女には別の訳があり、定子はそのことを磯部と霊玉には黙っていた。

　定子は、霊玉がきっちりと新米を教育しているかをチェックする役目を負っている。霊玉が厳しく仕込めば仕込むほど監視役として結構なことだが、反対の思いもある。鞭を入れ過ぎた結果、馬が倒れては困るのだ。座視していた定子が二人の苦悶を見かねて立ち上がり、霊玉に向かって命令する。

「もう、よしな！」

　せっかく肝心なことを教え込もうとした霊玉は、水を 注 ( さ ) されて不服な顔をする。

「どうしたんですか、おかみさん。ずいぶん甘いですよ」

　定子の諭しは冷静、かつ、客観的だ。

「やり過ぎは逆効果になる。ほどほどってもんがあるんだ、全てにね」

　二人にいつまでもこの行為をやらせると、本当に倒れてしまう、とおかみさんは判断したが、霊玉はまだまだ序の口と思っている。しかし、定子はここのナンバーツーであり、自分は雇われている身分だ。となれば、霊玉は渋々手を回す速度を緩めた。

「へーい、わかりやした。おっしゃるとおりで」

　手を左右に動かして霊玉が術を解いたことによって、二人とも相手の首に掛けた手を離した。苦しさから解放された二人の止まっていた呼吸が再開されると、青くなっていた顔色に血の気が戻るにしたがって意識も少しずつ回復する。我に返ったときには、あれっ、今まで何をしていたんだろう、という夢から覚めた感覚になった。

　それを見て安心した定子は、用は済んだとして退室した。厳しく仕込むのは規則としても、苦しめることは避けたい。辛い顔を見るのは先ほど言った「ほどほど」でよい、と定子は思っている。過度の虐待をしては、明智光秀に討たれた織田信長になる。

　自分の部屋に戻る途中、廊下で立ち止まった定子は三年前のことを回想した。

「あの子、亡くなった娘の美奈に似ている。顔の形といい、しなやかな体といいそっくりだ。美奈が生きているか、あの子がもっと早く来てくれたなら、悪事に手を染めなかっただろうに。･･････美奈、ごめんね。お母さんとお父さんは心から神や仏が消え、すっかり悪魔に変貌してしまった」

　国内不況、もしくは世界恐慌によって店の状況が悪化したかというと、そのときも店は安泰で、もっと身近な出来事が定子を襲っていた。たった一人の子、かわいいがっていた娘の死が、それまでの幸せな人生を転覆させることになったのだ。軌道に乗ってきた問屋の経営、かなりの額になった貯蓄、そんなものより娘の命の方が大事であり、財産を全部投げ捨ててもよかった。

　その娘が未だに忘れられず、どこかに隠れて生きている、と非現実的な希望を定子は持っていた。行方不明になった子の帰還を信じて、毎日仏壇にご飯や果物をお供えしている親と同じである。手塩にかけて育てた娘の美奈に似ている亜矢と会い、定子の望みが偽者といえ現実になった。

　しばらく涙を浮かべて俯いていた定子は、振り返って亜矢を見た。最初は見間違いと思ったが、よく見ると美奈そっくりだ。走り寄ってすぐさま抱き締めたい気持ちが募ったものの感傷はそこまでとし、きりっとした顔に戻して定子は立ち去った。

　買い物　

　次の日の午前中に、明とあすかは荷物を一時的に置いていた部屋の整理をする。独り者の割に明は結構物持ちが良く、不要な物まで持ち込んだため、がらくたの山ができていた。これだけあれば、前の部屋の空間が狭められたのはあすかでもわかる。価値が低い調度品は大型の廃棄品の収集日に出せるよう準備し、今後使うことはない、と判断した小物などは、搬送に使用したダンボール箱に詰めてゴミとして出せるようまとめた。

　どうやら引っ越しの後片付けが完了した二人は、簡単な昼食を取った後に作業用の衣服を小綺麗な服に着替えた。明とあすかはペアルックである。これは昨年の秋、二人が宮古島を旅行した折に購入したエメラルドグリーンのＴシャツだ。そのとき、東 平安名 ( へんな ) 崎や池間島から見た、七色ともいわれる海の色に目を見張った。それまで、珊瑚による綺麗な海の色は、ハワイとか遠い外国だけのものと思っていた。それが、日本で、しかも、虹のように鮮やかな色模様の帯を作っているではないか。その海の色に感動して選んだシャツを、今二人は着ている。

　そんな鮮やかな色の服を着た二人は、新鮮な気持ちという帽子を被り、まずは駅の西側に位置している鎌倉市役所に赴く。そこで前の居住地の市役所で貰った転出証明書を提出し、明の転入手続きを行った。また、ごみの分別収集や市の施設などについて、いろいろ情報を得た。これはあすかも覚えておくべきことだったので、しっかりメモを取った。かなり時間を要する、と覚悟していた手続きが短時間で済み、これによって明はようやく鎌倉市民の仲間入りができた。

　請求書をいつまでも持っているのは気分的にいやなものなので、街の中心部に戻った明は、銀行で運送業者への引っ越し費用の振り込みも済ませた。これで引っ越しのケジメが付いた。通常は引っ越しが終了した時点で現金にて支払うケースが多いのだが、当日の業者は「振り込みでもよい」と言ってくれた。ばたばたしているときにまとまった額の現金を持ち歩くのは危ないため、振り込みで気が楽だった、と思い明は喜んだ。

　その後入った大型電気店では、店の屋上に大きな看板が掲げられており、扱っている商品がたくさん描かれていた。大型電気店といえ、小物のアイロンや電気ポットもある。一つ一つの絵は小さくてインパクトに欠けるとしても、いかにも品物が豊富であることを示している。

　最近の家電製品や、高性能のパーソナルコンピューターを二人は見て回る。新しい訴求ポイントがありどれも欲しいが、ここで安易に手を出すのは軽率だ。引っ越しでかなりの費用をかけている、また、結婚式の費用も支払う必要があるので、それらはおいおいといきたい。

　近いうちに、と考えている大画面のフラットテレビを参考として見ると、メジャーリーグの野球の試合が展示用のテレビに映っていた。日本は朝、アメリカはナイターの時間帯だ。地球の裏側の情報が高精細の映像で、かつ、リアルタイムで見られる技術の進歩には目を見張るものがある。鎌倉時代の武士がこれを見たら、さぞ仰天することだろう。

　ライトを守るイチロー選手の所へフライが上がった。守備のうまいイチローは横に走って球を追い、難なく捕球する。あれだけの飛距離では楽に犠牲フライになる、と三塁コーチが判断し、手を大きく回したことでサードランナーはホームベースへ突進した。イチローはキャッチした瞬間に、投球の体勢に入っている。普通の外野手は内野手を中継してキャッチャーに球を送るものだがイチローは矢のような球をノーバウンドでキャッチャーめがけて投げた。ストライク！キャッチャーはホームベースの手前で余裕を持ってランナーをタッチアウトにした。

　テレビの前にずっと釘付けにされている客が叫んだ。

「すーっげー！レーザービームだ」

　もう一人の客は、もっと前からテレビを見ていた。

「イチローはきょう、ヒットを二本も打ってるぜ」

　友人と思われる一人は、冷ややかだった。

「ばか！ヒット二本でイチローがニュースになるか」

　確かにそうだ。ヒットを量産する者には不適切な称賛だった、と反省する客は、言い直す。

「そうか。三本以上、もしくは無安打で始めてイチローは話題になる」

　探し物の本命は、結婚後にもっとも必要になる物である。〝もっとも必要〟となると食べ物か？それもあるが、それを貯えるものだった。店内の冷蔵庫を物色する明が、何を思ったかいきなり言った。

「冷蔵庫を買い替えよう」

　前のアパートから持ち込んだ小さい冷蔵庫は作動しており、現にその中の牛乳を朝飲んでいる。牛乳は十分冷えていて、性能の衰えなど見られなかった。節約を信条とするあすかが、手を押し出して忠告する。

「無理しなくていい。結婚式の前後は、何かと出費が 嵩 ( かさ ) むものよ」

　そのことは先ほど明も考えた。しかし、美味と食欲が節制を上回り、無邪気な明に大きな冷蔵庫の必要性が突然湧いた。

「あすかのおいしい料理を食べたので、たくさん材料を貯めておき、毎日いい目に合いたくなった。今の冷蔵庫はツードアで、二人用としては小さすぎる。もっと大きいものを買っておこう」

　まるで幼稚園児の発想ではないか？理由がわかったあすかはあきれた。

「まあ、ちゃっかりしてること」

　候補の冷蔵庫の蓋を開け、明が目を近づけて中のサイズを調べる。

「これなんかどう？手ごろな大きさだし」

　冷凍室、冷蔵室、野菜室のスリードアタイプで、二人の生活には十分だ。なぜかあすかはこれに首を捻った。それは将来を見据えてのことだった。

「どうせ買うなら、もっと大きい方がいい。子供は食べるのよ、もりもりと」

　口を尖らせ獲物に噛み付く真似をした明は、あすかの例えを具体的に描写する。

「まるでピラニアだ」

　学校のクラブ活動として陸上競技をやっている高校生の子供を持つ先輩の話を、あすかは聞いたことがある。先輩は母親として大きい弁当箱にたっぷり入った昼食を持たせ、子供を高校へ送り出す。新陳代謝が激しい十代の子は、十時の休み時間に早弁をして弁当箱の半分を消化する。正規の昼休み時間では食べる量が不足となり、その子は業者が昼の時間だけ開く売店で、サンドイッチや菓子パンを買って食べる。放課後、激しいクラブ活動をみっちりして夕方家に着くと、カバンを放り投げて真っ先に向かうのは冷蔵庫だ。おやつはケーキか果物が普通だろうが、その子はそれではぶっ倒れる。夕食まで待てない胃が、きのうの夕御飯の残り、といっても、意識して多く残された食べ物を平らげる。それだけならまだよい。夕食ではご飯を二回御代わりする。これで十分かと思いきや、夜になると、またお腹が 空 ( す ) く。夜食にカップラーメンや肉まんを食べて、やっと眠ることができる。「もうとっくに父親より背が高くなってる。この間、高校駅伝に出場したの。三人も抜いて速かったわよ！わたしは息子の食料供給係かな」と愛息の旺盛な食欲をぼやく先輩が話してくれた。

　話の後編もあった。「三人目を抜いたんだけど、すぐに抜き返された。無理をして抜いたので、体力を消耗したのね。これはいかん、とうちの子は思い、次のランナーに 襷 ( たすき ) を渡す前に力を入れて再度抜き返した。帰宅後『どうしてがんばれたの？』と尋ねると『お母さんが毎日栄養のあるおいしいご飯を作ってくれるので、ここで負けたら悪い』と言ったの。わたし･･････涙が出ちゃった」と食料供給係としての仕事を、先輩は嬉しそうに自慢していた。

　これをヒントに将来生まれる、であろう子供を、あすかが例える。

「違う！ 獰悪 ( どうあく ) なピラニアなんかより、ずっとかわいいエンゼルフィッシュよ」

　あすかの意見を尊重し、明は大きい冷蔵庫を探す。スリードアが不服とならば、フォードアだ。四○○リットリを越える冷蔵庫の前に行き、明が指差した。

「じゃあこれだ。食欲旺盛なエンゼルフィッシュが三匹いてももつ」

　戦後、四、五人の子供を生む女性は結構いたし、毎年出産した子だくさんの母親もいた。今では女性の平均出産数が二人を割り込んでいる。大学まで進学させてやるとなると親の負担が大きくなるので、それを憂いるあまり出産を控えては人類が自然と滅亡に向かう。

　数を聞いて憤然としたあすかが、食ってかかった。

「わたしに子供を三人も産ませるつもり？」

　指で示し、明が冷静に説明する。

「二人がちょうどいい。でも、二回目の出産で双子が産まれると三人だ」

　電気店を出た二人は、小町通りという道を歩いた。こんなに狭い道に、観光客を対象とした二百店を超えるお土産屋や飲食店が軒を並べている。歴史を宿した鎌倉を訪れる多くの観光客で賑わっており、人気の地となれば向こうから来る人と肩が触れるほどの混雑で、ぼっとしているとスリの餌食になるので注意を要する。

　問屋　

　二、三分ほどの短い距離を歩いた二人は、紹介された問屋の前に辿り着いた。そこは広い道を曲がった所にあり、迷うことも近所の人に位置を尋ねる必要もないほどわかり易かった。店長が書いた地図は簡潔で要領を得ているものの、明は念のため地図と目の前の家を照合した。

「古式ゆかしい家ね」

　女店員が包装した品を持って戻って来た。

「お待たせしました」

　包装紙は、規則正しい模様が印刷された簡素なものであった。中味の良し悪しと包装の状態とは別物だ。凡作の絵を金色の額縁で飾ったからといって、称賛を得られるものではないが、秀作の絵に粗末な額縁を宛がっても感動できる。一番欲しい物が手に入っただけで、あすかは満足だ。

「ありがとうございます」

　あすかは礼を言って土産品を受け取り、それを丁寧にショルダーバッグに入れた。帰る際、女店員の深いお辞儀を見たあすかは、たった一枚の売り上げに対して丁寧なお辞儀をするとは、教育が行き届いている、と思った。きょうは気持ちの良いことの連続だ。

　用が済み、問屋を出る前に明は中庭をもう一度見た。枯山水の石庭だけがガラス窓の向こうにあり、女がすぐに奥へ戻ったところをみると、どうやら人違いらしい。

　疑問　

　土産の品を手にして喜んでいるあすかと一緒に道を戻ったものの、明の気がかりな状態は尚も続いている。もし中庭で見た者があの女であったら･･････自殺しかかった女と問屋、それらがどう結び付くのか、足を一歩出す度にこの理由あの理由と明は思慮を巡らせる。だが、どうもわからない。考え 倦 ( あぐ ) ねた明は立ち止まり、あすかに相談を持ちかけた。

「あの 娘 ( こ ) が来るかもしれないから、ちょっと待ってみよう」

　明はあの娘に固執している、と思うあすかの口から再度皮肉が出る。

「いいわよ、美女のためなら」

　いくら何でも美女のためだけに時間を浪費するのは、あすかに対して失礼だ。

「その毒舌、きついな。･･････どうしても気になるんだ」

　今週の明は全てに懐疑的である。由比ガ浜の件といい、問屋の件といい何が怪しいのか、一緒にいるあすかにはちんぷんかんぷんだ。いらいらしてきたあすかの追及が鋭くなる。

「何が気になるの？」

「あの問屋の隅に置かれている梱包箱に、海草が付着していた」

　明はポケットからハンカチを出し、剥ぎ取って中に入れていた海草をあすかに見せる。

「これだよ」

　あすかにはただの黒い紙切れにしか思えない。

「それが？」

　沈思した明がハンカチの上を撫でて問う。

「通常の輸送で海草が付く、と思う？」

　日本特有の土産といえ、海外で生産される物もあることをあすかは知っている。特に発展途上国や為替レートの低い国での賃金は安く、物を生産するのに都合が良い。現に陶器やガラス細工などは、輸入品が多数を占めている。

「輸入では？」

「仮に海上輸送の輸入品だとしてもよ」

　さりげなく言った明の言葉に、あすかは頬を引き締めた。どうやら刑事事件に繋がる話になってきた。これを他人に聞かれてはまずいため、周りの人が離れていることを確認し、あすかは明の耳元に口を近づけて言った。

「ということは、瀬取りによる密輸？」

　明もあすかの耳元で囁く。

「かもね」

　身の 弥立 ( よだ ) つ思いがしたあすかの顔から血の気が引いた。そうとなれば美女は許せる。明は浮気者と違うのだ。では、何か得るものが欲しい、と考え、二人は問屋の前で待つことにした。そこは人通りの少ない小道であり、ぼーっとして立っていても怪しまれることはない。

　明の目は 誤謬 ( ごびゅう ) を犯していなかった。しばらくすると、人目を 憚 ( はばか ) る亜矢が問屋の横の道をこそこそと走って来た。表口では店の人に不審に思われる、と警戒し、裏口を出て道を回り込んで来たのだ。二人の前に着いた亜矢は後ろを振り向き、付けられているかどうか確認するほど慎重である。

　羽織っている黒い印半纏の下は、東慶寺にいたときに着ていた物と同じだ。梅雨期といっても夏だ、家では着替えもするだろう。これは 急遽 ( きゅうきょ ) あの店に寝泊まりしたことを意味している。明は亜矢と問屋の関係を益々怪しんだ。

　催眠術によるマインドコントロールをかけられている亜矢の目は焦点がずれており、二人を目の前にすると瞳がやたらときょろきょろ動いて、相手の特定にまごつく様子だ。困った亜矢が頭を揺することで、やっと明とあすかの顔がはっきり見えた。

　待っていた甲斐があり、ほっとした明が声をかける。

「あゝ、やっぱりこの間の」

　亜矢は両手を膝頭まで下げてお辞儀をした。

「あのときはありがとうございました」

　言葉がしゃきっとしている割に骨が抜けた動物に見える亜矢は、体を横から軽く押しただけでぐにゃぐにゃと萎みそうだ。立っていることすら辛く見え、これでは「松葉杖を使いなさい」と忠告したくなる。亜矢の異常に気付いた明が、心配して言った。

「いいんだよ。それより顔色が悪いな。気分はどう？」

　亜矢の様子を見たあすかも指摘する。

「寝不足のような目よ」

　自分ではしっかりしているつもりでも、他人は異常とわかるらしい。霊玉に催眠術を受けていることを隠密にするため、亜矢は意識して目をぱっちりと開けた。更に言葉も見栄を張る。

「いえ、普段どおりです」

　傷付きやすい年代であることを考慮し、明は優しく疑問を投じる。

「どうして家に帰らなかったの？」

　やはりそこを指摘されたか。東慶寺で「早く家に帰りなさい」と諭され、お辞儀をしたことは「はい」を意味する。それを、裏切った、とこの二人は判断したようだ。この質問に正当な理由を持つ亜矢は、しみじみと説明する。

「問屋の旦那さんが親切で『家に帰るより問屋で働く方が良い』と言ってくれたんです」

　まさか悪者に騙されて連れて行かれた、という危惧は捨ててよさそうだ。ここにいたつじつまが合い、あすかはほっとした。

「それは良かった」

　経歴が不明の者を雇い、その日にいきなり雇い主の家に住まわせることがあろうか？それについては雇う側も、雇われる側も慎重になるはずだ。また、住み込みするにしても、着替えなどを持ち込む準備に数日かかる。明は両者の立場になって理由を考えた。

「むー、何か怪しい」

　自分たちは行く所を悩んでいた。世を 儚 ( はかな ) んだ自分たちを優遇してくれる恩人は、神様に見える。その人が悪人と疑われ、亜矢はいきり立った。

「違います。あの店の人、不幸な人にすーっごく親切なんです。何が怪しいんですか？」

　情報不足の明は亜矢の反論に手を焼き、言う言葉が小さくなる。

「何となく荷物がね」

　何だ、証拠があるのかと思ったら単なる推量で、恩人をけなしているように聞こえる。面倒を見てもらっている人のことを、いちいち詮索する人は嫌いだ。興奮した亜矢は、年上の大人に面と向かって怒鳴った。

「何となくで人を悪く見るのって、いいことですか？」

　亜矢の論理は正しい。推量で裁判が進んでは、公平性が失われる。明は手を頭に乗せ、あすかに言った。

「参った！一本取られた」

　相手がどんな人物かは、どうでもよいことだ。明の関心の的は店が扱っている品物であり、問題視している点はその流通経路だ。明の失策を挽回するべく、あすかが重要な話題に変えた。

「あの店、輸入もしているの？」

　いくらか冷静になった亜矢が、働いて得た情報を伝える。

「えゝ、大きい問屋なので、世界各地の物を」

　指で顎を押し上げ、明が尚も疑問を投げかける。

「それがどうも気になるんだ」

　刑事か探偵気取りのこの人は、疑いを益々増長させている。亜矢はここにいる方の恩人が憎らしくなってきた。自殺するところを助けてもらうなら、別の人が良かった、と思う。純真な娘の気持ちは一徹となっており、潤んだ目付きをした亜矢が訴える。

「お願です。店を疑うの、やめてください。わたしたち今、あの人にお世話になっているから、暮らしていけるんです。･･････失礼します」

　こんな人との話はもう無用と考える亜矢は、二人の前を去ろうとして体を捻った。心配してやった人にこの態度とはあきれる。「それなら勝手にしな」と言いたかった明は、疑問がまだ残っているため素早く亜矢の肩に手を掛けた。

「何かあったら連絡して」

　走りだしたい亜矢は、一応足を止めてくれた。明はズボンのポケットから手帳を取り出すと、端の穴から小さい鉛筆を抜き取り〝大友〟の文字と数字を書いた。そのページを切り取って亜矢に渡そうとした。

「これ僕の携帯電話の番号」

　受け取ろうかどうか迷って下げたままにしている亜矢の手を取り、明は強引に紙切れを乗せた。せっかく書いてくれたメモと思い、亜矢はそれを握って走りだした。ここで捨てては失礼にあたるため、後で破り捨てよう、と亜矢は考える。すたすたと走り、家を出たときと同様、周囲に注意を払って亜矢は問屋の裏門から敷地内へ入った。

　養ってもらっている人に背くことは不徳になるので、こんな物は保管しているだけで罪になる。良心が 咎 ( とが ) めた亜矢は問屋の庭に来ると、早速メモをくしゃくしゃにして地面に放り投げた。これまでのことは忘れ、さっさと部屋に戻ろうとすると、そこでもう一種の良心が働いた。命を助けてくれ、また、自分のことを案じてくれた人に対して、この行為は非礼になる。考え直した亜矢はメモを拾い上げ、たくさんできた紙のしわを丁寧に伸ばして取っておくことにした。

　熱々ムードの明とあすかは、仲良く手を組んで歩いて行く。引っ越しの際、不要になったゴミを捨てる仕事は午前中で済み、午後は物を買う仕事の連続である。誰が考えてもこちらの方が楽しいので、お金が無尽蔵にあるなら朝から晩までショッピングをしていたい。

　買い物をするにも人の個性が表れる。さっぱりした方のあすかの父親は物を見て、これだ、と思う商品を買い、それが一番良い、と思い込む。いわゆる衝動買いに近い。だから、いきなり高額の品に手を出すときもある。

　それに対して、あすかの母はお金を支払った後、別の方が良かった、と悔恨の念が生じる。その場ですぐに交換すれば事なきを得るが、品物を持って店に背を向けてからも迷いが起こる。そのときは慌てて取り替えに行く。家族旅行中、出発する時刻ぎりぎりになってそれをやられると、あすかも父も「いいかげんにして！」と呟くことが何度かあった。

　では、あすかはというと慎重派だ。価格に対する価値や機能を事前に比較し、最良の物を購入する。自分の預金通帳をよく 睨 ( にら ) み、クレジットカードを使用するにしても分割払いにしない。〝分割払い〟は一種の〝借金〟であり、利息を取られることが多い。クレジットカードを利用する場合は、一括払いにする方が安いのだ。あすかは明が言うところの堅実派である。

　大物、そして、土産の買い物の次は小物の買い物となる。芝居には大道具と小道具があり、住宅も同じことがいえる。新しい住居で生活するためには細かな物も必要となるので、明が手帳にメモしていたハンガー、タワシ、洗濯用の洗剤、石鹸などをホームセンターで購入し、あすかが主婦の目で見て不足している物も補充してくれた。例えば、冷蔵庫用の脱臭剤、生ゴミやリサイクル用のゴミを入れるビニール袋、食器用の洗剤、トイレの消臭剤などである。この連携プレーにより、買い物はすんなりいった。

　マインドコントロール　三　

　蒸し暑い時期に、同じ下着を何日も着ていると不衛生になる。ようやく時間が取れた定子が、直人と亜矢のために四組の衣服や靴下を購入して与えた。また、タオル、洗面用具などの日用品も揃えてくれ、これでどうやら二人の生活する環境が整った。

　着替えた物は自分たちが洗濯して裏庭に持って行き、シーツなどの大き目の物は、石の土台に付いた支柱の上部に掛けられた物干し竿に直接載せる。下着などの小物はプラスチック製のハンガーに吊るし、風で吹き飛ばされないようそれらを洗濯バサミで固定する。

　乾いた物は取り込み、アイロンをかける。アイロンや洗濯機などの家電製品は従業員で共用とし、順番を決めて使用する。仕上がった物を入れる引き出しも、直人と亜矢に宛てがわれた。

　貰ったばかりのプリムローズイエローの半袖シャツを着た直人は、午前中に入荷した荷物を識別し、倉庫に運び込んだ。この種の仕事は前に務めていた会社で行っており、要領が良い。持ち上げ方、商品に傷を付けない降ろし方、並べ方とも経験が生きている。磯部に「お前、なかなかうまいな」と褒められるほどだ。

　白にコバルトグリーンが交じった色の半袖シャツを着た亜矢は、事務の仕事をする。伝票を受け取ると商品の箱を持って来て送り状を作成し、配送担当者に渡す。注文はダンボール箱単位の発送もあるが、小分けして数個単位のこともある。中味が愛らしい商品であることを知っているので、やること全てが楽しい。ここで働かせてもらえて本当に良かった、と亜矢は思う。

　一日の仕事が終わった直人と亜矢が、部屋に戻って座った。簡単な作業の仕事ながら、何かをやった、という充実感がある。この気持ちを持てるから、その後の憩いが嬉しい。自分たちを卑下していたこれまでの回りの人たちに対し、ここの人たちは普通の人間として認めてくれる良い人ばかりで、恐れを抱いたことも非難されたことも忘れられる。終業後にこうしてのんびりと時間を過ごせることは、二人にとって大きな幸せだった。亜矢の手を取って、直人が今の喜びを表す。

「ここに住まわせてもらえて良かった」

　寮では間違った噂を信じて悪口を言う者ばかりで、親切心をちらつかせて近づいてきた者は、自分の体欲しさだった。親身になって相談に乗ってくれたり、世話をしてくれたりする人は、ここの旦那さんとおかみさんだけだ、と亜矢は思っている。直人の手を握り返し、亜矢は呟くように言った。

「うん、あんなに心の広い人がいたのね」

　「渡る世間に鬼はなし」の故事を思い出した直人は、この日、極めて楽観的である。

「世の中、見捨てたもんじゃない、ってことかな」

　確かそんな格言があった。それが頭にあった亜矢は深く肯く。

「そうかも」

　と言った亜矢は、あることを思い出すと直人の手を離した。

「でも･･････」

　顔を前に伸ばし、直人が問い詰める。

「何だい？どうかした？」

　口を滑らした結果として、災いが降りかかるのではないか？ここを追われると、再び自殺したい衝動に駆られる、と思い、畏怖した亜矢はここで言おうかどうかためらった。迷った挙げ句に、亜矢は先ほど明が渡したメモを引き出しから持って来て直人に見せた。亜矢は明の気になる言葉をしっかり覚えていたのだ。

「きょう東慶寺で助けてもらった人に会ったの。その人が言うには『この店、何か怪しい』って」

　亜矢が会った人は意外だが、言われたことはもっと意外だ。直人は身を乗り出して問う。

「えっ！あの人が？」

「そう、自殺を思い留まらせてくれた人」

　漠然と思い出した直人は、睨む目付きで追及する。

「それで、何が怪しいって言うんだ？」

　亜矢は直人の口に人差し指を立てて接触させる。

「しーっ！小さい声で話して。･･････店の荷物みたい」

　亜矢の人差し指が触れたまま、直人は囁く。

「盗んだ物だと言うの？」

　それは飛躍しすぎだ。これだけの数の土産を盗んでくるには骨が折れるし、安価な品物では見返りがあるかどうか疑問となる。亜矢は頭を横に振った。

「ううーん、そうは言ってないけど。きっと･･････」

「何だい？」

　亜矢は直人の耳に口を近づける。

「密輸品と疑ってるみたい」

　まるでスパイ映画かアクション映画で使われる言葉に、直人は背筋を伸ばした。

「密輸！どこの国から？」

「さあ、どこだか」

　悪に対抗して血沸き肉踊るのが男だ。自殺を願望した意志の弱い者にも、少しは勇気がある。直人は体を沈めて小さい声で提案する。

「こっそり調べてみようか？」

　言ったからには、亜矢もその気になっている。

「うん、後でね」

　定例の時刻になり、定子と霊玉が部屋に入って来た。和服を着ることが多い定子だが、きょうはワインレッドのワンピースを着装している。気品のある顔としゃきっとした姿勢は、洋服に替わったといえ威厳がある。

　霊玉はお馴染みの白い装束だ。着替えているだろうけど、いつもこの衣装ではセンスが疑われる。そんなことは霊玉にとってはどうでもよく、朝と夕方にマインドコントロールをしっかり行えば良いのだ。定例のこととなると、霊玉がつっけんどんに言う。

「修行の時間だ」

　霊玉に向かって定子が、意味ありげにそっと命令する。

「しっかり仕込みな。いよいよあしただよ」

「へい、承知しました」

　霊玉が直人と亜矢に催眠術をかけると、効きが早くなった二人はぼーっとなった。個人の考えは色あせ、霊玉の考えだけが注入される。また、二十年近くの間に貯まった記憶の膜に穴が開き、それが漏れるように感じる。霊玉に吸い取られるのは、意識も記憶もだ。

　良く仕事をするし、きちんとマインドコントロールを受ける二人に仕上げたことで、霊玉は鼻高々である。この教育振りに「しっかりやってるな！」と言って、勝が褒めてくれた。俺は得意技の催眠術の他にも優れた能力がある、と霊玉は自負している。

　霊玉が手を回して問う。最初は柔らかい言い方だ。

「お前のもっとも崇拝する方は、どなたかな？」

　この質問に慣れてきた直人が、すぐさま答える。

「はい、岩本勝様です」

　次の問いは亜矢に向けられた。

「お前のもっとも崇拝する方は、どなたかな？」

　亜矢もすらすらと答える。

「はい、岩本定子様です」

「お前は、あす何をする？」

　直人は恭しく頭を下げて言った。

「旦那様のために、大事なお手伝いをさせていただきます」

　ここから霊玉の顔が厳しくなり、言葉も鋭くなった。

「疑われた場合、お前はどうする？」

　亜矢は無抵抗な羊となり、霊玉の全ての指示を受容する。

「『全てわたしたちが行いました』と言います」

　この種の問答が三回繰り返され、どれも模範的な発言となった。訓練は上出来、この調子では、あした二人はしっかり働いてくれるだろう。そうすれば、ここの主人からたんとご褒美を頂ける、と期待し、霊玉はにんまりした。霊玉の仕事ぶりを目でしっかり確かめられ、定子も安心だ。本日分のマインドコントロールを早めに終了し、定子と霊玉は満足して退室した。

　しばらくして定子が再び現れた。訓練や苦行を強いることの後にお盆に載せて持ってきた物は、飲み物の入ったグラスと果物である。普段、客をもてなすときには従業員に指図してやらせるが、この果物は自分の手で洗い、飲み物は自分がジューサーで作った。こんなことは初めてだ。定子はそれらを直人と亜矢の前に差し出した。

「お腹が空いたろう？休みな」

　新米の自分たちを気遣い、厚遇してくれるのが定子だ。喉が乾き、気分がもやもやしていた直人と亜矢は喜んだ。

「ありがとうございます」

「頂きます」

　空腹となっていた二人は、ジュースのグラスを取って飲み、果物を食べた。指で直接イチゴの 蔕 ( へた ) を摘まみ、実を口の中へ入れる。歯で実を引っ張り、残った蔕は空の皿に落とす。この繰り返しである。オレンジを絞ったジュースと大きい真っ赤なイチゴは、新鮮な味覚を与えてくれ、この家にいることの良さを二人に再認識させるものだった。

　二人は定子に身の上話をした。ただし、亜矢が妊娠していることは伏せておいた。いずれわかることだろうが、今追い出されるのは困る。先のことは後で何とかしようと、亜矢は楽観的に考える。

　二人の話を聞いた定子は感涙し、できる限り援助しよう、と決意した。単なる女の慈悲かと思うと、もっと深い訳があった。定子は社会に見放されたこれらの不遇な若者と、当時の自分を比較してみた。

　四十七年前、大地震に見舞われた十歳の自分は、親兄弟を失ったうえ家屋が倒壊し、食べる物、寝る所に困窮した。荒涼とした街をさ迷い、道に落ちている物やゴミ箱の残飯をあさって食べたり、ガード下で寝たりして生き延びるという終戦直後のような体験もした。当時の自分より十歳ほど上となるこの子らが、住む家も食べる物もない状況は同じだ。

　定子にはおいしそうに食べている二人が、実の子供のようにかわいく思える。二人を客並の待遇にするのはそのためで、特に亜矢を見る定子の目は食い入るようであり、今にも抱き締めたい、という愛情が 迸 ( ほとばし ) っている。その気持ちを抑えて飲み物と果物を供することに留めているものの、娘に似ている亜矢ともっと親密になれば黒ずんだ邪心が浄化し、定子は娘が生きていた時代の善良な市民に戻れる気がする。亜矢を見つめることは、定子にとって心の濁りが消える坐禅なのだ。

　できればマインドコントロールをやめさせたいが、この二人だけ特別視したのでは他の従業員の 顰蹙 ( ひんしゅく ) を買う。差別は店内の混乱に繋がるので、磯部や霊玉がいるときは決められたことを行い、その後こうして二人を 労 ( いたわ ) るのが定子の喜びである。

　食べ終わった二人は、感謝の気持ちを込めて言った。

「御馳走様でした」

「新鮮でおいしかったです」

　元気になった二人の顔を見て、定子が 叱咤 ( しった ) 激励 ( げきれい ) する。

「それは良かった。これからもしっかりおやり」

「はい、一生懸命やります」

「いつも励ましていただき、ありがとうございます」

　空になったグラスとイチゴの 蔕 ( へた ) を入れた器をお盆に載せて定子が部屋を去るとき、お腹においしい物が入り、喉も潤った直人と亜矢が頭を下げて定子を見送った。世の中にはお金を貯めることだけを考え、他人に施しなどする気がない欲張りなお金持ちの人もいる。自分たちと似た境遇を持つおかみさんや旦那さんは狭量な人間とは大違いで、自分たちのことを考えてくれている。二人はここの主人夫婦を神のように崇めた。

　養子の相談　

　定子は器を台所へ持って行き、果物の残骸を生ゴミ用のポリバケツに捨てた。後始末は女子従業員がやってくれるので、器はそのまま流し台の上に置き、その後、潔癖性のある定子は入念に手を洗う。悪に染まってからは「やりすぎ」と他人に言われるほど、長い時間を手洗いにかけるようになった。落ちにくい汚れが手の皮膚にしっかり染み込んでいるように思えるので、今では十回も手を 擦 ( こす ) る。

　タオルで拭いた後、定子が豪華な応接セットのある部屋に入ると、コパー色の長袖シャツを着た勝がタバコをくわえながら雑誌を読んでいた。ここは問屋の管理に忙殺されている勝がくつろげる唯一の場所だ。大きく吸ってふーっと吐くと煙の輪ができ、雲となって宙に浮く。遊んでいるようにも、あすのことが気がかりで気を紛らわしているようにも見える。

　そばに寄った定子に、タバコを灰皿に置いた勝が尋ねた。

「どうだ、あの二人、進歩しているか？」

　二人の指導の責任者である定子は、自慢げに答える。

「えゝ、まじめにやっているし、あなたとわたしに感謝してますよ」

　定子、磯部、霊玉らの上層部の者に任せているのだから当然と思い、勝は満足の笑みを浮かべた。

「そうか、上々だな」

　機嫌が良くなった夫に向かい、ここぞとばかりに定子が猫撫で声で語りかける。

「ねえ、あの亜矢、亡くなった美奈に似てるでしょう？」

　勝は上を向いて目を瞑り、脳裏の奥の絵姿を思い起こしてみた。もっとも新しい記憶は、病床にいた亡くなる寸前の美奈の姿で、それは霊玉の力など借りずにいつでも思い出せる。その時代を更に十年ほど遡ると、勝の網膜に亜矢が美奈と重なってきた。

「言われてみるとよく似てるな。美奈もあの年ごろには香り高く、体がスマートだった。俺にはちっとも似ず、お前に似て美人だったもんな」

　この年になって称賛された定子は、恥ずかしさを押し殺す。

「ふゝ、今ごろお世辞ですか？」

「ほんとだぞ」

　前置きはそれくらいにし、定子は計画していた話題へと導く。

「大地震で親と家を失ったわたしたちを、ここの先代が引き取って 庇護 ( ひご ) してくれましたよね」

　素足で親を探し回ったり野宿をしたりした勝は、苦難の時代のことが目に浮かんだ。

「行き場を失った小さい自分たちを、先代が養ってくれた。その恩に報いようと、苦境にめげずにひたすら働いた。昼も夜も懸命にな」

　定子が勝と 邂逅 ( かいこう ) したのは正にこの店だった。とはいえ、当時、この問屋は都内の台東区にあり、浅草の土産物屋を主な対象とした商いをしていた。高度成長時代の真っ直中にあって景気は良く、物がよく売れたことで店は繁盛した。

　不幸な少年少女はその問屋の屋根の 下 ( もと ) で兄妹のように育てられ、店の仕事を手伝いながら転向した小学校、それに中学、高校まで行かせてもらった。わからない宿題を教え合った二人は、残っている仕事に手を貸してやったりお互いに励まし合ったりし、食事も一緒に摂って一年一年を過ごしていった。

「同じ境遇だったわたしとあなたは結ばれる」

　苦労もあれば成果もある。勝は誇らしげに語る。

「店のために一生懸命働く姿勢が認められ、先代の強い信頼を勝ち取った。その結果、子供に恵まれなかった先代の養子となった」

「ほんとうに感謝の連続でした」

　その他にも、良い履歴書はまだまだある。思い出を引き寄せる勝の鼻が、益々高くなる。

「社会へのせめてもの恩返しと思い、交通事故で親を亡くした子や、母国の戦乱を逃れて小さい船で辿り着いた難民を雇ってやった」

　そばにいて勝を支えてきた定子は、夫の努力をしっかり覚えている。夫の献身は定子にとって誇りであった。

「それも先代から受け継いだあなたの人徳ですよ。従業員たちは感謝し、命を捧げるつもりで働いています。労働意欲は高まり、店は繁盛しました」

　そうだ、そういう時代もあった。勝は大きな名誉を思い出し、顎を上げて自慢する。

「人道主義を貫く名誉ある区民と評価され、役所から感謝状と記念品を贈呈されたぞ」

　夫が高邁な人間として崇められた理由を、定子は十分承知している。

「善行が口々に区内に伝わり『あそこの店はいい仕事をするうえ、弱者を援助している』ともっぱらの噂となったんですもの」

　浅草も時代とともに変化し、昔ながらの土産だけでは商売が難しくなった。そのうえ「この地にビルを建てたいので、土地を譲って欲しい」と新しい事業を計画している会社の役員にしきりに頼まれる。「左右の家はもう了解が得られております。残るのはお宅だけです。浅草の発展のために、ぜひお願いします」と役員たちが入れ替わり立ち代わりに訪ねて来てせがむ。

　隠居している先代に相談したところ「ここでは大きな競争相手がいて、これ以上商売を拡大するのは無理、むしろ萎む方向だろう。それなら、鎌倉でやる手はどうだ？わしの実家がそこにあってな、親は亡くなったが、立地条件の良い広い土地があるぞ」と言ってくれた。

　孤児の自分たちを引き取って育ててくれた大恩義がある先代に、土地まで提供してもらっては恐縮する。強く辞退した勝と定子に、先代は「一度は生まれた所で商売をしてみたかった。うまくいくかどうかは時の運として、やるだけやって鎌倉に骨を埋められれば本望だ」としみじみ語る。「いきなりそこで商売を始めて、得意先があるんですか？」と勝が疑問を投げかけると「遠戚や同級生に土産屋を営んでいる者が何人かおる。きっと付き合ってくれる」と先代は希望を持たせる発言をする。勝は「店を建てるには多額の費用が」と言い、一番困難な理由で迫った。これに対して先代は「今の土地は一等地だ。売ると高いぞ」と言って交わす。結局先代に押し切られ、住んでいた地を手放して鎌倉に移ることになった。

　一からやり直しとなり、それこそ不眠不休、死に物狂いで勝と定子は働いた。開店当初は規模が小さく、販売対象の店は鎌倉市とその近辺に限定されていた。鎌倉という大観光地の膝元ということもあり、しだいに経営が成り立ってきて、今ではテリトリーが三浦半島一帯や、湘南、小田原まで広がった。従業員と一緒に懸命に働いたことによって売り上げは増加し、家屋もこんなに立派になった。これも先代や妻の定子、従業員の働きのおかげと勝は思っている。

　その繁栄を鎌倉の地で確かめた先代は夢が叶い、老境の生活を安逸に送った後、四年前に亡くなった。最後の言葉である「どうだ！俺の言ったとおりだろう」と満足げに呟いたのが、勝の耳に残っている。勝と定子は何から何まで支えてくれた先代、というより義父を手厚く葬り、別れを告げた。義父の遺骨は東慶寺に納められており、勝も定子もしばしば墓参に訪れる。

　サクセスストーリーがこのまま続けば善良な市民でいられ、皆から崇められた。人生は 紆余曲折 ( うよきょくせつ ) があるもので、山の後ろには大きな谷がある。勝の思い出はここで別の方向へと向かった。

「愛する娘が嫁ぎ、子供を生んだ。自分にとって初孫で、目の中に入れても痛くないほどかわいい。娘が孫を連れて里帰りする度に、童心に返って遊ぶことができたのに･･････」

　定子は腹を痛めて産んだ子のことを思うのが切ない。病床で娘の手を握り、何度励ましたことか。自分が代わってやりたい、と何度思ったことか。それを思うと目は潤み、ポロポロと涙が頬に落ちてきた。

「その幸せも二年前に急転。あの美奈が子宮癌で･･････。神や、仏を信じていたわたしは、もうそれも･･････」

　父親にとって娘は、精気を生む源泉となる理想のマドンナだ。あのとき勝は 慟哭 ( どうこく ) して我を忘れたばかりか、以後問屋の方針を方向転換してしまった。

　世を 儚 ( はかな ) む勝の言葉は嘆きに変化する。

「俺も懐疑的になった。好調だった商売は売れ行きが 鈍 ( にぶ ) り、赤字の直前にまで達した。そんなもんだからやり方を変え、利益を求めて何でも行うはめになった。欲得に凝り固まり、性格まで変化してしまったな」

　川の水は普段決まった筋を流れている。それが、台風や大雨により堤防が決壊すると、左にも右にも溢れる。勝の道徳心も娘の死と時を同じく 瓦解 ( がかい ) し、死滅するに至った。

　定子は運命という川の流れが急変したことを悔やむ。

「悪魔がわたしたちに乗り移ったんでしょうかねー？」

　背もたれに体を預けていた勝は顔を起こし、 毅然 ( きぜん ) として言い切った。

「店を守るためだ。綺麗事だけでは世の中を渡れん」

　大人の世界には、立て前という義と本音という欲望がある。綺麗なことを言い、法律のぎりぎりの線を渡っている者も、裏で法律を犯している者もいる。みな自分の利益を確保するためにやっているのだ。義を重んじる定子も、それが十分わかる。

「それもそうですね」

　このように過去のことが二人の頭の中を去来した。それは初心を思い起こさせて良いとして、定子の本音は隠れたままだ。

「今更昔話とは定子、いったいどうしたことだ？」

　頑固な人に直接ものを頼めば、拒否されるのが落ちだ。特に夫の勝は頑固一徹で、他人の意見などめったに聞き入れない。それを心得ている定子は、 婉曲 ( えんきょく ) 論法で迫る。

「わたしたちには子供も、この店を継いでくれる人もいないんですよ」

　後継者についてずっと悩んでいた勝も、先代から受け継ぎ、努力してここまで発展させた問屋を自分の代で終わりにするのは惜しい。問屋の断絶を回避して何とか次世代へと繋ぎたい、と願う勝は、この二年間いくつかの案を模索していた。

「従業員はよく働いているが、店を継がせるにはちょっとな」

　ようやく準備は整った、とばかりに、定子はここに来た目的を柔らかい口調で話す。

「あの亜矢と直人を養子にして、店を継がせるのはどうですか？二人は実にまじめに働いている。境遇も性格も昔のわたしたちとそっくり。『歴史は繰り返す』ですよ」

　慈悲をかけてこの家に住まわせた二人、それも、あることに利用しようとしている二人の処遇の提案に驚いた勝は、すっと背筋を伸ばした。

「むー、大胆な発想だな」

　何も降って湧いた話と違い、この前例は自分たちによってなされたものなので、確かなことだ。精神的なメリットを強調する定子は、これが妥当な案、一番の押しと考える。

「そうすれば、生き返った美奈と再び生活することになります」

　頑固な勝にも利があることは十分わかった。そうすることで、自分も浄化の道を辿ることができよう。さりとて、当面の目標が頭にこびり付いている勝は、やや上を向いてしっかりと言った。

「例の策がうまくいくことが前提だがな」

　どうやら自分の提案が実を結ぶ目途が付いた、と思い、定子は顔をせり出して念を押す。

「そのときはもっと真剣に考えてくれますね」

　妻の提案は良いものだった、と思う勝は、身を引き締める。

「そうしよう。ただし、油断は禁物。俺たちのやろうとしていることを勘付かれては、元も子もない。あまり心を許すなよ」

「勿論ですとも。この店のことが一番です」

　夫も二人に共感し、自分が抱いた計画に賛成してくれた。二人を養子にすれば、悪の道から容易に脱出できるうえ、神や仏を再び信じることも、美徳を重んじることもできる、と定子は期待し、ほっとした。こうして方向付けがされると、定子は勝の忠告を片隅に放り込んでおき、亜矢と直人にもっと優しくしてやろう、と決心する。

　お腹が満たされた直人と亜矢はまだ少し頭がぼーっとしており、畳の上に足を投げ出して休むもののそれも短い時間で、閉店時刻となれば二人は従業員の夕食作りを手伝う。新米者ではどうやっていいかわからないので、亜矢は先輩格の者に教わりながら野菜を切ったり、直人は盛り付けをしたりする。それができ上がると、二人はみんなと一緒に食堂の席に着いた。もう従業員の顔も覚え、言葉を交わせるまでになっているので、 和気藹々 ( わきあいあい ) と話しつつ二人はご飯を頂いた。

　不慣れな仕事により疲れが溜まった直人と亜矢は、宛がわれた部屋で早めに布団を敷いた。布団は押入に二つ用意されているものの、一つだけ敷いて二人で入り込む。狭い布団からはみ出ないようにするには、接近することだ。二人はこの世で一番愛している者と抱き合って夜を過ごすつもりだ。

　霊玉の術は他人の干渉を跳ね返す強い力を持っている。夕方のマインドコントロールを受けて頭の中を撹乱された二人は造反の意識が薄れ、挑戦する勇気も奪われた。先ほど言ったことを後悔した亜矢が、そっと言った。

「この家を調べてはだめよね。ここで世話になっているわたしたちだもの、旦那さんとおかみさんに悪い」

　この問屋に依存しているから生きていける。勝に畏敬の念を抱いている直人が、口を揃える。

「そうだな。ここ以外では俺たち日干しだ」

　〝探索〟という言葉は以後禁句となり、背徳行為の計画を 頓挫 ( とんざ ) した二人は、布団の中できつく抱き合った。家や寮には「どうしたの？」と言って心配してくれる人はおらず、ただ放っておかれるだけだ。ならば家に帰るより、死んで天国に行くより今の状態の方がはるかに良い、と二人は考えている。安定した住まいや日に三回与えられる食事とともに、大好きな人のそばにいられることは、谷底に落ちた二人にとって大きな喜びであった。

　地図　

　話は時間的に少し遡るとして、買った多くの物を両手に明とあすかは、午後マンションに戻った。二人ともラフな服装に着替え、あすかが早速冷蔵庫の整理を始める。冷やしている食物や食材をいくつかの大きいビニール袋に区分けして入れ、ペットボトルの飲み物はしばらく外に置く。引っ越し直後では保存してある食料は少量で、あっという間に整理がついた。

　夕方約束どおり注文した冷蔵庫が配達され、古い冷蔵庫を引き取ってもらった。環境問題が取りざたされている昨今では、引き取る費用も発生するので、それは購入した際に支払っておいた。背が高い分、新しい冷蔵庫は大きく、これで購入した食材やら食べ残した物がたくさん入ることだろう。

　あすかはビニール袋に一時保管しておいた物を、新しい冷蔵庫の冷凍用、製氷用、冷蔵用、野菜用に区分けされた所に一つずつ入れる。それらを全部収納した後でも、まだスペースがある。これなら家族が増えたとしても、十分対応可能だ。

　落ち着いたところで、あすかは明を伴ってスーパーマーケットに買い物に出かけた。駅の近くにある大きい店だ。こちらの看板には商品の写真や絵がない代わりに、文字が氾濫していた。「安い！」、「新鮮！」、「栄養満載！」、「ＤＰＥも有」、「駐車場完備」と大きな文字が書かれている。全部本当だとしたら、入ってみたくなる。

　 昨日 ( さくじつ ) 買い物をしたので、何がどの棚に置かれてあるかは、あすかの頭に入っている。魚はあそこのコーナー、肉はその隣、野菜は入り口近くだ。もう数日滞在するあすかは、明の好きな料理とやらを作ってやろう、と思い、その分の食料をたっぷり揃えた。部屋と同様、冷蔵庫も空間が埋められ、リッチに見える。

　条件が整い、二人共同で料理を作った。今夜はカレーライス、このくらいの料理は明にとってお手のものだ。一人暮らしの者のレパートリーは限られており、簡単でその割にはおいしいカレーライスを頻繁に作っていたので、明は自信を持って腕を振るう。

　肉を切っている明が宣誓する。

「冷蔵庫が大きくなり、たくさん食材が入った。さあ、おいしいカレーライスを作るぞ！」

　野菜を切る作業を手伝うあすかが、不安げな顔をして前日のお返しをする。

「早速、冷蔵庫が効果を発揮するのね。明のカレーライスって、食べられるかな？」

「うまいかどうかは別として、毒は抜いてある」

　物騒な話だが、それを明の下手なジョークとするあすかは、平気で言った。

「じゃあ安心して食べよう」

　冗談を飛ばした二人は、陽気に料理を作った。

　カレーライスができ上がり、二人は皿をテーブルに並べた。人間も並び、スプーンで掬って食べ始める。明が、

「毒見をしようか？」

　とおどけて尋ねると、あすかは、

「死ぬときは一緒でいい。だから、同時に食べましょう」

　と言ってくれた。冗談でも、これには明が喜んだ。そうか、あらゆる運命は、あすかと共に訪れるのだ。

　毒はないとして、さて味はどうだ？あすかが満足げな顔をしていることからすると、明の作品は合格であった。

　食後にふーふーと息を吐いて、濃いお茶を飲む。辛い味の後は渋い味、これが鎌倉の味とあすかは思った。鎌倉に慣れ、家に落ち着いたせいか、あすかは少し年寄りじみた気もしたが。

　半分飲んだところで、茶碗が隠れるほど大きな地図を明がテーブルの上に広げ、中央付近を指差した。

「これ、鎌倉の地図。ここが、うち。･･････どう、鎌倉駅にかなり近いだろう？」

　目を細めてあすかが地図を 覗 ( のぞ ) き込んだ。

「そうね、交通の便が良さそう」

　明が地図を横に動かすと、ススーッという音がした。下の茶碗が倒れるのではないか、と心配になるが、地図は茶碗の上縁を滑って移動したため、テーブルの上の洪水は免れた。

　まず公共機関を明がまじめな顔をして説明する。

「ここがきょう行った市役所」

「婚姻届はそこね」

「そう、式後に手続きをしよう」

　役所の手続きを忘れると、市のサービスを受けられないなど、いろいろ面倒なことが起こる。こういうことは、どたばたしているときによくあるもので、特に転居の際は要注意である。

　他にあすかは立場上の不具合も挙げた。

「それ忘れるとわたし、ずーっとお客様」

　ということは、正式な妻の座がお預けということだ。二人は既に同じベッドで寝ている。夜の相手が戸籍上の他人では不倫となり、明に後ろめたさが残るであろう。結婚届は不倫との絶縁状でもある。

「大変なことになっちゃうな。･･････それと、ここが警察」

　そこでやることがあるあすかが、さりげなく事例を挙げる。

「運転免許証の住所変更をする所。また、悪いことした人が連れて行かれる所ね」

　前半の例は妥当として、後半の例は問題だ。またもや明のおとぼけが始まる。

「あすか、近いうちに悪いことする予定ある？」

　まじめに働くより楽と思い、意識的に悪事を働いて刑務所暮らしをする者がいる。何とまあ醜いやつだ。そんな人間がいると、国民が納める税金の無駄遣いになる。社会の 蛆 ( うじ ) の類にされたあすかは驚いた。

「まさか」

「なら予約する必要ないな」

　ひどいおとぼけだ。それを無視しようと考えたが、どうもおかしい。おとぼけに対しても疑問は湧く。

「警察へ予約して入る人って、いる？」

　ホテルに泊まったり、公民館の会議室を借用したりする場合には予約が必要だ。運転免許証の住所変更などの手続きは、時間内であれば警察署内にて予約なしで処理してもらえる。署内の工事をする業者は事前の了解を得る必要があるが、一般人が予約を取ることなどない。明は先週見たテレビドラマにヒントを得ていた。

「自首しようとする人はする、と思う」

　それを予約というのかどうかは別として、あすかは感心した。

「そうか、よく気が付いた」

　地図の道筋を指で辿って、明は説明を続ける。

「これが最初の日に回ったコース。北鎌倉駅をスタートし、この道を通って大仏様へ。･･････それから浜辺へ」

　地図には波の形の線が何本も引かれている個所があった。いわゆる等高線である。それを見たあすかが発見をした。

「こうして見ると、鎌倉は周りを山で囲まれてる」

　市の中心部を両手で囲み、明が解説する。

「三方が山、残る所は海で天然の要塞だ。だから、敵が攻めにくい。頼朝が幕府の地にここを選んだ理由はそこにあった」

　時代のヒーローは、一般的に活動家である。義経、尊氏、信長、秀吉、信玄、謙信、家康と、どの武将も日本各地に遠征し、暴れまくっている。海外でもアレキサンダー大王やナポレンは、何日もかけて遠征している。そんな英雄たちの中で、あすかは例外があることに気付いた。

「頼朝って、鎌倉をあまり出て行かなかったみたい」

　さすが、あすか、よく気が付いた。冷静に明が歴史の事実を述べる。

「平氏追討は弟の義経や範頼に任せ、自分は鎌倉に留まっていた」

　頼朝の性癖を分析したあすかは、頼朝を内弁慶と見なした。それなら、時の権力者である平氏に対して、少人数で旗揚げするという暴挙に尻込みしたであろう。革命家は勇者であるべきなのだ。あすかが捻り出した結論はこうだった。

「人任せな英雄か」

「ふゝ、変な例え」

　明は再度地図を指差した。そこは鎌倉市のほぼ中心だ。

「ところで、あす、この鶴岡八幡宮で流鏑馬がある。部屋の整理が落ち着いたので、行ってみようか？」

　あすかはこれには胸を踊らせる。流鏑馬などめったに見られるものではない。憧れの鎌倉にいるメリットが、もう現れそうだ。

「いいな。わたし、流鏑馬って、見たい、と思ってた。勇壮よね、それ」

　先月までのデートでは、明は住んでいる横浜をやたらと宣伝していた。「横浜は明治維新のころから栄えた文明開化のルーツだ。大きな港があるし、ファッションセンスの良い街もある。何てたって、日本第二の人口を有する大都市だぜ」と。それが、市役所で登録を済ませたとなると、もう鎌倉に心変わりだ。あすかは「男心は秋の空」と言いたくなった。

　鎌倉市民に成り立ての明が、早速自慢する。

「そう、鎌倉の名物行事」

　一転して明は申し訳なさそうに続ける。

「と言いたいんだけど･･････」

　鎌倉で流鏑馬が行われることは、放送されたテレビニュースを何度か視聴しているあすかも知っている。それを否定する明が不思議だ。

「どうしたの？」

　ここは半分申し訳なさそうに明が説明する。

「本当は四月と九月が正式行事。あすは映画のロケのために、特別にやるんだって。 静 ( しずか ) 御前の舞も写すとのことだ」

　目的が何であれ、本番と同じ内容で催しが見学できればよい。幸運を掴んだあすかは、子供のようにはしゃいだ。

「あら、こんなときに来て、わたしって運がいい！」

「市民もエキストラとして参加できるらしい。あすかの姿も映画として残るかも」

「わたしたちも見物していいの？」

「うん、後ろの方だけどね」

　堅物のあすかが、妙に顔を緩めて叫んだ。

「明！」

「何だい？」

　明を見つめてあすかが猫撫で声で告白を始める。

「明のそばにいると、何しても･･････何話しても楽しくってさ。このままここにずっといたい！」

　あすかを抱いたのは良しとして、ずーっとここに居座るとあすかの家は大騒ぎとなり、怒り狂う両親が婚約を破棄することだろう。明は驚いて立ち上がった。

「もう駆け落ちかい？それも、結婚式の前に。･･････わがままなお嬢様」

　甘い美酒に酔ったあすかは、気を取り直して冷静になる。

「わかってる。冗談、冗談よ。甘えてみたかったの」

　胸を撫で下ろした明は、へたへたと椅子に座った。

「あゝ、びっくりした」

　静の舞　

　源頼朝が源氏の氏神として出陣する際、戦勝を祈願する目的でこの地に移したのが鶴岡八幡宮である。ここの代表的な行事は、春の鎌倉祭の際に行われる静御前の舞と流鏑馬となっている。

　流鏑馬は笠を頭に載せ、狩装束を身に付けた 射手 ( いて ) が、馬を走らせながら三つの的を 鏑矢 ( かぶらや ) という矢で射止める勇壮な弓の訓練である。鎌倉時代にもてはやされ、今も各地の神社などで伝統が守られている。人を 殺 ( あや ) める 戦 ( いくさ ) の練習にも取れるが、そこは目を瞑り、勇壮さと迫力だけを楽しめばよい。

　静の舞とは平氏追討に功績の大きかった源義経の 愛妾 ( あいしょう ) 静が、頼朝に命じられて回廊で行った舞のことである。義経人気は未だに衰えず、静との悲劇のロマンスに涙を流したい人が山ほどいるので、現代の舞踊家がここで当時を再現してくれる。

　これらの行事に纏わる物語を題材にした映画の撮影が、八幡宮で行われようとしている。題名は「疾走のイメージ」となっているラブロマンスだ。世界各地で行われる Ｆ１ ( エフワン ) レースをふんだんに取り入れた迫力満載の映像に、男女の愛が同乗するという仕掛けとなっており、制作発表の時点で人気が沸騰していた。

　鎌倉で生まれ、鎌倉で育った天才ドライバーがレース中事故に遭って記憶を喪失する。それを知った幼少のころ一緒に遊んだ同級生の女、今は八幡宮の巫女をしている女が、彼の記憶を蘇らせようとして鎌倉の各地を連れて回る。彼を慕う女の地道な努力によってカーレーサーは記憶が戻り、競技に復帰できた。勝負感も戻った翌年には、優勝するまでに至る。祝いの花束を持って勝利者を迎えたのは、彼の記憶を蘇らせ、永遠の愛を誓ったその女だった、というストーリーである。

　記憶喪失のテーマは在り来りとしても、鎌倉の史跡を回ることで記憶を取り戻すアイデアはユニークだ。こういうストーリーを基に、巫女がカーレーサーに静の舞や流鏑馬を見せるシーンが設定されていた。ロケ地は当然鶴岡八幡宮である。

　静が昔舞った回廊は狭くて踊りにくいし、見物する方も見にくい。今は立派な 舞殿 ( まいでん ) が完成したことにより、大勢の人が楽に見ることができる。舞殿は本宮や社務所と独立した離れ子島のような正方形の建物で、広い境内の中央にでんと構えている。本宮の色に近い濃い朱色の柱が厳めしく、舞の舞台にしては頑丈な作りである。四方が開放され、どの位置からも舞台が見えるため、見る側にとって好都合だ。

　開放はよいとして、夜間は戸を閉めるのであろうか、それとも吹き通しの舞台を維持するのであろうか？巻き取られている 簾 ( すだれ ) の下部を全部下ろせば中は隠蔽されるが、風雨を防御できるところまではいかない。あすかはこんな余計な心配をした。

　舞が始まる前にあすかはショルダーバッグの中の本を手に取り、他の人に配慮して小さい声であすかに問う。

「これ 義経記 ( ぎけいき ) 。読んだことあるよね？」

　あすかの本を受け取った明は、パラパラとページを捲った。静が舞う挿し絵を見て、明も小さな声で言う。

「勿論。･･････何でまたここに持って来た？」

「鎌倉に 因 ( ちな ) んだ話なので、読み返してみよう、と思って」

　明は本をあすかに返し、顎を突き出して冷やかしにかかる。

「文学少女に後戻りかな？」

　それはありとするあすかは、すまして本の内容に触れる。

「ときにはね。この本によると、源義経が四国へ平氏追討に向かう際、六人の女房と五人の白拍子を連れて行った」

　出張の際、公費で妻を同行させた者は袋叩きに合う。それも妾となればもってのほか、

更にそれが複数とならば、おそらく免職になるだろう。男である明は、昔の英雄が羨ましくなった。

「昔の大将って優雅なもんだよな。戦争に行くにも女を伴うなんて。しかもたくさん」

「その中で義経にもっとも寵愛されていたのが、静という白拍子だったの」

　明の羨ましさは更に続く。

「超美人だったもの」

　一転して、あすかの口調はしんみりとなった。

「平氏を滅亡させた義経に待っていたのは栄光どころか、兄、頼朝の憎悪。やがて義経は奥州平泉に追われて自害する」

　協力して念願の目的を達成した後に、邪魔物扱いにされる例はいくらでもある。それも、血を分けた兄弟という関係での話だ。「兄弟は他人の始まり」とはよく言ったものだ。

　歴史のことなら明の出番だ。同情する口調で明が断言する。

「義経は悲劇の英雄だ」

　愛を切り裂かれた静の悲劇を、あすかが表情豊かに紐解く。

「母の 下 ( もと ) に隠れていた静は探索に合い、発見されて六波羅から鎌倉に送られる。お腹に義経の子を宿してね」

　明は手の平を表、裏と交互に返して占いの動作をする。

「生まれる子が、男か女かで処置が決まる。男なら死、女なら救済」

　女のあすかは静の味方だ。切実なあすかの声が続く。

「静の母は『腹の中の子が男なら、女に代えてください！』と祈った」

　ここで明は手を止めた。

「その祈りは空しかった」

　あすかはいっそう深刻な顔をして語る。

「悲しいかな、運命は男の子を生ませた。赤ん坊は頼朝の 命 ( めい ) で由比ガ浜に捨てられ、短い命となった」

　明は義経と出会う前の静に興味があった。

「ここまでは誰も知ってる。もっと前の雨乞いのところがおもしろい」

「そう『雨よ降れ』と願い、京で百人の白拍子を集めて舞が催された。一人目から始め、九十九人まで舞ったが、雨は降らない」

　世界各地は無論のこと、降水量の多い日本でも日照りが続いて作物が枯れるケースは多々ある。雨乞いでお 湿 ( しめ ) りが得られるなら、どこも 飢饉 ( ききん ) と無縁になるはずだ。「それを実証するデータはどこにあるのか？」と明は言いたい。こんな所で興奮した明が、非科学的なことを冷ややかに排除する。

「舞っただけで雨が降る方がおかしい」

　物語の世界では、不可能も可能となる。自己陶酔に陥っているあすかが、劇的な場面を講談の調子で語る。

「最後に静が舞った際に雷鳴が響き、稲妻が光る。ここぞとばかりに、洪水が起こりそうな雨が三日間降った」

　雨ごいの儀式は各地で行われているものの、その効果となると疑問が残る、と考えている明が冷ややかに言う。

「奇跡だ。もっともそれ、創作くさいな」

　明の疑問をもっともとするあすかは、物語の世界では認めてやる。

「まあまあ。そんな話を聞きつけた頼朝が『一度静の舞を見たい！』と言い出した」

　幼少期を京の都で過ごした頼朝は上品である一方、当時の上級者がそうだったように複数の女と交わっている。独り身のころには近隣の豪族である伊東 祐親 ( すけちか ) の娘、 八重 ( やえ ) 姫に子供を生ませ、政子と結婚してからも他の女と浮気を頻繁に行って政子をいらつかせた。抹殺しようとしている弟の愛妾と知りつつ、絶世の美女を自分のものにしたい、と企んだ頼朝は、身籠もっていることを聞かされ、踊りを見て慰みに代替することにした。そんな週刊誌まがいの発想をする明が、ちらりと本音を吐いた。

「頼朝以外に、男は誰も美女に興味を引くものだ」

　ここであすかはきっぱりと言った。

「それを静は拒否する」

　舞は顔と体での心の表現だ。「あなたを慕っております」とか「あなとのことが気がかりです」とかいう内面を、見る人がわかるように演じる。味方の前では気持ちよく踊れるが、踊りが商売の白拍子とはいえ、嫌いな人に自分の意志を表すのは女として静は避けたい。

　その気持ちを理解しようとする明が、静の代弁をする。

「産んだ子供を殺し、恋人を討伐しようとしている人の前で踊るのは、いやだよな」

　女のあすかは、静の気持ちがよりよく理解できる。明には論戦相手がいるであろう。その者が家を訪れて来た場合、料理を作って食べさせてやる気には、とてもなれない。用が済めば、さっさと追い返すつもりだ。

「当然よね。そこで、家臣の妻が巧妙に静を諭し、頼朝と静は別々に八幡宮に参詣する、という条件で舞を披露する運びになった」

　頼朝役を演じるかのように、明がすまなそうに事実を述べる。

「約束は破られ、同じ日に頼朝が八幡宮に現れる」

　権力を手中にした男は嘘つきが多い、と思うあすかは、男の 卑怯 ( ひきょう ) さに腹が立つ。

「舞を見るのが目的だったんだもの。それではと、静は音曲の伴奏者がいないことを理由に、尚も拒む」

　明は両腕を組み、頼朝の真似を続ける。

「困ったな」

「伴奏する家臣を選び、ようやく静は舞うことになる」

「遂に静も諦めたか」

　あすかが声を震わせ、暗記している和歌を唱えた。

「舞いとともに歌ったのが『しずやしず　 賤 ( しず ) のおだまき繰り返し　昔を今になすよしもがな』と『吉野山　峯の白雪踏み分けて　入りにし人の　跡ぞ恋しき』だった」

　一見綺麗な和歌だが、そこには静の心が表現されている。それを明は指摘する。

「頼朝への強烈な当て付けだ」

　今、静になり切っているあすかは、力を落として結末を語る。

「激怒した頼朝を二位殿、つまり妻の政子が宥めたので、静も折れた。『吉野山　峯の白雪踏み分けて　入りにし人の　跡絶えにけり』と歌い直す」

　悲しそうなあすかの顔を見た明が、静の気持ちを代弁する。

「恋人を諦めた歌に変更したか。･･････そこまで妥協するのは、辛かっただろうな」

　恋人を敵扱いにされた静は、それを命令した人の前で踊らされてどんな気持ちだったか？おそらく腰に付けた太刀を抜き、頼朝に投げ付けたかったであろう。それでは自分の命はおろか、一緒に鎌倉に送られた母の命も奪われる。我慢、我慢と自分を戒めて静は踊った、とあすかは想像する。

　義経の母である常磐御前は、子供の命を助けるために恥を忍んで夫の義朝を討った平清盛の妾になり下がった。その屈辱的な忍耐は、歴史を大転換させた英雄義経の誕生に繋がったから立派なものだ。静も母の身を案じて心の奥で泣いて踊り、気持ちを歌に託した。それが静にできる唯一の頼朝への反抗だった。

　いったん読んだ歌を変更させられたことに同情するあすかが、その後を語る。

「京に帰った静と母は、やがて天王寺のふもとに粗末な草庵を作り、仏道一途の日々を過ごしたってわけ」

　二十七歳のあすかは、平均的な結婚年齢だ。平均寿命の短い昔は、それでは遅すぎる。明は静の年齢が気になった。

「静は何歳だったっけ？」

「数え年でわずか十九歳」

　ということは、今でいえば高校三年生だ。

「惜しいな。そんな若さで、しかも、絶世の美女が」

　話を歴史から脱線させた明に、あすかは口を尖らせる。

「これは悲劇、色話と違う！」

　また嫉妬深い人に明は叱られた。このままではあすかの追及が続きそうなので、それを 逃 ( のが ) れるには褒め上げることが有効と考えた明は、知恵を絞る。

「あすかは歴史の先生だったもんな。さすが詳しい」

　そんなことで妥協しないあすかは、明を睨みつけた。

「こら！ごまかしちゃあだめ」

「はい、美女とさよなら」

　降参した明は手を振って笑い、あすかもたまらず笑いこけた。歴史物語と美女談義はそこで終了となり、話題となった静の舞が始まるので、あすかは紹介した本をバッグに戻した。これからは現代の美女の登場である。

　鶴岡八幡宮の境内の一角にある建物の中で、赤い袴に白衣を着用した巫女たちが、神社のお守りや記念品を販売していた。彼女たちは髪を左右に分けて後ろで結び、背中の真ん中まで垂らしている。その中の一人の巫女はふっくらとした体格をしており、丸顔だった。彼女の性格は大らか、しかも、バイタリティーがある。

　何人かの参詣者は家内安全を願い、厄除札や健康守袋を、車を運転する商売人は交通安全のお守り袋を、 厄年 ( やくどし ) の人は破魔矢をその巫女から買い求めた。いずれも由緒ある神社のお守りに 御利益 ( ごりやく ) を期待する客だ。頂いたお金は、八幡宮の建物の維持管理などに使わせてもらう。巫女はお守りを買ってくれた人に、感謝の念を込めて丁寧に渡した。

　予定した時刻になり、忙しく客と応対していた巫女が壁に掛かっている時計を見ると、横にいる同僚に客の応対を依頼する。

「少しの間、失礼します」

「うまくいくといいね」

　と言い、同僚は客の応対を代わってやった。

「ありがとう」

　励まされた巫女は、建物をそさくさと出た。このとき既に撮影は始まっていた。お守りを売る動作も、同僚とのやり取りも映画のフィルムに入っている。

　巫女が舞殿の前に着くと、指定した場所に男がいた。男は背が高く、細身の体付きをしている。運動能力が抜群に高い男は反面気弱な性格で、一度自信を喪失すると立ち直るのが遅いタイプである。巫女はその男のそばにそっと寄った。

　無精髭に長い髪をなびかせ、トパーズ色のブレザーを着たこのカーレーサー役の男優と、巫女役の女優にカメラが向いた。脇にはレフレクターを持ったスタッフが、太陽光を反射させて二人の顔に当てている。準備完了。いよいよこれからヒーローとヒロインのシーンが収録される。

　男を愛する巫女が、涙ながらに語りかけた。

「思い出して！あなたは一級のカーレーサーだったのよ。レース中、事故に巻き込まれて大けがをしたけど、失った記憶さえ戻れば、必ず優勝できる。必ずよ！」

　男はわかったのか無意識なのか、ともかく肯いた。

「先々週は大仏と長谷寺、先週は北鎌倉のお寺を見て回ったでしょう？少しは記憶が戻りそうなこと、言ってたじゃない。今週は八幡宮で静の舞よ」

　和服の楽器奏者数人が、舞殿の両端に敷いてある座布団に座った。服の色はどれも地味な黒ながら、多くいる女性の後ろ帯は白の地に金色の模様が入っていて豪華だ。楽器は笛、三味線、小鼓、太鼓、琴で構成され、そこに歌い手が加わる。日本の中世のアンサンブルにしては奏者が多い。かん高い笛の音と刺激的な太鼓や三味線の音が 渾然 ( こんぜん ) 一体となって、八幡宮の空気を 雅 ( みやび ) なものに仕立てる。

　日本の横笛は息の吹き込み方によりピッチが変化する。微妙に揺れる音程と哀愁を帯びた音色が、吉野山で別れ離れになった義経の安否を案じる静の心境を表現すると、歌い手も浄瑠璃の節で「吉野山･･････」を吟詠し始める。

　白拍子姿の静に扮した長い下げ髪の女が、 舞殿 ( まいでん ) に登場して踊った。上は白地に金色の模様が入った 水干 ( すいかん ) を、下は足まで隠す赤い袴を身に付け、頭には光輝く黄金色の立烏帽子を載せている。腰には 白比巻 ( しろさやまき ) の刀を差した男の装いで、手には赤い扇を携えていた。身分が低い白拍子は簡素な衣装を身に付けるが、ここの静は貴族が着るような華美な装いだ。

　優美な白拍子の姿は平安絵巻を抜け出し、現在の世界に舞い下りた天女の姿と同じだった。ぴんと立った烏帽子は 嘴 ( くちばし ) に、両手を広げて作る長方形の 袂 ( たもと ) は、大きく羽ばたく鶴の羽に見えた。その金色に包まれた鶴が舞殿で舞う。気品のある顔立ちの女が男装で踊ると、優雅さが表れるとともにもの悲しさも漂う。

　音曲も聴く人の心を揺さぶった。数人が奏でる三味線のピンピンという音が情緒を掻き立て、ポンポンと豊かな破裂音を発する小鼓や大鼓が、優雅な曲にリズミカルな刺激を与えた。踊りを盛り立てるには、絶好の伴奏となっている。これがオーケストラとも、ロックバンドとも異なる日本独自の音楽だ。

　舞殿の前には、 櫓 ( やぐら ) を組んで載せた映画のカメラが回っていた。ひときわ高い所からは舞殿の中がよく見えるのだが、屋根が被さっている舞殿の中央は陰となり、映像が不鮮明だ。そこで投光器で光を浴びせ、艶やかな姿をフィルムに収めている。

　踊る静を狙い、全体像から静の顔へとレンズをズームアップする。静の踊り手がポーズを決めると、端正で凛とした静の姿がファインダーいっぱいに映った。ときにはカメラが周りの観衆をパンニングする。観衆は映画制作に協力しているエキストラである。

　その後はカメラを地上に降ろし、思い出がぼんやりと頭の隅に出かかったカーレーサーと、それを見守る巫女を撮影した。顔をアップで写し、マイクで音声も収録する。

　巫女は男の手を握り締めて言った。

「ほら、静の舞。最初に見たとき『すーっごく綺麗！』と言ってた」

　記憶が喪失している男は、以前のことを思い浮かべようと必死である。

「しずか･･････きれい」

　巫女はあの日の思い出を語る。

「『踊っている人、女みたいだけど、刀を差してるので男なの？』ってあなたが尋ねた」

　巫女に囁かれて静の舞を見ていると男の目が輝き、薄れていた記憶が少し蘇ってきた。聞いた言葉の中から記憶に残っている単語を男は断片的に呟く。

「おんな、かたな･･････おとこ」

　助詞も動詞も抜けた名詞だけの言葉は、男が過去に発した語句だった。言葉自体ははっきりしているものの、人間として回復した、といえる状態にはまだである。植物人間に近い無表情の顔は、現在の舞と思い出の舞が交錯した状態で映っていることを示していた。

　明とあすかは舞殿の西側で舞を見学した。大勢の人が来ることを予想し、明はライムグリーンのシャツにアイボリー色のズボン、あすかはオーキッド色のシャツにクリーム色のスカートだ。どれも最近購入した新しい物で、映画は記録として永久に残る、と配慮し、身だしなみは慎重に整えた。

　現代のバレエやモダンダンスに比べ、ゆったりとしたこの踊りはスローモーション再生の映像を見ているようだ。動きが速すぎては、心を表現しにくい。静の踊り手は流れる動作、ポーズ、顔の表情によって内面を表しており、撮影と知りながらもエキストラの観衆は優雅な舞に魅了された。これらの人たちのラブコールによって、静が現代に蘇ったのだ。

　遅い動作の日本舞踊なら自分もできる、と思い、舞を見る前にあすかは見くびっていた。実際、盆踊りは上手であるし、学校の運動会で生徒が行うマスゲームの指導もしていた。これは甘い考えであった。「動きが遅いイコール 楽 ( らく ) とは、誰が決めたの？」と言い出すと「自分だろう」と明に指摘され、あすかは頭を掻く。

　静の舞は身のこなし方、手の反らし方、顔の角度など、実にきめ細かいし、時々ぴしっとポーズを決める必要がある。これも難しい。ちょっと見ただけであすかは「自分ではだめ！」と言ってギブアップした。

　舞を終えた静が舞殿の周囲を一周すると、動く度にスースーという赤い袴の衣擦れの音がした。この音も良い。音程のないこの音がエンデングになり、かつ、無言の静の挨拶代わりとなった。暗くて舞が見にくかったのが建物の中、舞殿の端に出てくれれば顔や衣装がはっきり見える。扇をかざして胸を張るポーズのサービスを、静が所々で行ってくれた。やはりうっとりする姿だ。

　現代という殺伐とした世界にいっとき典雅な踊りを披露してくれた者に、賞賛の拍手が一斉に起こった。周囲で熱心に見ていた者も、数十メートルも離れた本宮の石段の席を早くから確保して待っていた者も、舞があることを知らずに通りがかった者も懸命に手を叩く。その拍手の嵐に明とあすかも加わった。

　舞殿を去る姿も美しい。運悪く隅の方で見物していた者は通路を歩く静を間近に見ることができ、感激している。その者たちの拍手が収まると、弓を引く構えをして明が促す。

「すばらしかった！さあ、次は流鏑馬だ。見に行こう！」

　静の舞に興奮冷めやらないあすかは、胸が益々わくわくしてくる。

「楽しみだわ」

　優美な舞を 堪能 ( たんのう ) した二人は、近くの流鏑馬会場へと足を運んだ。

　流鏑馬　

　舞殿を囲んでいた何層もの人の輪が崩れ、南側へと移動する流れが生じた。流鏑馬の馬場は、鶴岡八幡宮の参道と直行する小道が当てられている。早く行って良い席を確保したい者は舞が終わるとすぐに足早に歩き、出足が遅れた者は走ってカバーする。流鏑馬を良い席で見たい者は、朝早くからビニールのシートを敷いて陣取っていた。

　道の中央に三メートルほどの間隔を保ってロープが二百メートルほど平行に張られ、その中に砂が敷かれた。その外側には危険防止のため、見物席を仕切るロープ、もしくは竹の柵が設けられている。この道は本来参道の一部であり、流鏑馬のために仕込まれた馬場にしては長い。

　的は三個所に設けられ、短い間に続けざまに矢を 番 ( つが ) えて射ることになる。正式な行事では、最初一辺が四、五十センチもある大きな板にカラフルな五重丸が描かれた的が頂角を上にして立てられ、後ろには花束も置かれる。的を外してもこの花束に矢が 触 ( さわ ) れば命中とされるという、ずいぶん寛大な判定だ。回数が進むと的は小さい木の札に替わり、花束のおまけもなくなる。最後は、より小さい白い皿に黒丸を書いた奇妙な物体が的となる。この物体に命中すると、皿が砕けて中に入っている物が紙吹雪となるのだが、映画の撮影では時間の制約もあり、二番目の大きさの的が使用される。

　馬場を挟んで各的の前にはエキストラと一般見物人が目を凝らし、アマチュアカメラマンは矢が的を射る瞬間を捉えようと愛機を構えている。ただし、フラッシュ撮影は禁止だ。馬が 驚愕 ( きょうがく ) すると、射手も近くの見物客も危険であるため、映画会社のスタッフがメガホンでしきりに注意を喚起した。

　特等席である第二の的の前は、招待客が椅子に腰かけて見物することが多い。国や県の伝統行事をＰＲしようと、外国の大使や観光業者の重役が 招聘 ( しょうへい ) されるとか。映画の撮影のために偉い人にご足労するまでもないので、きょうは俳優とエキストラだけが配置され、後ろには一般の見物人が立って見ていた。

　静の舞は四月の第二日曜日に、流鏑馬は同月の第三日曜日と九月に催される行事なので、両方を一日で見学できるのは撮影というこんな特殊な場合だけである。ただし、二週間分の行事に見せようとして、俳優は衣服を着替えている。男優はカーレースの試合で優勝した際のスカーレット色の勝負服を着た。また、 無精 ( ぶしょう ) 髭 ( ひげ ) を剃り、髪も整えて前より普通の生活に戻っていることを示している。

　その日が休日の設定になっている巫女は制服を脱ぎ、オレンジ色のスーツに替えた。思い出があるその衣装は、けがを負う前のカーレーサーが優勝したＦ１レースを観戦したときのものだ。その色は、カーレーサーがサーキットを全力で疾走させようと応援する色であり、それを着ている方も心が燃え立つ。

　また、巫女は長い髪を後頭部で巻き上げ、形も変えた。そのそばでメイキャップ担当者が、巫女に扮する女優の顔の化粧を直す。たった数分撮影するだけで、多くの人が動くものだ。映画館に足を運んでくれる人をうならせるには、それだけ周到な準備が必要となる。手持ちぶさたの男優の方はずっと簡単で、指で自分の髪の毛を整えていた。

　的の前の席にカーレーサーと巫女が座り、契約しているエキストラの観衆が二人を取り巻いた。主役を撮影するときは、他の的の近辺にいるエキストラにここまで移動してもらい、観衆の多さを印象付ける。ということは、あまりにも派手な服を着ているエキストラがいると目立ち、カメラを求めて移動していることが容易にわかる。これでは映画会社の算段が見破られてしまうが、幸いなことにエキストラのカラーシャツの色はよくあるもので、そこまで案じることは不要だった。

　明とあすかは的の対面から少し離れた一般市民に交じり、今か今かと馬を待った。的のスタート側の横には、矢が的に命中したかどうかを判定する審判員と、的を付け替える数人のスタッフが椅子に座って控えた。いずれも 直垂 ( ひたたれ ) の衣装を身に付けて黒い侍烏帽子を被り、 古 ( いにしえ ) の様子をそのまま再現している。

　審判員たちの横には、市民から選ばれた代表者が椅子にゆったりと腰かけ、眼前のエキストラの様子を見守った。その男は格式ある顔立ちをしており、渋いエビ茶色のスーツは高級品である。さしずめ人材派遣会社の社長といった風貌だ。映画制作に一役買って出た男は、矢が的に当たったときにエキストラがうまく場を盛り立ててくれるかどうかが心配の種だ。

　代表者の横に大きな木が立っており、そこにはロープが張られて見物者の接近を禁止している。名人の技といえ的の近辺は何かと危険性を 孕 ( はら ) むため、安全を期している。ただし、ロープのスタート側は見物客が立ち入ってよい。横から見る形となり的は見にくいが、男優と女優が目の前となるメリットはある。

　とうもろこしの毛が頂上に付いたような 綾藺笠 ( あやいかさ ) を被り、 重藤 ( しげふじ ) の弓を抱えた射手たちが入場した。装束は紫色、緑色、水色、藍色、黄色と個性豊かな家紋付きの狩衣装だ。 射籠手 ( いごて ) を左肩に掛け、袴を穿いて 行縢 ( むかばき ) と呼ばれる鹿などの革製の具足で腰から足先までを覆っている。これには毛が付いていて温かさそうだ。もっとも温かいのは下半身だけであるが。腰に付けた太刀の鞘にも革包が巻かれており、手には同じく革の手袋を、腰には尻尾のように矢を三本付けている。いずれの者も勇壮な馬上姿だ。

　馬の頭と腰に朱色の房が首に同じ朱色の馬飾りが掛けられてあり、いかにも晴れがましい。ダービーで優勝した馬は背中に馬飾りを付けてもらい、場内をかっぽする。そのような気分を馬に味わわせたい、というのが明の個人的な意見である。競馬をまるきり知らないあすかは、それを丸呑みした。

　これから行われる激しい行動の割には、射手も馬も冷静に歩いている。栗毛の馬も 葦毛 ( あしげ ) の馬もだ。ここで暴れると、本番で振り落とされる危険性が増し、矢を射るどころではない。こうして大人しくしていてくれれば、人間も心の準備が整うというものだ。

　映画ということで、始まる前の儀式は省略されて早速流鏑馬となる、と思いきや、不可欠のことがある。ウォーミングアップに相当する 素馳 ( すばせ ) である。これは馬に道を覚え込ませるため馬場を一度疾駆することで、ファンファーレが鳴る前にターフを試走する競馬の返し馬に似ている。

　馬場の東側に赤い大きな鳥居が立っていた。八幡宮の正面にある鳥居に匹敵する大きさがあり、その下に流鏑馬の団体の横断幕が張られた。そこをスタート場所として八幡宮の西の端まで駆けるということは、ちょうど本宮への広い参道と直角に走ることになる。

　素馳が終わり、一息付いたところで太鼓が鳴った。観衆の目がスタート地点に一斉に向けられ、射手と馬の名前が紹介された後、赤丸の付いた普通の二、三倍もある金色の大きさの扇が、馬場の始端と終端で振られた。これは両側とも準備万全という合図だ。脇に待機していた射手が馬を馬場に誘導し、ぱっと走りだしたかと思うと、すぐに第一の的となった。

　流鏑馬の馬は小走りだろう、と思い、あすかは軽視していた。なぜなら、馬に乗って操ることは大変、手綱から手を離すことは危険、ましてその状態で疾走することは大の危険だ。そのうえ矢に命中させるとなると、神業に近い。人前で腕を披露する際の失敗は恥辱になる、したがって、スピードを落として走る、というのがあすかの論理だ。

　また、あすかはこうも思った。両手を離して自転車に乗れる自分は、平衡感覚が良い方だし、学時代には弓道部に所属したこともあった。したがって、馬に乗って矢を射ることは何とかなるだろう。

　この考えも甘かった。かっぽかっぽというのんびりしたステップどころか、馬は鼻を下げて全速力で走る。スピードが遅い馬の二本の前脚と地面が作る形は、二等辺三角形に見え、後ろ脚についても同じだ。前脚同士、もしくは後ろ脚同士が重なって見えるということは、大地を蹴って跳び上がる走り方だ。何と二百メートルを二十秒で駆け抜ける速さだという。これはオリンピックの二百メートル競走のタイムに近く、あすかが両手を離して自転車を走らせる速度とは桁違いだ。矢を放つタイミングが一秒遅れると、十メートル進行方向に矢が飛ぶことになる。

　第一の的に命中した模様で、遠くで歓声が上がった。 喝采 ( かっさい ) に浮かれずに馬は走り続け、目の前に近づくと明とあすかの目がきりっと開いた。速い！度肝を抜かされたあすかが叫んだ。

「えっ！この速度で矢を射るの？」

　馬がザッ、ザッという鈍い音を立てて走る。普通馬の走りはパカパカという擬声語の表現を使うが、ここは砂が敷いてあるので重い音となる。軽い砂は馬の蹴り足で遠くへ飛ばされた。

　馬が直前まで達すると、ドタドタという地響きが起こった。スマートな現役のサラブレッドに対し、流鏑馬の馬はかなり太めだ。五百キロを優に越える体重の馬の走りは大地を揺れ動かし、地震が発生したように感じた者もいた。

　低い音に交じり、凄い速さで飛ぶ鏑矢の音が発する。その短い音はバシッという鋭い音に変化し、第二の的が落ちた。馬と矢のスピード、地響きと命中の音は迫力満点である。

　 注連縄 ( しめなわ ) によく付いている 紙垂 ( しで ) 、それもかなり大きい物を先に付けた 御幣 ( ごへい ) を審判員が上げ、命中を宣言した。射手の妙技にわーっという歓声と拍手が起こる。栄誉を授かった射手は、喜びに浸っていられない。すぐに第三の的が迫り、もたもたしていると矢を 番 ( つが ) える時間を失う。しばらくして拍手が聞こえたということは、第三の的にも当てた模様だ。

　落ちた的は付け替えられ、二番目の射手に操られた馬が走ってきた。この射手は第一の的をこなした後、残念なことに第二の的を外した。矢を番えるのに手間取り、慌てて放ったのだ。観衆から「あーあ！」という溜息が出る。撮り直しか？幸いなことに、ここまでがカメラの試し撮りだった。

　撮影状態が確かめられ、リハーサルが終了した。さあ、後は本番だ。フィルムに残るとなるといっそう緊張が高まり、それを意識して次の射手も馬も興奮していた。見る側も、じわっと手に汗が 滲 ( にじ ) んでくる。

　映画の撮影も迫力があった。カメラは的のスタート側の横に置かれ、高さが四メートルもあるクレーンの先端に取り付けられている。身を乗り出すカメラマンが落ちる、と心配するほどの高さだ。

　射手を乗せた馬がさっそうと駆けて来た。馬が遠くにいるうちは上から撮影し、近づくにつれてカメラの位置を下げる。ピントは矢に合わせ続け、矢を射るときにカメラは的も写す。地面すれすれまでカメラを下降させ、命中した的が落ちるところを、ローアングルで狙う。上下、左右、遠近の動きが連動する、三次元のダイナミックな撮影だ。

　次にカメラアングルが変更になり、地上に降ろされたカメラは的の真後ろに置かれた。ズームを望遠にして的、といっても裏側であるが、そこを中央に写し、他を隠すトリック撮影だ。カメラのファインダー内を菱形の的が占有する。ただし、最悪射手が的を外した場合のことを考慮し、カメラはレンズ以外の所を板で遮蔽し、カメラマンの前にも 盾 ( たて ) 代わりの板が配置された。

　近づいて来た馬が望遠レンズの視野外にあって見えない代わりに、大地を蹴る足音がしだいに大きくなるのをマイクロホンが捉える。その音が一番大きくなったときに矢が放たれ、的の上半分が落ちるとカメラマンが急いでレンズのズームを引く。視界が開けた広角レンズの被写界深度は深く、走り去る馬と 颯爽 ( さっそう ) とした射手、それと残った下半分の的にもピントは合っている。

　再度カメラは移動し、的の後方の横となった。道を挟んでカメラを向いている俳優の顔と、的の両方を写す。ファインダーの右上に的、左下に俳優を配し、二人が的を凝視する構図としている。何人かのエキストラの顔も入っており、どれもうまく命中して欲しい、と願っている顔だ。これは監督の指示であり、エキストラはリハーサルをさせられた。

　バチッと拍子木が鳴り、カメラが回ると巫女が強い調子で男に語りかけた。

「今週は流鏑馬。これも毎年八幡宮で見たでしょう？」

　男にとっては巫女の言葉が意味不明だ。

「やぶさめ･･････はちまんぐう」

「そう、流鏑馬。八幡宮よ」

　記憶を喪失した半醒半睡状態の男は、ただ周りに人が多いことだけが認識できた。そうだ、前にここに来たときも車を運転しているときも席はびっしり詰まっており、観衆は走る物に注目していた。男にはここの人たちとサーキットの大観衆が、重なって見えてきた。

　カーレーサーの男優は呟く。

「こんなにたくさんの人がいる。これはいったい何だろう？」

　蹄の音を立てて駆けて来る馬上で射手が矢を弓に 番 ( つが ) え、ぱっと放つ。空気を揺るがすピューという音を発した鏑矢が的に当たると、わーっと歓声が上がる。特にエキストラの反応は大げさだ。さもあろう、映画会社のスタッフが喝采を扇動し、市民の代表として見守っている松谷も、扇子を 煽 ( あお ) いで加勢した。その派手な賞賛を期待している映画のカメラが、熱狂する観衆の顔を捉える。

　メインスタンドを意気揚々と通った自分も、こんな歓声を浴びた。そのとき何の車に乗っていたのだろう？男が記憶をたぐり寄せると、サーキットを疾走する自分の姿がかすかに浮かんだ。

　射手を乗せた馬が近づいて来たとき、巫女が馬を指差して叫ぶ。

「馬が走ってる。あれはレーシングカーよ！あなたが運転してた車よ！」

　あの日のスピード感覚が鮮烈に蘇り、男は身を引き締める。

「速い！」

　男の変化を感じ取った巫女は、男の手を握って激励する。

「あなたは、もっと速く走れたのよ。轟音を立ててね。しかも、先頭をよ」

　射手の射た矢が的に命中し、パシッという音が響く。横にいる男の手首を掴んだ巫女が左右に振って拍手させると、巫女の手を借りた男は他の見物者と同様に命中を祝った。それにより、こういう動作も過去にした、という記憶がカーレーサーに少しずつ戻ってきた。

　次の射手も見事に的に矢を当て、的が落下する現象は男にはっきりと見えた。これも覚えのあることだった。目をパチクリさせた男は、初めて感動を口にした。

「当たった！･･････上手だ！」

　馬が疾走する音、矢が的を弾き飛ばす音、大歓声、これらは大きな刺激となった。男は目を見開き、両腕を回してハンドル操作の真似もする。脳裏に昔の記憶が次々にたぐり寄せられ、その脳の変化を男優は演技した。

　更に次の射手が駆けて来て的を射た。皆名人であり、ほとんど的を射落とす。緊張は最高に高まり、歓声がエスカレートすると、観衆の顔もカーレーサーの顔も紅潮した。厳しい目付きをしていた映画監督の顔だけが、満足したのか和らいでいる。

　最後の射手の際には、カーレーサーの記憶がだいぶ回復していた。この射手が射終わった瞬間、彼の記憶が完全に戻るシナリオになっている。その最大の山場を待ち構え、カメラは的を前景にしてアップ気味に男優と女優の顔をファインダーの枠に収めた。矢がカーレーサーの記憶の眠りを打ち砕くのだ。

　ここで男優は 台詞 ( せりふ ) 外の言葉を心の中で呟く。

「いよいよ記憶が完全に復活するクライマックスシーンだ。さあ、やったるで！」

　順調に撮影が進んだことで、女優は次の演技のことを考える。

「記憶が蘇った瞬間、カーレーサーを抱き締める演技、うまくやれるかな？」

　最後の馬の走り方も、これまでと同様に軽快だった。一つ目の的は綺麗に落ち、その場が拍手で盛り上がる。残るのは二つ、そのうちの一つはカーレーサーと巫女の前にある。

　誰もが容易に矢を命中させる、と予想し、気を緩めた。男優と女優だけが次の決定的な演技のことを頭に入れ、緊張している。その演技の発揮はもうすぐだ。

　しかし、ここで特殊な事態が起こった。的の後ろ、かつ、スタート地点よりの所で、閃光が発したのだ。そこは明とあすかがいる所と道を挟んだ位置であり、松谷の肩の上であった。ルール違反の見物客がフラッシュを 焚 ( た ) いたのか？いや、その場所は一般人の立ち入りが禁止されている。しかも、発光された光は、射手だけがよく見える鋭いビームになっていた。

　この 光芒 ( こうぼう ) に惑わされた射手が、早めに矢を放った。矢は速く、あっという間に松谷の喉に当たると、松谷は喉を押さえて座っている椅子から地面に倒れた。それを見た観衆の悲鳴が上がり、会場はどよめく。

　流鏑馬の 鏃 ( やじり ) は、 蕪 ( かぶら ) 状の木や角などに孔を空けた 鏑 ( かぶら ) である。矢を放つと鏑の孔に空気が入り込み、特有の音を発生することから、戦闘開始などの合図として用いられた。相手を殺傷する武器としての用途で作られている流星形の 鏃 ( やじり ) を持つ矢と違い、先端は円錐の底面部分である。一見安全な平坦部だったが、猛スピードで喉に当たったことにより、強烈なショックを受けた松谷は起き上がれず、手で喉を押さえたまま動きが止まった。これも映画のストーリーか？男の倒れ方といい、倒れた後の顔色の変化といい、あまりにも生々しい。これは物語を超えた痛ましい事件だ。

　歓喜していた観衆の顔が一斉に硬直して声が途絶え、計画外の場面となっては、観衆の動作を誘導するスタッフの手が止まる。カメラは 驚愕 ( きょうがく ) した表情の男優と女優の顔を写し、それを操作していたカメラマンは、突如起こった事態に驚きの顔を見せている。会場は騒然となり、勇壮な行事の撮影は中止、一瞬にして八幡宮の馬場は大パニックに陥った。

　倒れた男の後ろには人がいた。若い女だ。女は逃げるようにその場を去る。その女の姿を目にした明が叫んだ。

「あっ！あの女だ」

　明が女のいた方向を指差した。女は速い。代表者近くの大木の横に張ってあるロープを 潜 ( くぐ ) って観衆の中に 紛 ( まぎ ) れ込んだため、あすかには女が見えなかった。

「えっ！あの女って、どこの？」

　明は最初、まさか、と思ったが、確かに彼女だ。なぜなら、自分の視力は良い方だ。

「東慶寺で自殺しかかった女」

　明は不気味な予感がした。「一度あることは二度ある」という諺がある。またあの女が生命を左右することに関与しているのか？押し殺す口調であすかは心配して呟いた。

「彼女が殺人を？」

「もしかすると･･････」

　注目を浴びていた主人公への関心が一気に失われ、男優と女優はきょとんとしている。混乱した会場にざわめきが続くと、倒れた人間を見た女は両手で目を塞いで恐れ、野次馬根性のある男は、俺が推理する、とばかりに周囲に証拠を求めた。これも芝居の内と考えた一般市民は、やがて救急車とパトロールカーが到着したことによって突発的な事件とわかり、肩を 窄 ( すぼ ) めて 震撼 ( しんかん ) した。

　全ての的を射た後射手たちが舞殿に勢揃いし、意気揚々と勝ち 鬨 ( どき ) を揚げる、その列の前にカーレーサーと巫女が行って、記憶が戻ったお礼を言うシーンが組まれていた。誰が書き直したのか、死人を登場させる悲惨な事件にシナリオは 改竄 ( かいざん ) され、ヒーローとヒロインに用意されていた次の台詞も断たれた。カメラマンはカメラをアルミの箱に、メイキャッパーは筆をプラスチックのケースにしまう。

　 慄然 ( りつぜん ) としたエキストラたちは、家へ帰ろうか、それともここに留まろうか迷って右往左往している。その混沌とした会場へ警察官が近づき、尋問を始めた。映画の 台詞 ( せりふ ) が中止され、役目を降りた男優と女優も事情を尋ねられる一市民になった。映画監督、カメラマン、他のスタッフも、見たことを話すよう求められた。「射手は最初から被害者を狙っていたのではないか？」とか「馬が 躓 ( つまづ ) いて射手の姿勢が崩れたか？」とか「射手の顔色など、健康面の異常などなかったか？」とかいう質問に、誰も「いや、特に変なことはありませんでした」と答えるだけだ。これはみんなの目が的に集中していた結果であり、的の横に世話役として座っている人物に目を注いでいる者は、一人もいなかった。

　カメラが誤射した瞬間を捕らえている、と警察は期待したが、カメラは一台だけだ。固定されたカメラは的と俳優の顔に向き、早めに矢が放たれた位置は視野の外となっていた。有力な証拠も証人もなしという、警察にとっては落胆することだらけの奇想天外な事件だ。元気なのは、死者を病院に運ぶ救急車が発する音だけであった。

　誤解　

　射手が見事に的を射たときに拍手を力いっぱいしよう、と思って意気込んでいた明とあすかは失望し、警察による尋問の対象から外されたことで、すごすごとマンションに戻った。真っ昼間の中、両方とも部屋で意気消沈し、他の名所を見に行こうという気も、買い物をする気もまるっきし起こらない。これでは最初の日の若い二人と同じだ。

　夕方テレビの電源を入れると、臨時ニュースが流れた。空前絶後の事件ともなれば早いもので、第一報の取材に続いてより詳しい情報が伝えられた。代表者が喉を抑えて倒れる様子を、たまたま市民が自分のカメラを使用して捉えた生々しい写真も公開された。もしやあの女が写っているのではないか、と思い、明は目を凝らして映像を追ったものの、残念なことにあの場所で見た女が去った後のシーンだ。

　人が入り乱れた馬場の映像に重ねられた字幕を読み、明が不審な顔付きで呟く。

「『映画撮りの流鏑馬で誤謝　市民の代表死亡。射手の突如の発作か？』･･････このニュースは事故死扱いだな」

　この言い方では、明に不満あり、とあすかは見て取った。

「エキストラの世話役の死が、仕組まれた事件だと言うの？」

　明は射手の腕を百パーセント信用している。的を外すことはあるにせよ、人に当たる失敗などあり得ない。

「名人が射るんだ。そんなに的を大きく外すもんか」

「ニュースのとおり、突然発作が起きた、ということは？」

　走行していて運転手が心臓発作を起こし、バスが暴走したという事故を明は知っている。

「それはあり得る」

　夜になり、この日もあすかが夕食を作ってくれた。クッキングスクールに通っているだけのことはあり、あすかのメニューは豊富で腕は確かだ。今晩のあすかの料理もおいしく、明にとってはこれからが益々楽しみになる。

　せっかく快く見物した静の舞と流鏑馬の最後に、水を差された形だ。一日も早く事件が解明されることを願いつつ、気が沈んだ状態で手を動かして物を食べると、二人の興奮がいくらか収まった。睡眠と同様、食事は気を紛らわしてくれる特効薬だ。

　その後もニュースは、流鏑馬の事故の話題で持ち切りだ。何年も継続している伝統的な行事の最中に発生した奇異な事故となると、各局の報道番組全てが取り上げ、トーク番組も予定を変更して話題にする。その日の夜、明とあすかの目はずっとテレビの画面に釘付けにされた。

　十時少し前に、考えごとをしていた明が立ち上がった。

「ちょっと出かけてくる。コーヒーが切れたのでコンビニへ買いにね。すぐ戻るよ」

　男でも夜の外出は危険を 孕 ( はら ) むことからして、一晩くらい我慢をして明朝買いに行けばよいが、まあコーヒーを飲んで気が晴れるなら結構なことだ。そう考えたあすかは、優しく言葉をかけた。

「遅くならないで」

「勿論」

　明は何を思ってか、ダークグリーンのシャツに着替えた。今まで着ていた服が外出用とならばそのままで良いはずなのに、それをわざわざ自宅内でのみ通用する着古したよれよれのシャツにするとはおかしい。おかしいことはもう一つあった。買った物を入れるバッグを持参する、というあすかの予想に反し、明は空手のまま外出した。荷物は一つなので、直接手で持ってくるつもり、それとも、店で袋を貰うつもり、とここでも良い方にあすかは 忖度 ( そんたく ) する。

　もう十一時を過ぎた。あすかはようやく住み慣れた家の椅子に座り、大人しく待っていた。一人では尋ねても、返事が返ってこない。二人いるから会話が成り立つ、二人いるから楽しい。黙っていると、周りの壁から流鏑馬の矢が飛んで来る恐怖に駆られ、それが自分の喉に当たることを考えると、あすかはいっそう怖くなった。

「遅いな。早く帰って！」

　と天井を見てぽつんとあすかは呟く。

　夜がどんどん更けていき、それとともに憂愁に閉ざされるあすかに閉塞感が続く。明が暴漢に襲われてけがをし、救急車で病院に運ばれた、とあすかは悪い推測もする。それは杞憂で、コンビニにコーヒーが売り切れていて、明が別の店まで足を伸ばしている、と考え直す。鎌倉に何軒コンビニエンスストアがあるのだろう？二、三軒の店を探し回ったとしても遅すぎる。じっと待っているあすかに、いつしか焦燥が募った。

「行って既に一時間半にもなる。何してるんだろう？暗くて道に迷ったかな」

　 スリッパが新しい床を 擦 ( す ) るツーツーという音を出し、 自問自答するあすかは部屋の中で右往左往する。じっとしているより動いた方が気休めになる、と考えてのことだ。両腕を組んで何回か行き来する、止まる。また動く。そんな繰り返しが続く。

　すると、ピンポンというチャイム音が鳴り、泣きそうになったあすかの顔が元に戻った。玄関にすっ飛んで行き、テレビモニター付きのインターフォンで来訪者の顔を確認した後に、あすかはドアを開けた。そこに何食わぬ顔をした明が立っていた。ほっとしたあすかが、早速質問を浴びせる。

「お帰りなさい。ずいぶん遅かったのね。何してた？」

　明は左手でカップを持つ振りをして答えた。

「ごめん、ちょっと大学の知り合いと会ってね、一緒にお茶を飲んでたんだ」

　この部屋に固定電話は既に接続されたし、明は携帯電話を持っているので、途中で電話をかけて欲しかった。また、こんな時刻に開店している喫茶店があるのか、とあすかは疑った。それは過ぎたこと、友人と楽しく語らった余韻を残させてやろう、とあすかは配慮もし、優しく明を迎えた。

「あら、そうだったの。わたし、何かあったかと思って」

「ありがとう、心配してくれて」

　ドアを閉め、靴を脱いだ明は平然とした態度で部屋に向かった。両手を振って元気よく歩いているいつものその姿がこの場合異常であり、あすかの疑問が 猜疑心 ( さいぎしん ) に急変する。

「コーヒーなど何も持ってない。おかしいな」

　コーヒーは虚偽と思ったものの、それより先の詮索は無駄だ。誰かと喧嘩をしてきたとか、転んでけがをしたでは気が休まらない。何はともあれ、明が無事に帰って来て一安心だ。そう自分に言い聞かせたあすかは、心を鎮めて部屋に入った。

　あすかが準備していたお湯を使用し、明がコーヒーを立てた。このコーヒーは残っていた物だ。それを知っている明が買いに行ったことも、 闊達 ( かったつ ) な明にしては口数が少ないのも怪しい。まあここも我慢とあすかは考え、もやもやしてきた感情を無理やり包み込む。

　二人がコーヒーを飲もうとしたとき、白のジャンパーを着て青のジーンズを穿いた若い男が、明のマンションの玄関前に来てドアを激しく叩いた。

「開けろ！開けろ！」

　入り口にはちゃんとチャイムのボタンが付いているのに、いきなりドアを叩くとは無礼なやつだ。誰だろう、と思って、明が玄関に行き、インターフォンのテレビモニターで来訪者を確かめた。見知らぬ酔っぱらいがふざけてやっているなら「帰れ！」と怒鳴って閉じたままにするつもりだ。ドアの前に立っているのは知っている人物、直人だった。

　明はロックを外し、ドアを少し開けた。その瞬間に直人がドアを大きく開け、強引に中に入り込んだ。直人は挨拶などいっさい抜きで、いきなり左手で明の襟元を掴み、右手で明の顔を殴る構えをする。

「この野郎！」

　直人の言葉は荒々しく、憤慨した顔は真っ赤になっている。明は両手で直人の右手を押さえ、必死になって拳が下りるのを防ぐと、直人は明の手を押し返そうとする。若者の力は強い。直人が力を入れる度に、明の手がぐるぐると回った。

「何をするんだ？」

　と明が叫ぶ。争う異常な声を聞いたあすかも、玄関に来た。男同士が喧嘩をしている様子を見たあすかは驚いた。若い男は自殺しようとした女の恋人だ。その女を助けてやったわたしたちの所へ、何でまた殴り込んで来たのか？どうも今夜は不可解なことが多い。

　この男の奥さんらしき人が出て来たのは、好都合だ。直人は怒りを覚えた理由を荒々しくあすかに訴える。

「こいつ、俺の亜矢を寝取りやがった。東慶寺で助けたのは、それをしたいためだったんだ」

　これを言いたいために殴り込んできたのか。しかし、それはとんでもない思い過ごしだ。直人の手を押さえ、明はしきりに弁解する。

「違うんだってば」

　頭に血がのぼった直人は、尚も叫ぶ。

「違うもんか。俺がこの目で二人が寝ているのを見たんだ」

　あの女に関心がありそうな明の言動が多かったことを思い出したあすかは、胸騒ぎがした。「コーヒーを買う」と明は言って自分を欺き、女と密通するために外出したのだろう。それなら遅くなったことが肯ける。さては東慶寺で自殺を思い留まらせたのも、打算的な行為か？先ほどのあすかのもやもやがぶり返す。

　明は直人の肩に手を移し、落ち着くよう宥めた。興奮していた息が少し収まった直人を玄関の外に連れ出し、明はドアを閉めた。しばらく明が直人と話し合っている声が、ドアの狭い隙間からあすかの耳に入ったものの、明が説明している内容は厚い鉄でできている遮音効果の高い扉に阻まれ、あすかには不明だった。

　二、三分後、立て続けに話して息が切れた明が、玄関に入って来た。何とかこじれた事態を収拾でき、ほっとした表情である。外にいたもう一人の人物はどうした？あれだけ激しく怒っていた直人は、明に諭されて帰ったようだ。

　結婚式前の男は高価なプレセントをしたり、映画や食事に誘ったりして、何やかやと女のご機嫌を取るものだ。それが、ひとたびその女をものにすると、他の女に興味を示したがる。その浮気が家庭崩壊を起こす例はあまたある。

　結婚する前に切れると粗野な女に取られる、と危惧し、疑心暗鬼を生じているあすかは、これまで仏の顔を保っていた。その忍耐はもう限界だ。婚約している女が訪れている間に 姦通 ( かんつう ) するとは、明は何という恥知らずな男か。あすかは冷やかな声で言葉を連射する。

「明、あの 娘 ( こ ) と寝たのね？結婚式を挙げる前に浮気するなんて、最低。あなた、そういう人間だったの？ 見損 ( みそこ ) なった！」

　そこそこの年齢に達しているあすかが、十代の娘のように早とちりして亜矢を自分の恋人と決め付けてしまった。とんだ誤解だが、本当の恋人である直人に踏み込まれたのでは、弁解も効果が薄れる。はて、困った。いい迷惑とばかりに、明は手を横に何回も振った。

「違うよ、誤解だ」

　そう言って 白 ( しら ) を切るのが男だ。そんな芝居に 籠絡 ( ろうらく ) される軽薄な女とは違う、と自負するあすかは、額に 皺 ( しわ ) を作って迫る。嫉妬の弾み車は、回り始めると慣性が付く。

「言い訳は無用。寝取られた男が殴り込んでるんだから、これほど確かなことってある？」

　立ったまま、しかも相手が興奮している状態で入り組んだことを説明するのは、混乱の増長を招く。部屋に入って落ち着いたところで説明しよう、と明は考え、黙ってあすかを部屋に促した。その沈黙を、あの男が訴えたことを明が認めた、と見なしたあすかは泣きだす。クレバスから雫が一滴落ちるかのように、あすかの片方の目から涙がこぼれた。それなら半分の悲しみか、と思うのは明の早とちりというもの、すぐに反対の目からも涙が落ちる。

「ウワーン、ウワーン」

　ぽろぽろ涙を流して大声を上げるあすかは、明月院で泣いていた女の子みたいだ。いや、それよりもっと 凄 ( すご ) い。泣き顔を見て困りに困った明は、あすかの肩に手を掛けて言った。

「違うんだ、あすか。今、説明する」

　情事を発覚された男がしきりに弁解する行動は、映画やテレビドラマでよく演じられる。そんな言い逃れなど聞きたくないあすかは明の手を払い、来客用の部屋へ走って行った。荒々しくドアを開けた後、バタンという大きな音を立てて閉めたかと思うと、あすかはベッドの上の布団に 潜 ( もぐ ) り込んで頭まで布団をぱっと引き寄せ、顔を隠して泣き続けた。まるで設計を間違えて作られた歯車が、うまく噛み合えずに回っているような明とあすかのすれ違いだ。

　あすかの怒りは収束しそうもなく、この夜、二人は別々のベッドで寝ることになった。一人寝は寂しいものだ。せっかくリハーサルを始めた夜の部も、今夜は中断となった。それどころか、この中断は永久の中断になろうとしている。ベッドの上に座って溜息をつき、天井を見て明はぼやく。

「あの二人の心中騒ぎは俄雨だったが、こっちは雷付きの暴風雨だ。こりゃあえらいこっちゃ！」

　取り乱した心を鎮めたあすかが部屋から現れるのを期待し、明は一時間その場で待った。どうやら怒りは根深いらしく、あすかはずっと部屋に閉じ籠もっている。凝然としていた明は、きのうまであすかと一緒に使用した布団に一人で入った。今夜は人肌の温もりがお預けだ。あすにはあすかの怒りも収まる、と楽観視し、明は目を閉じた。

　明は眠ろうとしたが、あすかの怖い顔が浮かんで目が冴えてくる。いつも柔和なあすかがあんなに立腹するとはよほどのことで、離婚を強要する剣幕だった。目を閉じたり開けたりしていると、初日にあすかが言ったことが思い出された。

「『普段でないときはかかあ天下』と言ってたこと、ほんとだったんだ」

　恋の波乱とはこんなものか？女はあんなに敏感なものか？明は悶々として寝付きの悪い夜を過ごす。冗談が真実に変移することが、早くも実証された日であった。

　夢　

　明は夢を見た。庭の中央に太い木の柱が一本立っており、そこに人が縛り付けられている。これは他人事ではない。ぼろぼろになった衣服を着ている鎌倉時代の下級武士たる明が、悪事を働いた罪人となって刑罰を受けているのだ。そばの立て札には「この男、夫婦の契りをないがしろにし、他の女と密通したことによって、三日間 野 ( の ) 晒 ( ざら ) しの刑に処す」と印してある。これは明に言わせると 冤罪 ( えんざい ) だ。

　白い砂が敷き詰められた広い庭のいたる所に、一メートルの高さの木が何本も植えられていた。その木とは、 繚乱 ( りょうらん ) 真っ盛りの 紫陽花 ( あじさい ) である。紫陽花が砂の上に育つかどうか、夢の中の明は疑問を差し込むことはなく、ただ花の紫色と砂の白が装飾している鮮やかな庭に目を奪われた。

　明の頬の左右と頭の上に設置されているのは三枚の流鏑馬の的で、それほど顔に近い所に的があるとはなはだ危険である。熟達した者なら的をきちんと射る、では、未熟者が矢を射た場合は･･････体が萎縮した明は、 射手 ( いて ) が達人であって欲しい、と願った。

　狩衣装の射手が、明を正面に見て左側から馬を駆けて来た。八幡宮で見たとおりの疾走となると驚くほど速く、ザッ、ザッと砂を蹴ったかと思うと、あっという間に明のそばに寄って弓に鏑矢を 番 ( つが ) えた。思ったとおり、射手は的を狙っている、しかもあのときより馬場と的の距離が近い。明は顔を強張らせて叫ぶ。

「ウィリアム・テルじゃないぞ。危ない！よしてくれ」

　正面に達した射手が矢を放つと風を切る音が発し、すぐに明の右頬の横にある的を射るバシッという音に変わる。矢が命中して支柱を離れた的は、明の頬に当たった後に地面に落ち、明は痛そうに顔を反対側に向けた。

　次の射手も馬を駆けて来て弓に鏑矢を番え、右手をぱっと離す。至近距離での矢は極めて速く、瞬きをするより短い時間で明の左頬の横にある的を射た。的が明の頬に触れてから地面に落ちると、明は渋い顔を作った。

　残りの的は頭の上にある。次の射手が馬を駆けて来たときも、同じことが起こった。真っ二つに割れた的の半分は地面に落ち、半分は明の頭に留まった。罪人にされたうえ、ピエロにもされて腹が立つ明は叫ぶ。

「邪魔な板っ切れめ！」

　三枚の的が見事に射落とされたのでこれで終わり、刑は脅かすだけで命は保たれた、と明は思ったが、もう一人の射手が残っていた。その射手は両手で手綱を掴んで駆けて来て、明の柱の前でぴたりと静止した。その位置で射手が矢を番えて弓の 弦 ( つる ) を引き絞ると、キリキリ、キリキリと音を立てて弓は反り、弦は射手の胸の方に引き寄せられた。反った円弧状の弓と細い弦が作る鋭角が、著しい緊張を示している。的はもうない、何を狙うのか？

　明は射手の顔を見た。何とこの馬上の射手は、狩衣姿になったあすかだ。恨みを晴らそうとするあすかが持っている物は、鋭い 鏃 ( やじり ) の付いた本物の矢である。女の 怨念 ( おんねん ) とは恐ろしいものだ。

　顔を上げて明が叫喚する。

「あすか、違うんだ！間違いなんだ！」

　叫んだことによって頭が下がり、載っていた板切れが下に落ちた。邪魔物がなくなったことで明はピエロの役を降りたが、安心するのはまだ早い。喜劇の代わりに悲劇が残っている。

「あすかの腕では、矢がどこに飛ぶかわからない。よしてくれ！」

　失礼な。罪を犯したうえ、こちらの腕をけなしている。明の言い訳を無視するあすかは、尚も弦を絞って言い返す。

「うるさい！裏切り者、覚悟！」

　自分が的となっていることを知った明の語調は高まる。

「待ってくれ！」

　嘆願は無視され、あすかが放った糾弾の矢は、音を立てて宙を水平に飛んだ。所詮素人の弓、的を外すに決まっている、と明は 蔑 ( さげす ) む。それは馬が疾走している場合のことだ。あすかは弓道をやっていた。この距離で、しかも静止した馬の上から射る矢は正確で、理想の直線軌道を描いて矢は明の喉に突き刺さった。しかも、ど真ん中だ。

「ヒュウヒュウー、ヒュウヒュウー･･････ヒュウヒュウー、ヒュウヒュウ ー･･････」

　喉を刺された明が必死に叫ぶと、風が吹くような息が漏れる音は、苦しい、という意味なのか、許して、という詫びなのか、聞く者には理解しがたく、ただ奇妙な音として続いた。その音もしだいに弱くなり、十秒もするうちに力が尽きた明は、がっくりと首を前に倒した。

　明月院で眺めた紫陽花の薄紫色は綺麗の一語、それに対し、明の喉から流出する血は黒っぽい不気味な紫色だ。赤いのが相場の血は、罪人の体の中では 汚 ( よご ) れた色となるのか？その血が敷き詰められた白い砂を 汚 ( けが ) していく。

　人間の体内にある血液の量は高々数リットルであり、明の足元に水溜りを作った時点で止まってよいはずだ。この場では血が果てどもなく吹き出て、庭の砂を覆い尽した。潔白な砂全体が淀んだ色に染められると、血は庭に堆積し始め、やがて 茫洋 ( ぼうよう ) とした庭が大きな沼と化す。

　明の体は汚泥の沼に沈み、首より上だけが水面上にぽつんと残った。この奇妙な光景は、見せしめのために 梟首 ( きょうしゅ ) されている様を思わせる。自分の血を全て放出した明は最後に息を引き取り、その顔にある恐怖に 戦 ( おのの ) いて 歪 ( ゆが ) んだ唇、青白くなった頬が痛ましい。明の死とともに周りの紫陽花もしなだれ、全て枯死するという事態になった。

　してやったり。 鬱憤 ( うっぷん ) を晴らしたあすかはほくそ笑み、一鞭入れて右方向の殺風景な草原へと馬を駆った。血の沼を馬が走れるであろうか？不思議なことに、あすかが操る馬は、沼の水面を地面代わりにして疾走した。

「むっ！」

　うなされながら眠っていると、九時近くにやっと明は起きた。ここは命を奪われた庭か、それとも地獄の底まで落ちたか？入居したばかりでも、横のカーテンが自分の家の物であることはわかる。となると、矢による傷は？即座に明は喉に手をやった。痛みはなく、出血もしていない。

「生きてる！」

　あすかの殺意は夢想だった。 酷 ( ひど ) い死に方の夢を見るとは、自分はこれまで悪事ばかりやっていてその天罰が下りたのであろうか？いや、自分は研究一筋の講師、他人の財産を奪ったり、生命を脅かしたりしたことは一度もない。情緒が不安定なときだったから、この夢となったのだ。そう明は弁解した。

　ほっとした明には気がかりなことがある。ぱっと起き上がった明は、パジャマ姿のままあすかの寝ている部屋の前に恐る恐る忍んで行き、いきなり開けると気分を害することだろう、と配慮しつつ、トントンと静かにドアを叩いた。

「あすか、おはよう。もう朝だ、起きて！」

　部屋の中では静寂が続いている。

「あすか、まだ寝てるの？」

　ドアをそっと開けて入った明は、あすかの顔が気になる。矢を射た鬼夜叉顔のあすかか、それとも機嫌を直した菩薩顔のあすかか、どちらだろう？それによって話しかける言葉を選ぶ必要がある。

「あれ、どこへ行ったんだ？」

　ベッドの上の布団は、頭の側から足の側まで真っ平らだった。部屋の周りを見渡すと、ベッドの横にあるワゴンの上にメモが置いてあるのを明は発見した。ぱっと手に取り、 暗澹 ( あんたん ) とした気持ちで明は読む。それはたった二行の短い文章であった。あすかとは何度も恋文を交わしており、これは確かにあすかの筆跡だ。

「『あなたとは縁を切ります。わたしの思い出など、雨に当てて消し去ってください。　　さようなら　あすか』･･････何だこりゃあ！最悪だ。･･････どうしよう？･･････こんなときの対応って、歴史の本に、むー、書いてあったかな？」

　文面を解読すると、復讐劇を予感させる文章だ。賢明なあすかの頭に血がのぼり、この家に放火したりナイフで自分を殺傷したりするのか？だが、それはあまりにもドラスチックだ。「さようなら」と書いてある、ということは、この地を離脱するつもりだ。ならば、復讐は除外してよい、と明は推量する。

　窮地に陥った者が、理性を失って自殺することはよくある。あの若い女だってそうだった。これは十分考えられる。直近の前例を思い起こした明は、早く行って止めねば、と思った。

　家の外を探すのに、この格好はおかしい。おどおどしている明はパジャマを脱ぎ、抹茶色のシャツに着替えた。慌てているので、シャツのボタンを一段ずれた穴に入れてしまう。それを直して再度メモを手にし、他の手がかりを発見するべく読み返した。

　あたふたとしていると、チャイム音が鳴った。この家を知っている者はまだ数人だ。納得して帰った直人は外してよいし、引っ越しを手伝った友人たちが今来るとは思えない。そうか、朝の散歩をしたあすかが戻って来た、と思い、明は玄関に行ってインターフォンのテレビモニターを見た。女がいたが、あすかではない。ドアを開けると知っている人物、実際自殺しかけた女が目の前に現れた。

「亜矢さんか。朝からいったいどうしたの？」

　スカイブルーの長袖シャツを着ている亜矢は、ぺこっと頭を下げた。

「全てわたしがしたことなのに、昨夜は直人が勘違いして怒鳴り込み、すみませんでした」

　亜矢は直人にこの場所を聞き、始業前にわざわざ謝罪に来たようだ。繊細で感情の起伏が大きい娘だが、心配りができる娘だ、と思う明が、亜矢の肩に手を掛けて安心させる。

「すぐにわかってもらえたのでいいよ。･･････でも」

　明の最後の言葉が気になる亜矢は、推量してみた。

「奥さんのことですか？」

　手を繋いで散策していた女性は、恋人と見なせる。夜マンションにいる女は、更にその上をいっているのだろう。第三者の亜矢は、あすかを明の妻と見なしたようだ。それは正しくもあり、間違いでもある。フライングしている明は、こそばゆくなった。

「実は、フィアンセなんだ」

　フィアンセはまあ夫婦の一種だ。その間柄の人との喧嘩話を差し控えようとしている明さんは、慶寺で自分たちを助けた大人らしい態度とほど遠く、どう見ても、愛する人に逃げられて苦慮している様子だ。明の深刻な顔は亜矢に読み取られた。

　直人がこの家に怒鳴り込んだことにより、この人のフィアンセは自分との関係を知ったことだろう。それが原因で二人の間に亀裂が生じている、と憂慮する亜矢がそっと尋ねた。

「直人のことで何か困ったことでも？」

「別に･･････」

　この答えに「困ったことがある」と亜矢は解釈した。それを示すものが明の持っている紙に書いてあると推測し、亜矢はしきりに明の手の先を見た。心配そうにメモを見ている亜矢に、明は渋々白状する。

「ちょっとこれがね」

　やはり二人に深刻な 軋轢 ( あつれき ) が生じている。明が渋々見せてくれた文章を読んだ亜矢は、また頭を下げた。今度は頭の位置が前より低い。

「わたしのためにこんなことに･･････ごめんなさい」

　 苦々 ( にがにが ) しい顔をして明は考える。

「一時的な噴火と思うけど･･････いったいどこへ行ったんだろう？」

　家を逃げ出すとしたら･･････第一の候補はあすかの実家だ。それはおかしい。家に帰るときは、大きなバッグを持って行くだろう。それは残っている。では何か？この難しい問題には前例があった、それも、もっとも身近なところに。自分に照らし合わせた亜矢は俄かに閃いた。

「〝縁を切ります〟と書いてある。･･････あっ！もしかして、あのお寺へ」

　これは良い発想だ。策に窮していた明は思い当たった。何しろ自分があすかに講釈した寺なのだ。

「えっ！東慶寺。縁切り寺だからか。よーっし！行ってみよう」

　そうか、東慶寺で気持ちの整理をした後に荷物を取りに来て、家に帰ろうというのか。亜矢さんはそこによく気が付いたものだ。せっかく婚約したのだ、縁を切られる前に止めねば、と明は思う。

　責任を感じている亜矢が提案する。

「わたしも行かせてください」

　婚約者者間のもめごとに他人、それも若い娘を巻き込むのはどうかと思うが、ここは証人が必要とならば明は了承だ。

「いいよ、一緒に行こう」

　これからが慌ただしくなる。明は洋服タンスからアンバー色のブレザーを出して着た。サイフをポケットに入れて部屋の照明を消し、玄関のドアに鍵を掛けて二人はマンションを離れた。

　さて、あの寺へどうやって行こう？小さい幸運が二人にあった。広い道路に足を踏み出した明が手を上げて通りすがりのタクシーを呼ぶと、タクシーは即座に止まってくれた。自動ドアが開くや否や亜矢を後部座席の奥に入れ、明はその横に並んだ。

　この日の朝、空が分厚い黒雲に覆われていた。走っていると雨が降り始め、邪魔者を払おうとしてワイパーが 忙 ( せわ ) しく首を振る。 梅雨 ( つゆ ) の中休みが終わり、雨の季節の再来となったのだ。慌てて家を出た明は、傘を持っていない。

「やばい！雨だ」

　と呟いて、明はタクシーのガラス窓を通して空を見た。おそらくあすかも手ぶらで出たことだろう。突っ立っていたり歩いたりしていてはびしょ濡れになるので、あすかが寺の軒下で雨宿りをしていることを明は願う。

　同義的に不実な者、端的に言えば浮気者の明にもう用はない。恥辱を受けたあすかは、意識が 朦朧 ( もうろう ) としたまま東慶寺の中を歩いた。しだいに雨が強くなると、白い薄地の長袖シャツのあすかは呆然と立ったままとなる。この雨は 鋲 ( びょう ) のつぶて、灰色の空は虚無だ。所詮逃げてきた身、どうにでもなって、という破れかぶれの心境にあすかは陥っている。どうやれば縁が切れるのか、それを考えるのもおっくうである。

　力の抜けた両腕を垂らし、 憔悴 ( しょうすい ) しきった顔で空を見上げているあすかの頬に水滴がこぼれてきた。空から 滴 ( したた ) る雨に見える水滴は、あすかが落とした雨、あすかの涙である。悲しみの涙は生理的には温かく、精神的には冷たいものだ。あすかの涙は凝固し、頬に一筋の氷河ができている。

「この雨はやがて 雹 ( ひょう ) に代わり、これまでの甘い思い出を全て真っ白に塗り潰す」

　雨足はいっそう激しくなり、視界が四、五メートルまで短縮された。こうなると、どこにいるのかさえわからない。全身びしょ濡れとなったあすかは、滝に打たれた修行者の様子で立ちすくんだ。二年間の甘い思い出も、昨夜の失望した出来事も、この雨によって流してもらいたい、とあすかは願う。

　明と亜矢が東慶寺の前に着き、拝観料を払って中に入った。まずは門のあたりを探すものの、この時刻、この雨では人影がなく、閑散としている。それならば、左右の幅が狭い境内をただ奥へ向かって進めばよい。先へ歩いて行くと、放心状態のあすかが穏やかな 金仏 ( かなぶつ ) の前にいるのを二人は探し当てた。

　走り寄った明はあすかの手を取り、優しく尋ねた。

「あすか、急に飛び出して、どうした？」

　当然のことであるが、明にとって不測のことが起こった。若い美女と一緒にいる 不埒千万 ( ふらちせんばん ) の明を見たあすかは、明が猛省するどころか根底から愛を崩壊させた、と悟った。独り静かに煩悶していたあすかの顔が急に険しくなり、軽蔑の目で明に怒鳴る。

「今度はわたしの目の前に、好きな女を見せ付けに来たの？あんたはいったいどういう考え？」

　「ここまで迎えに来てくれたのね、ありがとう！」という言葉を明は期待していた。甘かった。怒りが絶頂に達したあすかの表現は 辛辣 ( しんらつ ) で、予想とまるで反対だ。二人の間の溝がいっそう深まり、明ははたと困った。

　険悪な状態を察した亜矢は、手を組んで必死に訴える。

「あすかさん、誤解です。わたし、明さんとのいかがわしい関係などありません」

　あすかは悔しげに亜矢を睨んで反論する。

「あなたの彼氏が直接訴えたのよ。それでも『違う』って言い張るの？」

　同じ思い込みをした人から実情を聞いている亜矢の言い方は、真実味を帯びている。

「明さんが説明してくれ、直人は納得しました。ほんとに何もなかったんです」

　亜矢の真剣な顔付きは、明の言ったことが正しいことを示していた。半分信用しかかったあすかは、半分疑惑のまま上目使いで亜矢を見た。

「そんなに簡単に『はいそうでしたか』なんて言える？」

　この女の恨みは根深い、と判断した亜矢は、覚悟を決めて提案する。

「じゃあ、こうしてください」

　絶望して力が抜けているあすかの両手を掴み、亜矢は自分の首に持っていった。これは極めて特殊なポーズだ。相手の手が自分の首を締める行為は、霊玉にマインドコントロールを受けた影響である。あすかの手の平が締まる方向に亜矢が力を入れると、亜矢の首に雨で濡れた他人の手が食い込んできた。

　ボタボタ、ジャージャーという音を立てる雨の降り方が、いっそう顕著になった。その雨は大地を湿らせ、華奢な二人の女の体にも襲いかかる。びしょびしょに濡れた二人の着ている長袖のシャツは体に密着し、まるでぴったりの潜水服を着ているようで、両者とも胸や腕の女性らしい柔らかいラインがよくわかる。

　身を引き締めて亜矢が迫まる。

「まだ疑っているのなら、その手でわたしを絞め殺してください。どうせ一度死のう、と思ったんです。未練はありません」

　特殊な自殺に驚いた明は、額を流れる雨粒を手で拭って叫ぶ。

「亜矢さん！」

　手が塞がっているあすかは、額から頬に流れ落ちる雨粒にお構いなしだ。ずっとここにいるあすかの髪は地肌に吸い付き、頬から雫が落ちている。一方の亜矢も手に力を入れており、付着した雨粒を拭えない。強く瞬きして目に入った雨粒を追い出し、亜矢は尚も訴える。

「わたしが死んだら、また明さんを愛してやってください」

　亜矢の手の力は滅法強く、あすかの手が締まることで亜矢の首が圧迫される。亜矢が更に力を入れると、あすかの指が亜矢の首に深く食い込む。まるで霊玉の魔力が、亜矢に乗り移った格好だ。

　明が異常な行動を阻止するべく近寄ると、亜矢は明から離れる。明が亜矢を追う、また亜矢は離れる。ちょうどあすかの周囲を回転するかのように逃げ回るため、明は亜矢の素早い移動に翻弄された。

　苦しければ力が弱まり、手を緩めるのが普通だが、血の気を失った亜矢は尚もあすかの手を締め続ける。こんな自殺があるだろうか？事情を知らない雨は降り続き、二人を水浸しにする。

　女には女だけに与えられた使命というものがあり、この女はそれを断とうとしている。婚約者を奪った憎い女が死ねば良い、と切望したあすかだが、亜矢の手を解き、女の使命を伝える。

「亜矢さん、もうやめて！女は新しい生命を生み出すもの、人の命を奪うものとは違うのよ」

　亜矢がもう一度瞬きをした後、あすかをしっかりと見ると、きりっと結んでいたあすかの唇は緩んでいる。凍ったあすかの唇を、雨が融かしてくれたのか？あすかの手を離した亜矢はほっとした。

「わかってもらえましたか？」

　一生を共にする人を取られた、と思い、あすかは理性を欠いていた。黙って飛び出したことも、この女を憎んだことも愚劣な行為だった。早とちりを認めたあすかは、恥ずかしげに軽く頭を下げた。

「明、亜矢さん、ごめんなさい。わたしの思い違いね」

　一時は、破滅へ向かっている、と明は憂慮した。婚約は解消、結婚式場へはキャンセルの通知、準備中の招待状は白紙、それどころか、ローンを組んで購入した新居に住む意味がない。愛の破綻を回避できた明は、あすかを慰めにかかる。

「わかればいいんだ。さあ、家に戻ろう」

　幸せの絶頂にいる二人の仲が、自分のことで壊れては責任重大だ。どうやらフィアンセの疑いが収まり、亜矢もほっとした。相手がカップルとなると、若者の亜矢にも配慮する心がある。冷静になった亜矢は、二人の邪魔をするのもこれまでと考えた。

「じゃあわたしはあの家に。何か情報が入ったときには、お知らせします」

　自殺する弱気の性格がある反面、気丈な点もある娘だ。切れたあすかを説得し、更に情報を提供してくれるとは凄い。非行に走り、さ迷っているそこらの家出娘とは違うらしい。となると、何か訳があったのだろう。これまで亜矢を無節操な若者という偏見を持っていた明は、同情的な立場に変わった。

　その女から情報を貰えることは良いとして、それが災いを招くことを案じる明が優しく忠告する。

「危ないこと、しちゃあだめだよ。慎重にね」

　悲愴感が薄れ、やっと笑顔になった亜矢はしっかりと約束する。

「はい、わかりました」

　濡れた体を早く乾かす必要がある。それも三人ともだ。風邪をひくのを恐れる明は、亜矢を誘う。

「一緒にタクシーで帰ろう」

　あすかと仲直りした亜矢は、遠慮も導き出せる。

「若いので走って帰ります。失礼します」

　濡れた肩をクロスにした腕で押さえ、亜矢は勝の家に帰って行った。雨を防ぐ傘も雨を拭き取るタオルも持っていない亜矢は、ただひたすら走る。相変わらず雨の攻撃を受けたが、気分的にはまるで違う。あすかの誤解を解消でき、寒いという亜矢の感覚は和らいだ。

　明と亜矢との間に起こったことが不明のあすかは、こっそり尋ねる。

「何かあるの、あの家？」

　あすかにそのことを早く説明するべきだが、それよりもっと優先することがある。明は濡れたあすかの顔をハンカチで拭いて諭す。

「風邪をひくとまずいので、早く帰ろう。説明は家でする」

　真実を早く知りたい、と思ったあすかは、長い間風雨に 曝 ( さら ) されて冷たさを感じており、明の提案した順序を了承した。

　二人は足早に雨に煙る東慶寺を去った。水の衣を羽織った金仏は、東慶寺での縁切りが再度回避されたことを喜び、三人を送り届けた後も定位置に残っていた。自分の存在がいくらか寄与できた、と自負する気持ちを抑制した慎み深い表情をして。

　北鎌倉駅まで歩き、そこで二人はタクシーに乗った。その前にちょっとした買い物をする。座席シートを濡らすのは迷惑と気を遣い、駅の近くでビニール製のポータブル雨合羽を手に入れて羽織った。それを着た奇妙な客にまごついたタクシーの運転手は二人の配慮とわかり、快く行き先まで乗せて行った。

　回想　探索　

　マンションに戻った二人は早速シャワーを浴び、下着や服を着替えた。雨に濡れることは想定外であり、宅配便で届いたあすかの着替えの服は限られている。また、洗濯した服は乾燥中のため、あすかはしばらく明の衣服を借りることにし、ターコイズブルーのシャツを着て上に黄土色の薄手のジャンパーを羽織ることになる。これでは、再度引っ越しをする格好だ。

　若竹色のシャツに着替えた明が、湿っているあすかの髪を梳くうように指で持ち上げ、パワーのあるドライヤーで熱い風を送る。モーターの回るグォーという低い音、ビーという羽根の回る音、ザーという風を送る音、その風があすかの髪の毛に当たるサーという音、この四種類の音がする。そこが乾くと別の所を持ち上げ、明は風を当てる。こうして甘えられる明なら、何か深い訳があった、と思い、あすかも直人同様、歩み寄る気になった。

　ドライヤーを振る明が説明を始める。

「どうも問屋の様子がおかしいんだ。それで、調べてみたくなり、昨夜忍び込んだ」

「『コーヒーを買いに行く』と言って、外出したのね」

　ばれたからには素直に謝るのが手だ。

「嘘言ってごめん」

　 両方の人差し指を頭の上に突き出し、あすかは鬼の 角 ( つの ) を作った 。

「『亜矢さんの所へ行く』と言うと、わたしがこうなるからでしょう？」

　この言い方は冗談交じりなのか、まだ怒っているのか、明は判断に迷う。それが冗談だとして「うちの鬼は天下一品だ」とか言って冗談で返すと、また、あすかの噴火が予想される。おそらくそれはポンペイを埋め尽くしたベスビオ火山の爆発に匹敵することだろう。あすかが以前の比類なき堅物に戻っている、と明は思い、やんわりと本心を呟いた。

「ご正解。あすかがさっきの顔になると、怖いもの」

　誠実な明に限って、浮気などするはずがない。心配をかけさせないための明の嘘は、許せる悪事である、と考えたあすかは、昨夜から 今朝 ( けさ ) にかけて怒りを爆発させた顔を、借りてきた猫のような穏当なお嬢ちゃまの顔に変えた。他愛ないことで 下司 ( げす ) の勘ぐりをし、悪態を曝け出したうえ婚約を解消する気にまでなったことが恥ずかしい。ここは素直にあすかが言った。

「ごめん」

　曲解していたあすかを宥めることに成功した明は、話を続ける。

　三日月が空に見える夜だった。犬の遠吠えが小さく聞こえる以外、この辺は静かだ。その静けさの空気をかすかに破る足音を立てて明は家に近づく。一歩、二歩、更に一歩、二歩。出入りが途絶えた問屋の裏門に、人目を 憚 ( はばか ) る明が辿り着いた。わざわざ暗い色のシャツに着替えたのは、夜陰に乗じて忍び込むためだ。

　裏門には鍵が掛けられている。違法行為はこの際勘弁してもらい、敏活な明はすばやく横にある塀に手を掛けてよじ登った。敷地内を確認し、地面に跳び下りる。無意識に下りると、ドタッという異常な音がして発見される恐れがあるので、膝を柔らかく使い、小さい音で済ませる。

「さて、どうしよう？」

　明は周りを見渡す。左奥は裏庭だ。右奥に灯りが点灯している部屋が見えたので、取りあえずその窓の下へ行ってみる。目だけを窓に近づけ、中を 覗 ( のぞ ) くと亜矢がいた。

「すぐに見つかって良かった」

　窓ガラスを爪で軽く叩くカツカツという小さい音を聞いた亜矢が、明を見るなり裏口へ回った。ロックを回して戸を開け、明を家の中に 入 ( い ) れる。就寝前の亜矢は辞めた従業員が使用していたパジャマを着ており、アンマッチに見えるそのダブダブの服が、たおやかな亜矢の体を包んでいる。

　靴を脱いで亜矢の部屋まで行った明が、ひそひそと亜矢に話す。

「夜遅くごめん。ちょっと調べてみたくなって」

　他人の家を探索することは、刑事か探偵の仕事だ。相手に発見されずに行動し、去るときは形跡を残さないなど、特殊な能力を必要とする。この男にその能力があるかどうかは不確かだが、最悪のことを想定する亜矢が小さい声で提案する。

「十分注意してください。もし危険を感じた場合は、どうぞここへ」

「了解。･･････彼氏はどうした？」

「コンビニへ夜食を買いに行ってます」

「そうか、じゃあ探してみる」

「家の構成はこうです」

　店舗、応接室、勝の執務室、経理の事務を行う部屋、勝と定子の寝室、従業員の寝室、食堂、台所など、こと細かに亜矢が家の構成を説明してくれた。そして、最後に重要なことも。

「倉庫の鍵は裏口の壁にある箱に入っています」

　五里霧中の中での闇雲の探索は効率が悪いので、この情報に喜んだ明は早速部屋を探索しにかかった。亜矢の与えてくれた知識が功を奏し、人がいる危険な部屋に入ることは避けられた。また、従業員全員が眠っていて、心にゆとりがあった。

　廊下に不審の物があるかどうかも調べた。整理整頓されている家の中には、疑った密輸品らしき物や、海草が付着した箱も置かれていなかった。必ずあるはず、と思う明はしばらく注意深く探し回ったものの、普通の家であることが強まるばかりだ。

　今度は教えてもらった裏口の壁に付いた箱の中の鍵を手にし、庭にある倉庫らしき建物へ明は行った。倉庫なら少なくとも物はある、怪しむべきはその中の物だ。古風な錠に鍵を入れて戸を開け、中に入ると入り口の壁にある照明のスイッチを押した。はっきり見えた倉庫の中には、ダンボールの箱が多く積み重ねられている。明はすぐさま上の箱を下ろし、先端が溝に差込まれる方式の蓋を開けて中を 覗 ( のぞ ) いた。そこには頼朝、義経などの人形の土産品が入っていた。下の箱の中も見た。小型の兜や鶴岡八幡宮の模型だ。更に隣の段を調べてみた。

「むー、どれもまともな物だ」

　当てが外れた明は両腕を組み、頭を抱えた。部屋の隅にある箱も同様な印刷があることからして、似たような物だろう。念のため調べてみたいが、あまり長い時間探すのは危険、ここで区切りを付けるのが無難だ。

　明は開けた箱の状態を元に戻すと照明を消し、周りを気にしながら倉庫の鍵を掛ける。忍び足で母屋に戻るや裏口からそっと入り、鍵を元の箱に戻す。そこに心配する亜矢が立っていた。

「何も発見できなかった。きょうはこれで帰るので、裏口のロックを掛けて」

「はい、気を付けて戻ってください」

　明が外に出たのを確認した亜矢は、裏口の戸を閉めてロックを回そうとした。そのとき裏門に近づいて来る足音が明の耳に入った。

「誰か来た！」

　と呟いた明は戸を開け、家屋の中に戻った。亜矢は急いで戸を閉めてロックを掛け、明を自分の部屋に連れて行った。その間にも周りに人がいないことを亜矢は確かめる。部屋に戻った亜矢は慌てて押入の中の布団を出して敷き、そこに 潜 ( もぐ ) り込んだ。そして、布団から腕を出し、明を手招きする。

「さあ、ここに入って」

　布団の中に体を入れて障子戸と反対の方向を向いた明は、首の上まで布団を被せ、頭の一部だけを 覗 ( のぞ ) かせている。その明の胸を亜矢は両手で抱き締め、頬もぴったりと寄せた。

　得意先である店の主人と居酒屋で酒を酌み交わして酔っぱらった磯部が、爪楊枝を口にくわえて裏門の前に来た。よほどご機嫌なのか、鼻歌交じりでよろめきながらである。夜空を見上げての歩きは酔い醒ましに効果がある、と期待したものの、酔いが深いせいで磯部はまだ赤い顔だ。顔が真っ赤なら着ているシャツも真っ赤で、これは磯部のトレードマークだ。

　どこにも自由に入れるよう全ての鍵を持ち歩いている磯部は、ジャラジャラと音を立てて鍵を選び出した。裏門の錠に鍵を差し込んで開け、その後閉める。慣れていることなので、酔っていても戸締りはしっかりでき、庭を通った後、磯部は母屋の裏口の錠も開けて家の中に入った。酔っていたことと、明が自分の靴を従業員たちの靴の間に紛れ込ませたため、不審な物が置かれてあることに磯部の頭は回らない。

　裏口の戸が閉まる音を聞いた磯部は、そこに近い部屋は直人と亜矢の寝室であることを思い出した。こんな夜だ、不審な人物はいないだろうが、一応確かめる必要がある、それも番頭の務めだ。廊下を歩き、亜矢の部屋の前に行って障子越しに磯部が声をかけた。

「音がしたな。誰かいるのか？」

　どうやら見つかったようだ。入り込まれた場合、一巻の終わりとなる明は、背筋が寒くなった。こうなると、亜矢がどう答えるかで運命が決まる。

　焦った亜矢も考えた。一緒に寝ている者が直人でないと知られたら、明さんも自分も、それに直人までが破滅状態になる。そこで亜矢は機転を利かせ、甘ったるい声で怒鳴った。

「今、直人といいところなの。あっちへ行ってて！」

　愛し合う者たちの情交シーンを 覗 ( のぞ ) くのは野暮な行為としても「念には念を入れよ」という教訓がある。戸を少し開け、亜矢の顔と布団からはみ出ている明の後ろ頭の一部を磯部は見た。常夜灯だけが点灯している部屋は薄暗いため、酔っている磯部は細かな点を見過ごしてしまい、亜矢と抱き合っている男は直人と取る。にやにやして磯部が言った。

「それは仲のいいことで。じゃあ、お休み」

　羨ましい表情をした磯部は戸を閉め、その場を去った。酔ってよたよたしている足取りは遅く、パタパタと間隔の長い足音は聞いているといらいらしてくる。早く自分の部屋に行って、とばかりに亜矢は手を押し出した。一分ほどたつと、磯部が自分の部屋に戻ったのでやっと足音が止まり、明の胸を巻いていた亜矢は恥じらいを見せて腕を解いた。

「危なかった。もう大丈夫です」

　亜矢をじっと見て、明は横になったまま顎を引いた。

「助けてくれてありがとう」

「見つからなくて良かったです」

　明には問屋の荷物の他に、大いに気になっていることがある。それを聞きたいがために危険を冒してここに来た。これは人権に関わることなので、慎重を期する質問だ。明は穏やかに問う。

「きのう流鏑馬の会場にいたみたいだけど、何してたの？」

　そうか、それでわざわざ忍び込んだのか。それなら知っている情報を全て与えよう、と亜矢は思った。だが、記憶があるはずのきのうのことが･･････亜矢は手で頭を抱えた。

「馬が走っているのは覚えているんですけど、何をしてたか･･････むー･･････」

　亜矢のうつろな目付きと記憶が薄い状態から、精神的な麻酔にかけられている、と明は察した。ここの問屋に鎌倉彫を取りに行った際も、この女の目は死んでいた。裏に何かある。この女、この家に対する明の疑念がいっそう深まる。

　どうやら危険な道に入り込んでいることに感付いた亜矢は、頭を下げて依頼する。

「わたしたち、何か悪い道に迷い込んでいるみたいです。そんな道を抜け出したいので、これからもお願いします」

　既に婚約している男といえ、美女に懇願されて背を向けるのは野暮な男だ。ここは男らしくいこう、と見栄を張る明が、少しの自信をちらつかせて答えた。

「僕はシャーロック･ホームズでも、エルキュール･ポワロでもないけど、できるだけのことはしてみよう」

　亜矢は載せている布団を少し持ち上げ、明るい声で促す。

「ありがたいです。きょうは危険、さあ早く家に戻ってください」

　いつまでもこの女と接近していたい気もあるが、そこは婚約済の者、明は惜しげもないかのように別れの挨拶をする。

「うん、今後も時々来てみる。じゃあ失敬するよ」

　明が布団を上げようとしたとき、直人がコンビニエンスストアで買った夜食の菓子や飲み物をビニール袋に入れて持ち、廊下を通って帰って来た。直人は別の鍵を持って裏門を出たのだ。部屋の前に達すると、直人は勢いよく障子戸を開けて中に入った。

「亜矢、ただいま。いろいろ買ってきたよ」

　布団の中の明を見て、直人は立ち止まる。

「あっ！そこにいるのは誰だ？」

　愛する直人といえ、ここに居て欲しくないこともある。困惑した亜矢が首を伸ばして紹介する。

「東慶寺で助けてくれた人よ。ちょっと訳があって一緒に」

　亜矢の恋人が戻って来るとは予想していなかった明は、慌てて布団を抜け出す。

「出直す。失礼」

　直人の横を素早く通り、明は足早で裏口へ向かった。ロックを回し、戸を開けて外へ出る。外したロックは亜矢さんが戻してくれることだろう。裏庭を走り、塀をよじ登った明はすかさず跳び下りた。以後明はマンションへ早足で歩いて行った。

　愛する亜矢、貞節な亜矢が、自分以外の男と床を共にしているとは、どういうことだ？男と女があれだけ接近していれば、やることは一つだ。戻った直人の頭に血がのぼってきた。

「亜矢、あの男は何してたんだ？あっ！お前、まさかあの男と･･････」

　布団を出た亜矢は、訴える顔をして直人のそばに寄った。

「違うの、こうなの。聞いて！」

　きっとあの男は東慶寺で亜矢を見て心を引かれ、命を助けた。それを恩に着させ、愛欲を満たすためにここへ来たのだろう。何という卑怯な手段だ。そんな汚らわしい男のことについて聞く耳を持たない直人が、持っていたビニール袋を横に投げ出すと、中に入っている夜食の菓子や飲み物、ペットボトルが床に散乱した。そして、直人は空手になった両手で亜矢の肩を押し返した。直人の力は強く、亜矢は布団の上に倒れ込んだ。

「うるさい！言い訳なんかよせ」

　起き上がった亜矢は、直人に抱き付いて叫ぶ。

「落ち着いて聞いて！」

　直人が両手で突き飛ばすと、亜矢はまた倒れた。それでも亜矢は這って行き、直人の脚にしがみ付いて訴える。

「あの人はわたしたちを救いに来たのよ」

　そんな芝居みたいなことが、この場で起こることがおかしい。純情な亜矢だが、苦し紛れに嘘をついている。その亜矢を奪い取ろうとしているあいつは、卑劣極まりない。そう考えた直人の顔は、怒りで紅潮した。

「あいつ、東慶寺で助ける真似なんかしやがって、亜矢をものにするつもりだったんだ。畜生！殺してやる」

　激情した直人は亜矢の手を払い、裏門の錠を開けて明の後を追った。月は雲に隠れ、暗闇の世界を 宥 ( なだ ) めるべく所々に街灯が点灯している。それだけでは暗く、遠くは見にくい。

　亜矢と言い争っているうちに、明はかなり先を行った。直人は直進の道、左の道と駆けずり回る。どこにもいない。ならば、戻って右の道へ向かう。

「あれだ！」

　ようやく遠くを歩いている明を捉え、直人は必死に走る。足に自信がある直人は速く、手をテンポよく振る。かなりあった距離が縮まった、と思って喜んだとき、明の姿を見失った。そこは明のマンションの前であった。

　セキュリティの厳重なマンションでは、住人以外は容易に入れない。幸いなことに、ここはそこまで厳しくなかったため、直人はすぐに建物の中に入った。何階だろう？亜矢が見せたメモには〝大友〟と書いてあった。では名前は？そうだ、東慶寺で連れの女が「あきら、わたしたちは行きましょう！」と言っていた。

　直人は頭を働かせ、郵便受けが整列してある場所を探して一つずつ見る。予想どおり、そこには各所帯の名前が記されている。そして、三階の五つ目の位置には〝大友〟の表記があった。また「Akira　Asuka」と小さい字で印刷されたシートが貼られている。明が先のことを考え、二人の名前を用意しておいたのだ。こうすることにより、一週間ここに寝泊まりするあすかを結婚した正規の妻と、マンションに住んでいる人は思ってくれるだろう。

　エレベーターを待つ時間を稼ごうとして、直人は階段を利用する。トントントン。ここは手を小さく振り、足を持ち上げる。目的の位置に達した直人は、玄関のドアを激しく叩いた。

　ドライヤーで髪の毛を乾かしてもらったあすかは、鏡に向かって口紅を塗り直しながら言った。

「そういう訳だったの。複雑な関係」

　明が密通をしたというのは、自分の邪推だった。わたしが愛した明は、そんな軽い人間ではない。それと、ガラス細工のような繊細な娘とばかり思っていた亜矢さんは、知恵と行動力のある女だ。あすかは疑った二人を見直した。

　窮地を助けてもらった明が、感心して言う。

「苦し紛れの亜矢さんの機転さ」

　女はやはり感情的なんだろうか？理由を説明しようとした明の行動を無視し、やるせない感情に駆られて嫉妬したあすかは、自分が情けない。やっと寛容になれたあすかが、手を膝の上に置いて小さい声で謝罪する。

「ほんとにごめんなさい。わたし、悲しくて、悲しくて」

　もし本当に亜矢を好きになって忍んで行き、それを嗅ぎ付けたあすかが平然としていた場合、どうであろう？婚約者の不倫を知って、平気でいられる方がおかしい。そんな女は元々愛情が薄いのだ。明はあすかの嫉妬をプラス思考と取った。

「あすかは愛情深いもんな。僕の心はずっとあすかだけだよ」

　そうだ、わたしが選んだ人が浮気をすることなどない、と考え直したあすかは嬉しそうに肯いた。

　疑惑が氷解して神妙になったあすかの肩を明が 擦 ( さす ) ってやると、尖っていたあすかの口が丸くなってきた。わたしの体に 触 ( さわ ) れるのはこの人だけ。そう思うあすかは昨夜から般若仮面のように頬を引き吊らせていた顔を、いつもの柔和な菩薩の顔に戻して言った。

「大好きな人が愛撫してくれると、こうも楽な気持ちになれるのね。ありがたいな」
