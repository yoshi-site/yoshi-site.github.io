第三章 大イチョウ

発見

ずぶ濡れになって東慶寺から勝の家に戻った亜矢は、すぐに衣服の着替えにかかる。ぴったり体に付着したびしょ濡れのシャツは取りにくく、直人が脱ぐのを手伝ってやった。雨に打たれて震えている亜矢を気遣い、更に直人が手の平で体を何回も 擦 ( さす ) ってやると、亜矢は冷えからようやく解放された。

いつも朝と夕方に催眠術をかけられることがルール化されており、その日も午前十一時に行われたので、せっかく理性を取り戻した二人は、また霊玉により頭の中の記憶をごちゃごちゃにかき交ぜられた。催眠術が土砂降りの雨となって記憶という文字を散乱させ、一時間たった後も意識がぼーっとしている。そのため、昼食を摂らず、直人と亜矢は向かい合って部屋の隅の座布団に座っていた。

わずかに残っている記憶を頼りにぼんやり思い出した亜矢が、頭を押さえて言った。

「きのう何か悪いことさせられたみたい」

ぼっとしている直人も、定子が入れ込んだことは覚えている。

「おかみさんは『鎌倉の商売の秩序を守るため』って言ってたよ」

ここに住ませてもらい、食事をいただけるとなれば、亜矢に義務感が生じる。

「わたしたちの面倒を見てくれてる人の言うことは聞かなきゃあね。疑うとバチが当たる」

そうは言うものの、亜矢は明が様子を探っていたことが頭にあった。自分たちのことを案じ、危険を犯してまで家の中を調査する理由は、ただの親切心とは違う。もしかして、この家が悪事の巣と睨んで刑事が探索しているのかもしれない、と亜矢は考えた。

「むー・・・・・・」

言葉にならない、いや、言葉にできない恐ろしいことを想像している亜矢に、直人が心配して問う。

「どうした?」

亜矢がうろ覚えのことを 恐々 ( こわごわ ) と話す。

「『人が死んだ』って叫んでた。それって異常よ」

八幡宮の事件と定子や霊玉が言ったことが錯綜している直人は、目を瞑って必死に思い出した。

「頭が重くて記憶がおぼろげだけど、みんな大騒ぎしてたな」

いくら貧乏でも、いくらいじめられても、悪の道に染まることは自分の信念に反する。そんなことをすると、いくら家出同然の身といえ、自分を生み育ててくれた両親に傷が付く。この家を疑う気持ちがいったん後ずさりしかけた亜矢は、一大決心をして尊崇する人の恩を振り切り、 毅然 ( きぜん ) として言った。

「恩と事件とは別よね」

養ってくれている人に背くことは不謹慎だが、極悪を見過ごす意気地なしでは男として失格だ。これまでのことを客観視してみると、直人にも 擁護 ( ようご ) してくれている人の店が怪しいことはわかる。普段優柔不断の直人に俄然勇気が湧き、体を乗り出して言った。

「調べてみようってこと?」

後ろめたさを感じながらも、直人はどうやら賛成のようだ。二人の意見が一致し、気持ちを大きく持った亜矢が声を潜めて話す。

「そっとね。何もおかしなことがなければ安心だし」

捜査を効率よく行うには、情報を入手するとか、目星を付けるなどの戦略が必要だ。直人は両腕を組んで考えた。

「どの辺が怪しいかな?」

密輸なら、それを供給する所を発見することが第一だ。これは遠方の捜査となり、自分たちの手が及ぶ範囲を超えている。次の手は品物を隠匿する場所だ。明に傾注しかかった亜矢の頭に浮かんだのは、直人が怒った日のことだ。

「この前、あの人、倉庫を探してた」

「何か見つけたの?」

「ううーん、何も。『ダンボール箱を少し見ただけ』と言ってた」

あの人が失敗したのなら、自分が証拠を見つけてやろう、と意気込む直人が提案する。

「みんなは昼食を摂っている最中だ。今がいい機会。よっし、行ってみよう!」

亜矢はいったん屋外へ出て、公衆電話で明に連絡しに行く。その間に直人は裏口へ行き、倉庫の鍵を箱から取り出した。亜矢が戻ると、二人は忍び足で倉庫へ向かう。庭にも倉庫の周りにも人はおらず、思ったとおりチャンスだ。

直人が倉庫の古風な錠に鍵を入れて回すと、ピンという音とともに錠が簡単に外れたので、きしみを極力押さえる戸の開け方をして二人は中へ入った。いつも荷物を運んでいる倉庫とならば、照明のボタンの位置に容易に辿り着き、すぐさま蛍光灯を点灯させて中を見渡した。

床の上に積み重ねられているダンボールのそばに寄り、二人は一つずつ見た。どのダンボール箱にもきちんと生産者などが印刷されており、これらは入荷や出荷の度に持ち運んでいる物と同じだ。となると、次は中味だ。

五センチほどの切り溝に蓋の先端を差し込む方式のダンボール箱を、折り目がつかないように慎重に開けた。あーあ！明さんが見たとおり、中は平凡な土産物ばかりだ。予想が外れてがっかりした一方、これで良かった、という複雑な気持ちにもなり、直人は俯いた。

その俯いた直人の目に、興味ある物が映った。ぼんやり見ていると見過ごしてしまいがちな、一本の細い物である。そんな物は仕事中に見ても、何の関心も湧かない。今だから、この状況だからこそ目を引き付ける物の前に、直人はしゃがみこんだ。

「これ髪の毛?」

亜矢も膝を付き、床からはみ出ている物を見た。頭に何万本も生えている髪の毛は、日に何本か抜け落ちる。これは従業員の誰かの一本だ。この細い物によって光明が差した、と亜矢は思った。

「そうね。隠れてる先端は床の中よ。きっとこの下に何かある」

　直人が摘んで引っ張ると、湾曲していた髪の毛がぴんと一直線になった。手縫いをしている針を引き上げたとき、そこに付いた糸が張った状態になる様に似ている。これこそ髪の毛の一端が床板の間に挟み込まれている証拠だ。こんな細いゴミが秘密を教えてくれたのだ。直人が勝ち誇ったように叫んだ。

「ここが開き、その後閉まったってことだ」

　髪の毛の近くに置かれているダンボール箱を、直人が横に移動させた。たまたまそこに無造作に置かれた、と思えるが、下の床を隠匿するために置かれたのかもしれない。とにかく邪魔物をどかした。すると、四角の枠がはっきり見えた。直人が枠と床の間の隙間に爪を入れ、押してみる。キューというきしむ音がして、枠がごくわずか動いた。亜矢を見て直人が確認する。

「動いたな？」

　自信が付いてきた亜矢は、すぐさま次の行動に移るべく手を出した。

「動いた！やっぱり何かある。開けてみよう」

　爪を隙間に入れ、枠を二人がかりで持ち上げた。それは重く、爪が剥がれるほど痛い。途中で離すとバタンという大きな音がしてここにいることが発覚するため、慎重には慎重を重ねて持ち上げる。

「あっ！」

　大きなスペースが現れた。下に地下室があり、目の前に階段が見える。そこは入ったことも、聞かされたこともない場所だ。ここが秘密の隠し場所なのか？予想が現実味を帯びてきた、と思うと、二人の心臓が高鳴りした。

　蓋を取って穴の脇に置き、二人は恐る恐る階段に足を踏み入れた。傾斜がきつく、階段の板幅が狭い。足を踏み外すと下の床まで落ちてしまうので、二人は慎重に足を出してゆっくり下りた。

　地下室は暗く、不気味である。大事な物を入れて置く場所だろうが、施錠されていないとはどういうことか？地下室の入り口に段ボール箱を置き、かつ、倉庫の入り口に鍵を掛けてあれば十分と考えたのだろう。

　地下室の照明のボタンはどこだ？こうも暗くては探索に支障を 来 ( きた ) すため、それを解消するべく直人が一階から漏れてくる光を頼りに辺りを見渡すと、階段を下りた右手の壁に照明用のボタンがあった。すぐさま直人がそれを右手で押す。

　二人は明るくなった地下室の中を、目を凝らして観察した。地下室には売れ残った商品の箱が 猥雑 ( わいざつ ) に置かれている、と予想したが、綺麗に整理整頓されている。二メートルもある立派な仏像が剥き出しの状態で立っている、という期待も裏切られた。置いてある物はダンボールの箱だけだ。なーんだ、一階と同じ物だ。まてよ、中味まで同じと見なすのは早計だ。積み上げられたダンボールを見た亜矢の胸が踊る。

「中は何かな？」

「開けてみよう」

　ガムテープの梱包では、それを外すと箱の表面が 剥離 ( はくり ) して後始末が面倒になる。一階と同様、細い溝に箱の先端を埋め込む方式なら、元の状態に楽に戻せていい、と直人は思った。直人が重なっているダンボール箱を床に置いて見ると、残念なことにガムテープがしっかり掛かっていた。高価な物を収納する箱に埋め込む方式は不釣合いだ、と思い、考えが甘かったことを直人は反省する。

　二人は箱の両側に分かれて 跪 ( ひざまず ) き、箱の表面がテープの幅より広く剥がれることを避けるため、慎重にテープを取り去る。後でここに同じ幅のテープを貼ればよい。テープが一階にあることは、商品の出し入れを担当している直人は知っている。

　直人が扉状になっている蓋をそっと開けた。中味が一階にある物と同種のときは、あの人の疑いが妄想といえる。はたしてどうか？中を見た二人の顔に緊張が走る。

　亜矢が箱の中の一つを手にして言った。

「あっ！金の仏像。これ、この店で扱ってた？」

「いや、初めて見る」

　ということはこれだ。亜矢が恐る恐る呟く。

「きっと密輸品」

　恩人イコール善人と見なしていた直人は、それが誤りであることがわかり、箱の横に手を当てて冷静に事実を確認する。

「ダンボール箱には、品目や生産会社の印刷がない」

　隣の箱にも宝石が付いたネックレスや指輪、 翡翠 ( ひすい ) の置物など、目を見張る高級品が詰まっている。他の箱に入っているのは象牙、虎の革、砂金の砂時計だ。一般の土産屋に卸す物もあるが、こうも高価な品揃いでは怪しい。身を引き締めて亜矢が推理する。

「こうして地下室に隠し、どこかに売っているんだ」

　直人は亜矢の肩に手を乗せて意気込む。

「証拠を掴んだ。あの人が疑っていたこと、ほんとだった。早く知らせよう！」

　思い切って探索したことが報われた亜矢の心は弾む。

「うん、早く早く」

　ここが悪事の巣であることが断定でき、次は後始末だ。直人は一階に行ってガムテープを持って来ると、箱の左右を亜矢が両手で押し、前と同じ状態になるようにダンボール箱にテープを貼った。これによって、箱の表面が剥がれた個所は、新しい茶色のテープによって隠された。

　位置が変化している箱は怪しまれるので、移動した箱は元の位置に正確に戻す。後始末が完璧となり、二人はふっと息を吐いた。テープの消費量は少なく、輪の直径はほとんど前と同じである。そのテープを手にして照明を落とし、二人は階段を登り始めた。

　昼食を終え、午後の仕事を頼むつもりの磯部が、直人と亜矢を探していた。二人の部屋を見ると、そこには座布団が置いてあるだけだ。ならば庭を探す。そこにもいない。どこだろう？倉庫を見ると錠が外れている。

「荷物の出し入れをしてるのかな」

　あの二人は働き者だ。ちょっと教えればすぐに覚えるし、応用も効く。だが、磯部はよく考えてみた。

「きょうは入荷も出荷もない日だ。むー、おかしい！」

　倉庫の中に数歩足を踏み入れた磯部は、中はひっそりしているものの照明が点灯されている状態に驚いた。鍵を掛け忘れ、照明を点けっぱなしにして倉庫を離れる従業員がどこにいる。奇妙なことは他にもあった。地下室への蓋が開き、ぽっかりと穴が開いているではないか。磯部はその場で怒鳴った。

「地下室に誰かいるのか？」

　階段の真ん中まで来ていた直人と亜矢は、急に声をかけられて真っ青になった。あのドスの効いた声は番頭、発見されると一番困る人である。直人が小さい声を発した。

「しまった！見つかった」

　二人は後ろ向きに階段を下り、地下室の床に戻った。ダンボール箱の陰に隠れようと、とっさに考えたが、地下室の蓋が開いているので疑われて入り込まれ、ダンボール箱を移動されたときに発覚する。そこで、直人が上に向かって大声で答えた。

「直人と亜矢です。在庫品の整理をしてるんです」

　慌てた二人が取った行動は、もっともらしくダンボール箱を持ち上げて荷物の整理をすることだった。

　やはり人がいた。それも疑問を生じさせる人が二人も。磯部が地下室への穴の前に来て、中を 覗 ( のぞ ) き込んだ。

「何！在庫の整理を。･･････そんなこと、誰が頼んだ？」

　 印半纏 ( しるしばんてん ) の下に赤いシャツを着て、黄色のズボンを履いている磯部が二人の目に入った。「従業員の誰々に頼まれた」と言えば一時的にこの場は凌げるが、いつか割れる。直人は都合の良いことを必死に模索した。苦し紛れに直人が挙げた言い訳は、愛社心をちらつかせることだった。

「あまりにも乱雑なので、何とかしよう、と思って」

　ここをいとも簡単に発見されるとは、教育係として 沽券 ( こけん ) に関わる。さては何かあるのか？昨夜、酔いで視覚が麻痺していた磯部は、ここで鋭い嗅覚を働かせた。今考えると、あのとき布団の中にいた男は、直人と別の人物のような気がする。となると、磯部の声が俄然不気味になった。

「地下室なんか、お前たちにまだ教えてない。･･････きのう亜矢が楽しんでいた相手は直人と思っていたが、ほんとかな？」

　こちらの答えはただ一つである。亜矢は拳を作って弁解する。

「ほんとです。わたしのそばにいるのは、直人だけです」

　きのう亜矢の部屋から自分の部屋に戻る途中、磯部は裏口近くで発した音を聞いた。そのときは野良猫が塀から飛び下りた、と磯部は思っていた。よく考えると、あれは人が裏口を通った音に近い。もしかして、そちらの方が直人だったのではないか？では、亜矢の布団の中にいた人物は誰か？磯部の疑いは益々強くなる。

「亜矢の隣に寝ていた男は、髪が短かったぞ。･･････さてはお前たち、何か企んでるな？」

　いくつかの怪しいことが、これで結び付いた。やったぞ！顔色を変えた磯部はいったん倉庫を出て母屋に入り、手を口に当てて大声で叫ぶ。

「おーい！みんな来てくれ。大変だ！」

　昼食を摂っている最中の印半纏を着た従業員の男五人が、箸を置いて倉庫へ向かった。何人も廊下を走ると、バタバタという音が響く。慌ただしい音を聞き、別の部屋にいた勝と定子も出て来た。昼食を摂り終わり、自室で気持ちよくタバコをふかしていたところを中断された勝が、迷惑そうに怒鳴った。

「騒々しい！何事だ？」

　二人を教育したのは自分だ。仕事を丁寧に教え、苦労して洗脳もした。そして、二人の背信行為を発見したのも自分だ。教育の成果が御破算なった見返りは十分ある、と思い、磯部は得意になって言った。

「旦那様、入荷も出荷もない日に、直人と亜矢のやつ、倉庫を整理していましたぜ。まして地下室まで」

　極秘中の極秘の場所を発見され、勝の眉が大きく吊り上がる。

「何、あの二人が離反？」

　みんなは倉庫の中に集まり、ぽっかり開いている床の穴を取り囲んだ。首を長くして下を 覗 ( のぞ ) き込むと、磯部の言ったとおり、直人と亜矢が薄暗い地下室にいた。どうしたことか？内密にしておいたはずの地下室を、ここに来て数日の若造たちに見破られた勝は困惑した。

「何でここがわかったんだ？」

　磯部は手の平で顎を押し上げ、眉を曲げた。

「それが、どうも 合点 ( がてん ) がいかんので」

　ものものしく鍵を掛けると、そこに重要な物が置かれてあることが明白になり、暗に情報を与えていると同じだ。目ざとい盗人は金属を加工し、合鍵を作って入り込むだろう。だから、裏をかくことが有効と考えていた勝は呟く。

「普通の倉庫に見せかけようと、地下室の錠を省いたことが裏目に出たか」

　独立して店を持つまでの野望を抱かない磯部は、せめて従業員のトップとして存在感を発揮し続けたい。そのためには規則を厳格に 遵守 ( じゅんしゅ ) し、罪には罰を与えることが必要だ。それが見せしめになり、部下が主人と自分を 畏敬 ( いけい ) することに繋がる。勝の言い付けなら人を殺すことなど平気な磯部は、罪人を叩き殺してやりたいが、そこは従業員の身分、怒る気持ちを押さえて勝に裁断を仰ぐ。

「亜矢の様子がどうもおかしい、と思ってましたがね。･･････どうされます？」

　さて、二人の措置をどうしよう。秘密の場所が発覚されたとして、重要な点は別のところにある。隠しておいた物がばれたかどうかだ。それが無事なら、事なきを得る。勝は怯えている二人に穏やかに尋ねた。

「お前ら、地下室の中の物を見たのか？」

　「見た」と言えば殺される。黙っていれば追及の手が伸びる。ここは「見ていない」と言うのが助かる唯一の道だ。びくびくして言ったのでは怪しまれるため、恐怖心を抑制して冷静に直人が答えた。

「いーえ、ただ入っただけです」

　亜矢はダンボール箱に手を掛け、丁寧に言った。

「箱を綺麗に並び替えたんです」

　いかにもごまかそうとする言い方だ。殺すのは簡単だが、そうかといって、二人の消息が不明になると警察の捜査の手が入るので、早まっては損だ。純真な世間知らずのこいつらが真剣な顔をして言っているとなれば、それは正しい、と勝は考えた。

「そうか、それならよいが」

　自分たちを養ってくれた主人は寛大だった。その主人を 騙 ( だま ) せた直人と亜矢は、これなら何とかなる、と思った。しかし、疑い深い者もいた。磯部は指を回して主人の早合点を制する。

「誰かに頼まれてやっているかもしれませんぜ」

　すんなり許すのは軽率と反省した勝が、磯部に向かって沙汰を下す。

「むー、それはあり得るな。よし、男を攻めてみろ」

「こんな物、ちょっと力を入れれば、すぐ取れるぜ」

「いーち、にーの」

「万事順調、いけるぞ！」

　と明は呟く。

「これが見えんか？」

　 愚弄 ( ぐろう ) された勝が、反り返って 蔑 ( さげす ) む。

「ぷっ、ばかたれ！水戸黄門じゃあるまいし、 印籠 ( いんろう ) なんか何の効き目がある？」

　あきれ返った磯部は、威張っている明の内心を突いてきた。

「手も膝も震えてるぞ。さぞや怖いんだろう？」

　正直、明の体も心もぶるぶると 震撼 ( しんかん ) していた。 不撓 ( ふとう ) 不屈 ( ふくつ ) の精神で敵に立ち向かうのが日本の侍、水戸黄門のお供をする武術の達者な助さん格さんの真似をして明は見栄を切ったものの、虚栄を張る姿はどうも弱々しい。なぜなら、彼らはどんなことがあろうとも生き続ける芝居の世界にいるのに、自分がいる所は現実の世界だ。それも、死ぬ確率が極めて高く、磯部の言ったとおり本当に怖い。

　見せかけの自信を持った明は手にした物の蓋を開き、アンテナを伸ばして前方に突き出した。

「ばかたれ。これが印籠に見えるか？よく見ろ！」

　明は体を回し、後ろにいる磯部にも見せた。これには目を見開いた磯部が狼狽した。

「あっ！携帯電話」

　磯部に向かって厳しく勝が命令する。

「おい、電話をかけさせるな。こいつら三人とも 殺 ( や ) っちまえ。お前らは今夜、由比ガ浜で舟遊びだ。その後は重い石を 背負 ( しょっ ) て海底見物、最後は魚の餌になりな」

　前を向いた明の背後から磯部がすっーと忍び寄り、明が手にしている携帯電話に手を掛けた。不意をつかれた明はいとも簡単に重要な物を奪取され、しまった、と思ったが、もう遅い。明の真似をし、磯部は携帯電話を見せびらかして威張る。

「わっはっは、これをよく見ろ！貴様の脳足りんに笑いが止まらん。わっはっは、わっはっは」

　他の手下たちも一斉に腹を抱えて笑い、勝ち誇った勝はとどめの言葉を投げかける。

「どうじゃ、諦めたか？」

　これほど不利な状況に置かれては、降伏するのが通常だ。そうすれば、少しは長く生きられる。ところが、屈服を否定する明は、ふてぶてしい笑いを見せた。

「これから警察に連絡するとでも、思ったのか？」

　素直に負けを認めることが嫌いな人間は、痩せ我慢をするものだ。頑固なこいつも破れかぶれになってほざいている、もしくは、恐怖で気が狂ったかだ。いずれにせよ、一巻の終わりだ。とはいえ、鼻高々になった勝は、明の言った内容が少し気になった。

「何だと？」

　震えている明のジョークが続く。

「自分はこんな所で電話をかける脳足りんじゃない？」

　益々勝は気になる。

「今、何と言った？」

　逆に明が鼻高々になった。

「地下室で証拠を掴んだときに、既にかけたわ。家の外を見てみな！」

　助かりたいための嘘にしては、どきっとさせる。もしかして、本当に地下室を探られたのか、そして、既に電話をかけられたのか？ひどく心配になった勝が、指で手下に指図した。

「おい！外を見て来い」

　手下二人が慌ただしく走って行き、裏門の戸を開けて外を見た。彼らも事の成り行きがひどく心配だ。もしここで捕まると、自分たちの生活が崩壊するので、主人と共に何とかこの場を凌ぎたい。

　彼らは目の玉が飛び出るほど驚いた。這い出る隙間もないほど、大勢の人たちが家を取り囲んでいる。三十人近くもいるかという数だ。その最前列に構えている警察署長が、突入せよ、との号令をかけようとしている。

　これはえらいことになった。取り乱した手下が部屋に戻るやいなや絶叫する。

「警官の壁だ！」

　こんな所で一番耳にしたくない言葉が発せられた。まさか、それはないだろう、と思うが、少し動揺した勝が歩み寄って聞き返す。

「どこにだ？」

「家の周り、全部に」

　多数の警察官がドドドッという音を立て家に入ると、廊下を埋め尽くした。襖を開けて反対側からも警察官が部屋に入り、磯部たちを睨み付ける。相手方の人数は勝の方よりずっと多い。逆に勝たちが四面楚歌の状態となり、逃げ道を失った者たちは 愕然 ( がくぜん ) とした。

　山吹色のシャツに着替えているあすかも、警察官の後に続いて部屋の中に入った。「女は危険」という警察の忠告を無視して、あすかはこの店に来た。明の安否が気がかりで、家でじっとしていることなどできないあすかは、明の生命が維持されていることを確かめた後、息を殺して見守る。

　指揮を執っている署長が、毅然としながらも丁寧な言葉で伝える。

「岩本勝さん、裁判所の令状に基づいて、家宅捜索をさせてもらいます」

　地下室に入られては、密輸の証拠品を押収される。正常な意識が戻った直人と亜矢が口を開けば、流鏑馬の仕業も判明することだろう。直人と亜矢を仕込んで松谷を殺害するという綿密な計画は、最後にその直人と亜矢によって壊され、水泡と化す。 もはやこれまで、と勝は観念した。

　そうかといって、素直に逮捕されるのは 癪 ( しゃく ) だ。犯罪人となることは受け入れるとして、勝には一つだけやりたいことがある。自分たちを破滅に導いたもっとも憎いやつを、この世から消し去ってから手錠を掛けられたかった。

　勝はとっさに横の 梁 ( うつばり ) に掛かっている槍を取り外し、明の三メートル前で身構えた。それと同時に、手下たちも手に持ってきた出刃包丁や鎌を胸の前で構え、あくまでも抵抗する気だ。犯人たちを取り押さえようとしていた警察官は、明の生命を危ぶみ、身動きが 制 ( せい ) された。

　一触即発の状態になった。もしここで手錠を掛けたり警棒を振るったりした場合、勝の持っている槍はすぐさま明の心臓を突き刺すであろう。では、ピストルを発射すればよい。これは正当防衛に当たる。だが、命中した瞬間に勝が槍を投げ、明に当たったらそれも危険だ。したがって、捕縛しようとする署長の命令は保留され、全員絶句した。この 膠着 ( こうちゃく ) 状態の中、恐れを知ってか知らないでか、あすかがそっと明に近づく。

　自重している警察官を 嘲 ( あざ ) 笑うかのように、数回槍の穂先を振った勝は明の心臓めがけて進んだ。勝の履いた足袋が畳を滑走するススススッという音が、恐怖で静まり返った部屋で起こり、槍の穂先が明に接近する。危ない！

　そのとき危機を感じ取った亜矢がふらふらと立ち上がり、敢然と飛び出したかと思うと、尊敬の念を抱き始めた明の体に抱き付いた。急に現れた亜矢の背中を刺す形で、勝の槍が進む。慌てたあすかは無我夢中で肩に掛けていたショルダーバッグを取り、亜矢の背中めがけて放り投げた。バタッという音とともにショルダーバッグが亜矢の背中に当たり、槍先はそのショルダーバッグを激しく突き刺した。更にバッグは亜矢の背中を押し、亜矢はどっと畳の上に倒れた。と同時に、亜矢に抱き付かれた明も、亜矢の下になって倒れた。

　二人を見て、槍が亜矢に突き刺さった、と恐れたあすかは、呆然と立ち尽くした。憎い者を葬ることに失敗した一方の勝が 唖然 ( あぜん ) として槍を放り投げると、バッグを刺したままの槍がドタッという音を立てて畳の上に落ちた。コンニャクを刺したおでんの串が置かれた形だ。恨みを晴らすことに失敗し、次に打つ手が思い浮かばない勝は放心状態となる。

　この行為をもっとも確かな証拠とする署長は、早速容疑の内容を切り換える。

「公務執行妨害と、殺人未遂の現行犯で逮捕する」

　警察官たちは、ここぞとばかりに勝に手錠を掛けた。「 窮鼠 ( きゅうそ ) 猫を噛む」という 諺 ( ことわざ ) がある。苦境に陥った者が、普段見せない力を発揮することだ。苦境どころか二人の面倒をよく見てやったのに、直人と亜矢が反旗を 翻 ( ひるがえ ) すとは何たることだ。養子にすることで自分の心を清浄化してもらおうと思っていた、あんなに純情な若者がだ。それと、どう見てもコントロールに疑問がある女にバッグを正確に投げられ、復讐の邪魔をされた。どこにあんな才能があるのか、と勝は考え悩む。

　そうか、悪に 同 ( どう ) じない精神があいつらにあったのだ。悪に手を染めると報いが来ることは、熟慮すればわかることだった。それが自分に欠けていた。

　篤実だった自分は目が 眩 ( くら ) み、悪の道に走った。心眼を開いて見れば、ここ数年、ばかなことをしていたことがよくわかる。今ようやく勝は、悪夢から目が覚めた。

　ここは「ぜひ鎌倉で問屋を」と最後の夢を抱いた先代の実家、そこを自分たちの悪事で 汚 ( けが ) してしまった。我が子として育ててくれた恩人が、天国でこの手に填められた重い鉄の輪を見たら、どんなに悲しむことだろう。せめてもの慰みは、悲願を達成した先代の生存中にこの姿を見せなかったことである。先代を裏切ったことに対して自責の念が募り、勝はただ俯いた。

　親分が捕まったとなると、他の者たちはおしまいだ。じたばたする手下たちもやがて全員手錠を掛けられ、カチッカチッという金属音が連鎖反応的に起こった。定子だけは覚悟ができていたのか、目を瞑って合掌したまま素直に手錠を受けた。いつかこうなることは、悪事を始めたころに予想していたかのような落ち着き振りである。冷たい音を発すると、固い輪が定子の手首の自由を奪った。神仏を見放した定子は、神仏に見放されたのだ。

　あすかははっと我に返り、倒れた二人の 下 ( もと ) に 跪 ( ひざまず ) いた。

「明！亜矢さん！大丈夫？」

　亜矢の安危が気がかりな直人は、亜矢のそばまで這って行った。

「亜矢、生きてるの？死んだの？」

　仰向けに倒れた明の上に、亜矢は俯せの状態で被さっていた。正義感があり、知恵と勇気を兼ね備えた男にいくらか慕情を抱いた亜矢の頬は、偶然か故意か明の唇に接触している。東慶寺で命を助けてくれた恩人の身代わりになるつもりの亜矢はあの世で息をし、死んだ状態で明に抱き付いている、と思った。この状態が継続するなら、死も良いものだ、この感触を大切にしよう、とも亜矢は思った。

　その状態はすぐに幕を閉じた。亜矢の肩を両手で押して起こし、明がゆっくり立ち上がると、亜矢もようやく立つことができ、明の胸を名残惜しげに離れた。ここで吸っている空気は天国の綺麗すぎる空気と違い、少し薄汚いけれどもこの世の空気である。生きていることを確認した亜矢は、近くにいる直人に抱き付いた。生きている間はこの人が唯一の恋人と思って。

　明も駆け寄ったあすかときつく抱き合った。九死に一生を得る思いで亜矢とあすかに命を救われた明は、あすかの温かい肌に触れることで生きていることを実感した。若い二人に 憐憫 ( れんびん ) を感じて探偵気取りで犯人探しをし、命を落としては笑いものになる。こうしてあすかを抱けた幸運を神のご加護と思い、明は喜んだ。

　穴を開けられて身代わりとなったバッグを、署長が槍から丁寧に抜き取ってあすかに返すと、鋭利な槍の穂先とカバンの穴を見た明と亜矢は、バッグを自分に置き換えて身震いをした。バッグの所有者が労わるように穴を手で撫でてやることによって、穴はいくらか縮小した。一方、大事なバッグを傷付けた罪深い槍は証拠品として没収され、人間と共に逮捕される形になった。

　手錠を掛けられる前に、磯部が放り投げた携帯電話機を明は大事そうに拾った。あすかのカバンと同様、壊れたのではないか、と思い、不安な気持ちで明が蓋を開けて見た画面に文字が現れた。どうやらこちらも人間に倣って無事だった。ほっとした明は伸びたアンテンを丁寧に戻し、そっと元のポケットに納めた。

　手錠を受けた者たちが、警察官に連行されてぞろぞろと退去した。じたばたしている者もおり、大人しくうな垂れて付いて行く者もいたが、いずれにせよ一人残らず逮捕されて 悪業 ( あくごう ) 劇の芝居は完結した。一網打尽とはこのことである。

　連行される途中、立ち止まって亜矢を凝視した定子は、亡くなった娘の美奈を思い出した。少しでもいい、一秒でもいい、もう一度その美奈に似ている亜矢を見たかった。それが未練というものだ。

　長男の頼家が暗殺された後、政子は頼家の子の 善哉 ( ぜんざい ) を次男実朝の養子にしていろいろ面倒を見てやり、 公暁 ( こうぎょう ) の名となって 園城寺 ( おんじょうじ ) で修行した後には、八幡宮の別当という要職に付かせている。しかし、公暁は深情ある政子の最後の子、将軍実朝を暗殺し、恩を 仇 ( あだ ) として返した。政子にとって結果的に 自業自得 ( じごうじとく ) である。

　政子と同じように定子は亜矢に情をかけ、従業員として雇ってやった。その厚情が同じように仇となり、亜矢によって逮捕されることになった。あゝ、何と皮肉な運命か、何と自分は愚劣なことをしたか。八百年たった今、ここで歴史が繰り返されたことを定子は悔やんで自戒しても、もう遅い。歴史と同様、自分の身に起こったことは、書き換えることができない。

　そのような後悔だけが定子を支配していたかというと、良い点もあった。亜矢と暮らしていた五日間、若くして亡くなった美奈がそばにいるように定子には思えた。扇動もいじめもしたが、地下室を発見されるまで亜矢に極限の苦しみを与えることは差し控えた。それより、もしあの事件が事故として扱われ、自分たちの経営する問屋が順調に回復軌道に乗った場合、養子として直人と亜矢を迎え入れ、問屋を継がせる計画も立てていた。その夢を考える束の間の幸せが定子にあった。

　その 目論見 ( もくろみ ) は自分の失策により飛び散り、心に神や仏が消え失せた自分という悪魔に、幸運は見切りを付けた。悔恨は蘇生に繋がらない。これが世の習いである、と思い、定子は 一切合財 ( いっさいがっさい ) を失った絶望感を持って連行された。

　亜矢もしばらく定子を見つめた。考えてみると、この問屋の人たちは、みな善人の仮面を被った悪者だった。その中に一人だけ心のある人がいた、と亜矢は思っている。それが定子だった。定子は細部まで亜矢に気を遣い、身の回り品などを用意してくれた。不慣れな仕事を始める前にはやり方も教えてくれ、お腹が空いたころには間食を与えてくれた。

　定子の娘に自分が似ていることなど知りようもない亜矢は、定子の親切心だけは感付いていた。従業員に対して厳しいことを言うおかみさんである一方、定子には従業員を労わる面もあり、従業員に慕われているのはそのせいだ。この定子に亜矢は恩義を感じるとともに敬愛し、一生懸命仕事をした。

　立ち止まっている定子に警察官がきつい目付きをして歩行を促すと、これが最後と思い、惜別の念を込めてもう一度じっと亜矢を見てから定子は歩きだした。未練を断ち切り、その後は俯いたまま定子は護送車へと向かう。汗水流して築き上げたこの家とも、 愛 ( いと ) しい亜矢とも永遠の別れとなる。頭を落とした定子の後ろ姿にはあの気高さがすっかり消滅し、寂寥感だけが残った。

　うっすら涙を浮かべながら感謝の気持ちを込め、亜矢は引かれて行く人に小さく会釈した。殺人や密輸は重い罰を課せられることだろうが、少しでもそれが軽くなり、善人として再起することを亜矢は願う。やがて定子が去ると、亜矢は目頭をそっと押さえた。

　武器を手にした者たちと対峙するという緊張を解いた明が署長のそばに寄り、倉庫を指差して事情を説明する。それを聞いた署長に指名された警察官の何人かがぞろぞろと地下室へ歩いて行き、彼らは多くの証拠品を没収して持って来た。それらを仕分けし、家の外へ運ぶ。

　一段落した署長である井上が、明の手を取って労をねぎらう。

「明、ごくろうさん！危ない目に合わせて悪かったな」

　連中に取り囲まれて以来、貧乏揺すりをしていた明の膝がようやく止まった。映画のヒーローなら「軽い仕事でしたよ」と涼しい顔で言うところだが、この素人探偵はかすれた声で本音を告白する。

「何とか間に合ってくれて･･････ふー、命拾い。もうちょっと遅いと、地獄へ真っ逆さまでした」

　明を危険な目に遭わせることを心配していた井上が、ほっとして言った。

「危機一髪とはこのことだな」

　明はごくんと唾を飲み込んで答える。

「正しく」

　初対面においては、警察署長ともあろう者にもっときちんとした言葉使いをするべきなのに、明のこの親密な口の利き方はどうしたものか？明の馴れ馴れしい態度を煙たがる様子が井上に見えないところを見ると、どうやら二人は知り合いらしい。

　考えのある明が人目を 憚 ( はばか ) り、井上の横に回ってそっと耳打ちをする。何やら願い事らしく、柔らかい言い方だが最後の言葉ははっきりと言った。

「それで、あした」

　井上は 口髭 ( くちひげ ) を蓄えた厳格な顔付きをしている。てきぱきと命令を下す即断即決のこの者は、いくつかの難問事件を解決した実績がある。切れ者の井上は杓子定規の厳格さを示す以外に、物事をうまく進めることもやぶさかではない頭の柔軟な人物だ。その井上が明の願いを聞き入れ、深く肯いた。

「うん、了解！」

　明の肩をポンと叩いた井上は、他の警察官と共にこの場を去った。何人かの警察官は店内を検証したり、現場を維持したりする役目があり、尚も残っている。おそらく夜を徹して証拠の場所を見張っていることだろう。夢を包んだ土産物をたくさん在庫したこの店は、しばらく厳戒態勢となった。

　問屋は封鎖され、家の周りにはロープが掛けられた。塀には立ち入り禁止の表示の紙が貼られ、一般人は勿論のこと、取引している土産屋の関係者や、運送業者も完全にシャットアウトだ。鎌倉の有名な問屋も、これでは危険区域扱いされる。

　多くのパトロールカーが並ぶという異様な家の周りに、野次馬がたくさん集まって来た。親戚や知人に土産屋を経営している者がいる人は、その人がこれから商品を仕入れることができるかを心配してやった。商売に関わりのない近所の人たちは、人徳のある岩本の店にこんなに多くの警察官が押し寄せるとは、いったいどんな事件だったのか、と頭を巡らし、腕を組んで貼り紙を見ていた。

　依頼　

　ヘッドギアにより起こった意識の錯乱が収まり、普通に歩けるまで回復した直人と亜矢には、支えも手を取ってやることももはや不要である。うつろだった目の焦点も定まり、相手の顔をはっきり認識できるまでに至った。意識の錯乱の方は尾を引くものではなく、短い時間が解決してくれた。

　安心した明とあすかは、古風な問屋と打って変った白い近代的なビルの病院へ二人を連れて行き、治療を受けさせた。体の傷の方は専門医の治療が必要となる。まずは外科だ。多数あった直人の傷は、幸い浅かったことにより簡単な処置で済んだ。薬を塗ってもらうときにしかめ 面 ( つら ) をした直人は、回復のための痛みは拷問に比べてずいぶん軽い、と感じた。

　マインドコントロールを受けていたので、念のために二人は精神科で診察してもらった。両者とも医師の質問に正確に答えることができ、記憶力も思考力も正常と太鼓判を押された。霊玉の催眠術による影響は払拭され、流鏑馬の会場で起こった事件、倉庫を 覗 ( のぞ ) いたこと、発見されて痛い目に合ったことなど、二人ははっきりと思い出せる状態になっていた。

　急に長く歩かせると、症状がぶり返すこともある。拷問という生死を左右することを受けたからには、心の動揺を抑えることが必要と明は判断し、二人を病院の待合室で少し休ませてもらった。明は会計のカウンターで診療費の支払いを済ませ、それが済むと待合室に戻って直人と亜矢にマインドコントロールを行った。今回のマインドコントロールは、霊玉が行った邪気を帯びた悪徳行為と反対となる自分を見い出す瞑想、つまり坐禅である。直人と亜矢は椅子に座るという姿勢で教わったとおり手を組み、目を半眼状態に保って静かに呼吸をした。

　その 間 ( かん ) に、明とあすかはある所に出向いた。そこは昨日悪夢と化した鶴岡八幡宮、馬上から放たれた矢が当たり、一人の生命が失われた所だ。いったい何が目的であの場所へ、と不思議に思ったあすかは、明のユニークな発想を聞いて納得し、後に付いて行った。

　明が 宮司 ( ぐうじ ) の橋本に面会を申し入れた。もう夕方だ。平服に着替えた橋本は先輩の所へ行って懇親を深めながら、八幡宮の今後のあり方について相談する計画を立てていた。管轄する地で大事件が発生したとなれば、手を打つ必要があるのだ。それでも「昨日の事件に関する大切な連絡がある」と明が強く訴えたことによって、玄関で靴を履き終わっていた橋本は出かけるのを延期して会ってくれた。

　霊玉は宗教、それも、偽物の宗教に携わっていた。日本の神を崇める職にある橋本は凛としていて礼儀正しく、 神魂 ( しんこん ) も高潔で悪の誘いなどあっさり跳ね返すことができるので、霊玉とは大違いの人物だ。

　明とあすかが事件の仔細を説明した。橋本はひっきりなしにパトロールカーが勝の問屋の前を走り回っていたことを、知人に聞いている。きのうは自分の管轄する領域で人が亡くなり、いやな思いをした。きょうもまた事件か、鎌倉も物騒になったものだ、と思い、橋本は顔をしかめどおしだった。

　事件の詳細を説明した明が、最後にこう言った。

「流鏑馬に乗じて殺人を企てた犯人が、逮捕されました」

　長年災厄など無関係だった神聖な八幡宮の境内で、事故が起こった。それが殺人事件とは、橋本は跳び上がるばかりに驚いた。

「えっ！『誤射と報道された松谷さんの死が、殺人だった』と言うのですか？」

「はい、商売敵の岩本勝らの企みです」

「そうでしたか。やはりあの男がね。共栄の精神を持てば良かったのに」

　「やはり」は明にとって気になる言葉だった。

「ということは、もしかして、そのことを予測しておられたんですか？」

　岩本勝と松谷の不仲を知っていた橋本は、松谷が殺されたとすると、犯人は岩本勝と勘ぐっていた。何か私怨がありそうなのだ。明の説明にすんなり納得したのは、そのためである。橋本は胸裏の一端を紐解いて言った。

「予測というほどではありませんが、あの二人は最近口げんかをしていたようです」

「なるほど」

　どうやら外出を延期した見返りがあり、橋本は丁寧に頭を下げた。

「あなた方のおかげで、 忌 ( い ) まわしい事件が解決しました。本当にありがとうございます」

　神社に頭を下げてお祈りをしてきた明は、神社のトップに逆に頭を下げられ恐縮する。

「いやー、あまりお礼を言われると、照れくさいです」

　事件が未解決のままでは参詣者はびくびくしての参拝となるので、目の前の二人は八幡宮にとって救世主となった。それより鎌倉にとっての救世主だ。晴れ晴れとした橋本は大きく胸を広げる。

「これで鎌倉も安心です」

　不安を抱いている人はもう一人いた。さぞ他人から冷たい目で見られていることだろう。あすかは嫌疑をかけられた人のことにも気を遣う。

「矢を射た人も安堵できますよね」

　当の射手は鎌倉在住で、毎年春の行事に参加してもらっている男だ。的を外すことが極めて稀な流鏑馬の名手であることは仲間の誰もが知っており、橋本自身も目で何回も確認している。その男をよく知る橋本が、聞いていた心境を伝える。

「そうそう、何しろ射た矢で人が死んだんですから、当人は気落ちしていたんです」

　犯罪の容疑をかけられると睡眠が疎外され、逮捕、訊問、裁判、服役、社会の非難など、延々と苦汁を舐めさせられる。まして殺人は重罪、辛苦は大きい。これには明も同情する。

「大変驚いたことでしょう」

「あのままだったら不憫です。これで本人も元気になりますよ」

　日本の歴史や文化は二千年もの年月を積み重ねた一方、それ以前に興隆を極めた世界のいくつかの国の歴史や文化は現在、滅亡、もしくは衰退している。そこへいくと、侵略されることも分断されることもなく日本が栄えているのは、厳然たる事実だ。この国の歴史や文化を尊重するあすかは、是が非でも武芸の保存を願う。

「これに 懲 ( こ ) りずに、また流鏑馬をやってもらいたいですね」

　励ましの言葉に感激した橋本は、鼻をすすって約束する。

「はい、そう言ってやります」

　ここに来た目的は流鏑馬の犯人逮捕を伝える他にもう一つあり、そちらの方がもっと大事だ。つまり重要な依頼事がある明が、姿勢を正して徐に依頼する。

「実は一つ折り入ってお願いがあるのですが」

　何でも聞く耳を持っている上機嫌の橋本が、にこにこ顔で言った。

「八幡宮のイメージを保てたんですから、わたしにできることなら何なりと」

　願いを聞いてもらえそうなので、ほっとした明は一歩近づいて話す。

「あす、ここの 舞殿 ( まいでん ) を少しお借りしたいのです」

　祈祷をしてもらいたいとか、破魔矢などのお札を頂戴したいという依頼だろう、と予想した橋本にとって、明の発言は意外だった。しかも 途轍 ( とてつ ) もなくでかい物を借りたい、と相手は言う。こんなことを初めて言われた橋本は、驚きを隠せない。

「えっ！舞殿を。いったい何に使うのです？」

　明は入念に考えた計画、相手にとっては突拍子もないようなアイデアを切々と訴える。

「先ほど話した若い男女が、犯人たちにマインドコントロールされてしまったんです。だいぶ回復しましたが、最後の決め手として舞殿で舞わせたい。自分を堂々と表現し、自信を持って前向きに人生を歩めるように」

　幼児用の本に出てくるファンタジー物語を思わせる解決策に、橋本は首を傾げた。

「そんなことで直るもんかね？マインドコントロールとかいうのが」

　組んだ両手を胸の前で振り、あすかが応援する。

「直ると思います、必ず！」

　あまりにも相手の負担が大きい依頼ごとは拒絶されるものだ。そこで、明は受ける側の立場も考えてある。

「勝手にこちらが踊るので、公に案内したり宣伝したりすることはいっさい不要です。ただ場所をお借りしたいのです」

　八幡宮の管理を預かるトップといえ、権限は限られている。各方面の人たちに相談する必要があり、引き受ければ引き受けたで仕事が入り込む。これは面倒なことだ。橋本は両腕を組み、頭を落として悩んだ。

　この二人は八幡宮の恩人だ。それも、素人でありながら機知を働かせ、敢然と悪に立ち向かって変事を早期に解決してくれた。その行動は宗教の真理を説く活動に匹敵する。この恩人を粗末に扱っては、 神道 ( しんとう ) への道を歩む者として失格、ここは微意を表すべきである、と橋本は考えた。

「前代未聞のことですな。･･････うーん、その若い二人とあなた方が尽力してくださったことだし、他の人に迷惑がかかることはない。わかりました、お手伝いさせてもらいましょう。わたしが関係者に相談してみます」

　明はほっとして頭を下げる。

「ありがとうございます」

　あすかも両手を合わせて続く。

「ありがとうございます」

　静の舞は年に一回だけ行われる古式ゆかしい行事であり、それを見学しに遠くから訪れる人もいる。映画のロケならまだしも、個人用に舞殿を使わせては格調が下がる。こう考え、依頼は断られる、と二人とも覚悟をしていた。幸いにも宮司の協力を取り付け、二人は手を組んで振った。

　舞の練習　

　病院に戻った明とあすかは医師の診断書を貰い、休んでいた直人と亜矢を引き取った。坐禅をして頭を冷やすことによって、死に直面した悪夢も拷問を受けた苦痛も薄らぎ、二人は明の携帯電話機を借りて自分の両親に無事でいることを伝えた。その話す声は力強く、態度は堂々としている。これなら普通の生活をしてよい、と考えた明は、二人を自分のマンションに連れて行き、一晩泊めることにした。

　まずは夕食となる。あすかが腕を振るい、もりだくさんの料理を作った。エビのケチャップ煮、肉ジャガ、手作りの白ソースがかかったチキンソテーと、味に定評のある国の料理をずらりと並べた。これには多くの食材の入った大きな冷蔵庫が役立つ。子供が生まれる前に奮発して買った物が、もう大活躍である。それに、ぴかぴかのシステムキッチンや新しいフライパンと鍋が、効率を高めてくれた。

　いろいろの国の味を楽しめたし、おいしかったことが効き、料理の統一のなさについては三人の文句が出なかった。それどころか、 忌 ( い ) まわしい事件から解放されたみんなは、お腹いっぱい食べて鋭気を養った。特に昼食抜きだった直人と亜矢は猛烈な勢いで食べ、それを明とあすかは嬉しそうに見ていた。

　食べ終わって手を腹に当てた直人は、いかにも満足な顔をした。

「御馳走さま。おいしかったです」

　亜矢は三種類の料理を立て続けに作ったコックに向かって褒め称える。

「あすかさんは料理が上手なんですね」

　あすかが作った料理を家族以外の人に食べてもらうのは、今週が初めてだ。その料理の腕をまず婚約者が確かめ、その明はプラス気味の得点を与えてくれたが、それはお世辞もあることだろう。第三者であるこの二人なら冷静な判定をしてくれる、と思い、あすかは客観的な評価を期待した。その結果が高得点と聞き、あすかは笑みを浮かべる。

「まだ修行中よ」

　婚約するとなると、女性は料理がうまくなるようだ。なぜなら、主婦は家庭のコックとして夫や子供たちに、食事の楽しさを与える必要がある。以後ずっと恩恵を受ける人を直人は 羨 ( うらや ) んだ。

「それにしちゃあ 上手 ( じょうず ) だ！明さんはこれから楽しめていいな」

　これも客人としてのお世辞とは思うが、フィアンセを高く評価してもらい、明もご機嫌である。

「こう褒められると、また呼んで御馳走したくなるな」

　あすかもすっかりその気である。

「そうよ、ときどき遊びに来てちょうだい。これでよければご馳走する」

　もうここの住民と十分心が繋がっている直人は、両手を高く上げて万歳をする。

「わーっ！嬉しい。お願いします」

　いずれは自分も台所に立つことが多くなる亜矢は、手を組んで頼んだ。

「作り方、いつか教えてください」

　これについてはいつでもオーケーである。あすかは微笑んで了承する。

「はいはい。講習料は無料ですよ」

　少しは謝礼をと予想した亜矢は、嬉しいサービスににっこり笑った。

　食事が終わり、お茶の時間となった。たっぷり食べたみんなの胃腸はフル回転し、代わりに脳は平和の世界に浸っている。少々眠気を催すが、まだ夜は浅い。頭が冷静になると、この二日間で起こったことを直人と亜矢は思い出した。

　直人の背中に手を当てて亜矢が案じる。

「どう、まだ痛む？」

　ワンワンと泣いては男が 廃 ( すた ) る。病院へ行く前までは人目を気にして、痛いのを我慢した。今は薬の効果によって痛みが取れ、緊張感も解かれている直人が正直に答えた。

「もう何ともない」

　拷問といえば、人間は様々な種類を考案した。体を叩いたり、重い石を腿の上に載せたり、体中に付けた蚊に血を吸わせてかゆみを発生させたりする肉体的な苦痛、食事を減らしたり、睡眠を妨害したりする生理的な苦痛、猛獣の檻に入れたり、額に水を一滴ずつゆっくり落としたりする精神的な苦痛など種類が多い。

　ほっとしたあすかが、直人を慰める。

「軽い傷で良かったね」

　明とあすかが来てくれなければ、直人と亜矢はいずれ生命を断たれたであろう。自殺を計った者といえ、他人に殺されるのはまっぴらごめんである。直人と亜矢は改めて二人に頭を下げた。

「ありがとうございました」

　何の情報も持たずに行動を起こすことは無謀だ。まして敵の巣に忍び込むことは、最たる危険である。明は有能な協力者がいたことを挙げた。

「『家の中を探して、二時には連絡をする』と亜矢さんが電話をしてくれたことが効いたな」

　一度はメモを捨てた亜矢は、それを書いて渡した人のことを失念していなかった。利発な亜矢が捨てたメモを拾い直したことが事件解決の第一歩になり、外に出て電話をかけたことが明の行動を呼び込んだ。褒められた亜矢は、照れくさくなった。そのときの実状をあすかが話す。

「そうよね、三時近くになっても連絡がないので、この人が行ってみたの」

　あのメモが自分たちの生命を維持させるとともに、事件の解決に大きく寄与した、と考える亜矢が、感慨深気に言う。

「おかげでわたしたち助かったし、変な術から抜けられました」

　亜矢と明の連携プレーで難局を 凌 ( しの ) げ、事件を解決へと導いた。一人では到底無理なことも、協力すれば可能となるのだ。仕事の上でもスポーツでもチームワークが重要な決め手であることを、みんなは再認識させられた。

　直人の体の状態ばかり案じていたが、生命の危機に見舞われた人がもう一人いる。それも、細い凶器で心臓を刺されそうになった者だ。今度は直人が亜矢の背中に手を当てて尋ねた。

「亜矢の背中に槍の刺し傷はあるの？」

　すっかり落ち着いた亜矢がとぼけて答える。

「刺さってたら、ここで大きい声上げて泣き叫んでる。『痛い！痛い！』って」

　まじめな亜矢が辛い素振りでした芝居がいかにも現実味を帯びており、みんなは声を上げて笑った。笑って済ませるということは、亜矢が無傷であったのだ。

　危機一髪の状態から起死回生を図った者を明は挙げる。

「あすかの物を投げるコントロール、見事。名投手だ！」

　確かにあれは 神業 ( かみわざ ) 的な美技だった。ぽいと投げただけで、動いている亜矢の背中と槍の穂先の間にバッグが入るのは極めて稀有なことで、コントロール抜群の野球の投手でも至難の技だ。何かのトレーニングをやっていた、と推察する直人は、あすかの技量が高い訳を知りたくなった。

「ソフトボールかバスケットボール、やってたんですか？」

　野球のピッチャーは上手投げ、ソフトボールの投手は下手投げ、バスケットボールのシュートは両手を胸の前に置いてボールを押し出す。それに対してあすかは腰から上方に向かって両手でバッグを放り投げた。ということはラグビーのパスをするフォームで、それは並みのラガーマンのパスを 凌駕 ( りょうが ) していた。

　あすかはいかにも神 懸 ( が ) かった口振りで答える。

「いーえ、亜矢さんの背中に偶然当たったのよ。大仏様が見方してくれたのかな？」

　天が善人に味方してくれることが実証され、みんなは肯いた。あれほど鮮やかに亜矢の背中に命中するとは、よほど運が良い。これはたくさんお寺を拝観した 御利益 ( ごりやく ) と思い、あすかは早速頂いた効果に感謝した。

　あすかのコントロールの良さを認める明は、牽制もする。

「その調子に乗って、家で鍋や皿を投げないでよ」

　牽制されたあすかは、すまして言い返す。

「普段はね」

　了解は条件付きだった。そこに明の新たな不安が生じる。

「また普段以外のときがあるってこと？」

　あすかは両方の人差し指を頭の上に置き、 角 ( つの ) の形を作る。

「こんなときはね」

　すっかり明に心を引かれている亜矢は、あすかを見るや泣きだしそうな目をして懇願する。

「あすかさん、旦那さんをあまりいじめないでください」

　亜矢は本気になって明を弁護した。これには、わたしの夫になる人に気がある、とあすかは一瞬思った。だが、それは自分の欠点、つまり嫉妬と思い直す。

「ふゝ、冗談よ」

　せっかく心を込めて忠告したのに、それは空振りだった。からかわれてむっつりした顔になった亜矢が、しおらしく言った。

「なーんだ、心配して損しちゃった」

　あすかの冗談を本音と受け取った亜矢を、みんなはお腹を抱えて笑った。もう心を許しあった四人は何でも言えるし、何でも聞ける。そして、おかしいと遠慮せずに笑えるようになった。

　夕食後お茶を飲んでいると、明の提案に呼応して動いた 宮司 ( ぐうじ ) の橋本から電話がかかってきた。明は持っていた茶碗を置き、すーっと立って受話器を取った。舞殿を借用する目途がついたとのことで、明は電話越しに丁寧にお辞儀をした。これで見込み発車をして宮司から借りたＤＶＤが役立つ、と思い、明はほっとする。

　直人と亜矢は食べたり飲んだりした食器やカップを流し台に持って行き、一緒に洗った。すっかり御馳走になり、少しはお手伝いを、と思って二人はやっている。このきびきびした動作を見て、直人が楽に動けるようになった、と明は判断した。そうなると、きょう最後の仕事にかかりたい明は、教材を手に取って宿題を課す。

「さあ練習してみるか。宮司さんに借りたビデオを参考にしよう」

　指導してくれる師匠は、この場ではＤＶＤだ。餃子の皮みたいの薄いプラスチックの円盤に、二時間も映像が記録されている。ビデオテープが円盤に進化し、大きさも重量も小さくなった、いわゆる軽薄短小だ。この文明の利器を利用することで、何とかなるだろう、と明は楽観的に考えている。

　ＤＶＤをプレーヤーで再生し、亜矢が舞の練習を始めた。四、五秒間テレビの画面を見て手足を動かす、次にテレビの画面を見る、真似て手足を動かす、この繰り返しとなった。スポーツにおけるフォームの研究の際、再生、一時停止を連続的に行う様に似ている。

　初めて舞う亜矢の動きは、予想したとおりぎくしゃくだ。次の動作が頭にないため、体を止めてはビデオを見る、そして、急に体を動かす。これでは日本舞踊の流れが損なわれる。物見 遊山 ( ゆさん ) の構えで亜矢を見ていた直人が、両腕を胸の前で折って批評する。

「しとやかな静とは違うぞ。立ち上がった熊っていう感じだ」

　酷評されて怒った亜矢が、人差し指を口に当てて言い返す。

「うるさいわね、初めてなんだから、外野席の人は黙ってて！」

　ここにも鬼はいた。あえなく返り討ちされた直人は、しょげかえった。怒る人、怒られる人を見て、明とあすかはくすくす笑う。

　何回か練習しているうちに流れが亜矢の頭の中に入り、横目で映像を見る回数が減ってきた。五秒に一回が、十秒に一回、更に三十秒に一回となり、顔の表情にも優雅さが感じられる。昔の日本の踊りは動作がゆったりとしていることもあり、最後にはＤＶＤを止めて亜矢は初めから終わりまで踊れるようになった。

　動作が身に付き、次はポーズだ。これを決めることも難しい。ここでの亜矢の意気込みはすごい。自殺しようとしたときのとろりとした目とは大違いで、目標を是が非でも達成したい亜矢の目は血走っている。熱が入った亜矢は、腕捲くりをして意気込みを表すまでになった。

　ここぞと思われる個所で、亜矢が手を静止させる。それを見てあすかが意見を言い、亜矢は手の位置を修正する。練習が進むと、たおやかな亜矢の踊りにスムーズな流れが伴い、一方ではぴしっとした静止も生まれて様になってきた。体の捻り方、止め方、手の上げ方、降ろし方、扇子の回し方、どれもビデオの映像と遜色ない身のこなし方だ。明は顎を手で撫でて感心する。

「ほう、何とかなるな！」

　身近な応援団がいた。前に冷やかした直人が、今度はネジを巻く。

「亜矢、その調子だ！」

　練習は順調にいき、タッチ交代となる。ここで大問題が発生した。残りの練習方法をどうするかだ。あすかは腕を組んで悩んだ。

「静の相手である義経の舞なんて、ないよね」

　そのことを承知で計画している明が、心配無用とばかりに提案する。

「能の舞を参考にしよう。そのＤＶＤも借りてきた。後は直人さんのアドリブだ」

　亜矢と違い、直人には踊りとか舞とかいう経験は、これっぽっちもない。上体を持ち上げ、直人はびっくり仰天した。

「ひゃーあ！踊りが苦手の俺にアドリブも？」

　ビデオの真似をするだけならどうにかなるが、即興の振り付けを交えるとなると素人にとって大変な負担だ。それをここでぼやくのは手遅れというもので、決定したからには前進あるのみだ。あすかが 怯 ( おび ) えている直人を宥めすかす。

「こっそりやるんだから安心して。音楽に合わせる必要もないし」

　直人に尚も不安が残る。最大の悩みはこれだ。

「八幡宮に参拝にくる人が『何やってんだろう？』と思って見るよね」

　失敗を恐れ、気 後 ( おく ) れしては成功というゴールが遠のいていく。勉学もスポーツも芸術も、挑戦してこそ道が開ける。自分の胸に手を当て、明がきっぱりと言った。

「それはある。後は度胸！」

　これまでは不安という消極的な力が働いて行動が制限されていた。今度、亜矢は拳を強く握り締めて意気込みを示す。

「そうね、三回も死ぬ目に遭ったんだから。･･････それを思えば、楽なもんよ」

　確かに亜矢は三度命を落としそうになった。一度目は自ら、二度目はこのあすかの手によって、そして三度目は尊敬する人を守るために。壊れやすい薄いガラスのような神経を持つ亜矢が、この事件を境としてふてぶてしさを有するとは、そばにいる直人も驚きだ。直人は亜矢の気構えに圧倒され、脱帽した。

「お前、すーっごい心境の変化だな」

　明とあすかを交互に見た亜矢が、悟った釈迦の顔をして言った。

「この人たちのおかげでね。結局、人間の弱い面は、自分の気持ちの中にあるってことがわかったの」

　まるで長い間、坐禅をしていた人の発言だった。亜矢が言ったとおり、人間は何とも弱い動物で、他人の意見に振られたり大勢の者が取る行動に合わせたりする。少し強い者が現れると、そちらになびいてしまう。

　堂々と主張を述べた亜矢に、あすかが拍手を送る。

「亜矢さん、それ、すばらしい悟りよ」

　この事件のおかげで強くなれた亜矢は、もうどんな悪の誘いが迫ろうとも断固拒否する自信を持てた。睡眠薬を不法入手したことで脅迫され、黙認する代わりとして金や体を要求されても、である。そのときは素直に罪を認めるつもりだ。また、看護の勉強を続けることに疑問が生じた場合、その迷いを押し返せる。亜矢は神仏から強い精神力を授かったのだ。

　直人と亜矢の二人合わせての練習が続く。踊る、少し休む、ＤＶＤを見直す、また踊る。真剣そのものの練習、それは心を豊かにする練習でもあった。こうして四人がエネルギッシュに舞に取り組む新居の夜が更けていった。

　朝刊　

　翌朝、明、あすか、傷が治癒した直人、それと、事件と舞の練習の緊張からすっかり解放された亜矢が、朝食を摂っていた。ダイニングキッチンの窓は東側に面しており、早朝から日差しが入って明るい。台所はこうであるべきで、新鮮な朝に暗い所で調理の仕事をしては気が沈む。

　 悍 ( おぞ ) ましい事件が解決し、重荷が取れたみんなの顔は晴れやかだ。これは服装に表れた。明はジェード色に山吹色の模様が入ったシャツ、あすかはパンプキン色のブラウスを着ている。問屋に荷物を置いている直人と亜矢は、前日の服装だ。まあ梅雨期だ、一日くらい同じ物を着ても汗臭くなることはないだろう。

　朝食のメニューはトースト、目玉焼き、ハム、サラダ、牛乳、ジュースの組み合わせだ。これは朝食のお決まりパターンである。軽めの食事ながら、栄養は揃っている。昨晩はあすかが作った御馳走をたらふく食べたので、朝はこのくらいが胃に優しくてちょうど良い。

　背中の傷が治りかけた直人と悪夢を忘れた亜矢は熟睡でき、爽やかな顔をしていた。話し方はしっかりしており、箸の運びも良い。十分練習して自信満々なのか、と思いきや、そこまで到達していない。不安はあるとして、うまくやれるかどうかは天に任せ、気楽にやろう、と割り切ったまでだ。

　食事が終わり、皿を片付ける。空いたテーブルの上のスペースに、明が朝刊を載せた。見開きに広げられた新聞がテーブルの多くを占領し、やむなく飲みかけのコーヒーが入ったカップは縁に追やられた。みんなは中央に陣取った紙面を四方から 覗 ( のぞ ) き込む。

　大見出しを指差し、明が早速事件の記事に触れる。

「〝鎌倉の悪徳商人　逮捕〟とある」

　ここ数日間のことを思い出した直人は、身震いをした。

「あそこの旦那たちは、とんでもない悪人だったんですね」

　既に新聞を読んでいる明が、捜査の途中経過を冷静に伝える。

「犯人たちは流鏑馬の殺人も密輸も、素直に白状したらしい。ほら、ここに書いてある」

　みんなが目を合わせた社会面のトップの記事に、数年前、善行を施していたころの勝の大きな顔写真が掲載されていた。これは不遇者を支援する人道主義者の顔であり、不義を働いた今の顔と比較すると変化がわかる。

　その写真の下には、見事に的が射られた瞬間の流鏑馬の写真も添えられており、更に「流鏑馬は継続」という文字があった。流鏑馬の廃止を案じていたあすかは、これで次回は安心して勇壮な行事を見物できる、と思い、大いに喜んだ。そうなると、次に犯人たちに関心を持った。

「彼らはどんな人間像なんだろう？」

「若い頃苦労した岩本夫婦は、店の経営を始めたころから、みなし子などを引き取っては従業員として働かせ、面倒をみていたようだ」

　一生の間、悪行を繰り返す者は少ない。大泥棒の石川五右衛門がじわじわと熱くしていく釜茹での刑に処せられた際「子供だけは煮えたった湯にさっと入れてくれ」と要請した伝説がある。子が苦しむ時間を短くしたい、という父としての愛情があったのだ。もっとも、自分だけ熱さを逃れるため、子供を下敷きにしたという逆の説もあるが。

　善意も持ち合わせていた岩本夫婦に、あすかは同情する。

「聖人の面もあったのか。それで、直人さんと亜矢さんも引き取られて･･････」

「そう、最近は他の従業員も悪事に利用されていたがね」

　堅い顔になった直人と亜矢は、霊玉に植え付けられた盛衰の歴史物語や、仕込まれた悪事を明とあすかに話した。網膜が映画のスクリーンに変化し、霊玉が勝手に映写機を回したこと、映し出された場面は源氏の将軍、しかも兄弟である二人を悲劇に追い込んだ鎌倉時代だったことなど、正常に戻った脳が覚えていることを二人はこと細かに伝えた。理論的に立証が困難な不思議な電波による映像は、どの場面もハイビジョン映像に匹敵する鮮明さとなっており、迫力ある音とともに直人と亜矢に映画を見るような鮮烈な印象を与えていた。言葉だけは知っているテレパシーを現実に体験し、直人と亜矢はその威力に圧倒された。

　教え込まれた歴史について、直人は真実を知りたくなった。

「亡くなった松谷さんの祖先は北条で、捕まった岩本の祖先が源氏と説明されたけど、ほんとですか？」

　歴史を持ち出して 手懐 ( てなず ) けるとは、岩本たちめ、うまくこじつけたな。歴史が専門である明は感心するとともに、にやっと笑った。

「それ、歪曲どころか、真っ赤な嘘だ」

　どうもおかしい、と思っていた。溜息をつき、 騙 ( だま ) された亜矢は反省する。

「やっぱり。･･････わたしたち、あの人たちを親切な人とすっかり思い込んでしまって」

　情けをかけてくれる人は全て善人だ、と考えた直人が、うな垂れて語る。

「マインドコントロールされ、言われることが全て正しい、と思い込んでしまった」

　最後の部分は興奮して叫ぶ。

「そして、あの日！」

　記憶が戻っている亜矢も、手を握りしめて言った。

「思い出した！あの流鏑馬の事件を」

　回想　流鏑馬　

　流鏑馬が行われた日、薄い茶色のシャツを着た直人と、ライトグレーのブラウスを着た亜矢が強いマインドコントロールをかけられ、それを解けてもらえない状態で会場に駆り出された。二人はまるで酔っ払いのようにふらふらしながら歩く。その場には水晶玉を隠し持ち、いつもの白装束から一般人が着る青いシャツに扮装した霊玉がいた。霊玉はしきりに誰かの名前を唱えながら 呪詛 ( じゅそ ) し、水晶玉越しに見える直人と亜矢に暗示をかける。屋外でも効果が適用される強い霊玉の催眠術にかかると、自分の意志は置き去りにされ、霊玉が指示するとおりに二人は手足を動かした。

　給水器の栓を捻って柄杓に水を注ぎ、それを射手に渡すのが直人の仕事だ。これは勝が流鏑馬の団体に強引に提案して作った役目であり、団体は「ありがたいことです」と感謝の言葉を述べて提案を受け入れた。岩本勝の名はこの辺ではよく知られており、何ら疑われることはない。

　観衆は矢の先と的を結ぶ直線に目を集中させており、それから外れるエリアには無関心だ。そんな中で的を射るとなると射手にストレスが生じ、待っている間に神経が高ぶる。そのため、深呼吸をして心を落ち着かせ「うまく当たってくれ」と射手は心の中で祈った。そうして待機していた射手に直人が柄杓を渡し、それを受け取った射手は口に当てた。冷たい水が干涸びている喉をすっと通り、実に気持ちが良い。喉が潤った射手は柄杓を直人に戻し、元気よく馬を馬場に進める。

　同様の行為が続けられたものの、最後の射手に渡す手順だけが異なった。大きな木の陰に隠れていた勝の手下が割り込んで来て、給水器の水を柄杓に注いだ後、隠し持っている瓶の中の液体を柄杓に入れた。その柄杓を直人に渡し、手下が威張りくさって命令した。

「行きな！さりげなくだぞ」

　「冷静にやるように」との霊玉の細かい指示も手下は伝言する。直人は柄杓を持って行き、これまでどおり待機していた射手に渡した。

「どうぞ」

　最後とあって、待たされた 射手 ( いて ) はいらいらが貯まっており、早速手を伸ばして柄杓を受け取った。

「気が張ると喉が乾く。これはありがたい」

　灼熱感に襲われていた射手は柄杓の水を一気に飲み干し、手で口を拭った。

「うまい！」

　水を飲んだ射手がさっと手綱を引くと、馬が歩みだす。 古 ( いにしえ ) の衣服を 纏 ( まと ) った馬上の射手の姿は雄々しく、さっそうと馬場に姿を見せると待ち構えていた見物人がカメラのシャッターを切った。人気俳優並みの扱いをされて嬉しい射手は、弓を掴んでいた手を強く握って奮起する。

「さあ、トリとして有終の美を飾るぞ！」

　時間が経過するにつれ、射手に異変が生じた。凛とした静止の姿勢を保っている射手は周りがはっきり見えるものだが、この射手は目の前がぼーっとし、映る物のピントが外れている感覚になった。昨夜、晩酌を意識的に控えている射手が、あたかも激しい二日酔いになったようで、馬の制御もままならない。それに観衆のざわめきが弱まって聞こえる。

「何だこりゃあ？目が霞み、耳が遠い」

　射手は目をぱちくりさせて視覚を取り戻そうとしたものの、効果は今一だった。スタートの位置に着いたこの状況ではカメラが回っており、弱気になって流鏑馬を棄権すると映画が中途半端になる。自分が最後だ、がんばろう、と射手は思い直し、心の中で気合いを入れた。

「困ったもんだが、行くか。はいよー！」

　射手は馬を駆け、弓に鏑矢を 番 ( つが ) えた。

　「両手を手綱から離した状態できちんと鞍に 跨 ( またが ) っていられることから、運動神経は大丈夫。これならどうにかなる」

　と呟き、射手は自分を奮い立たせる。

　一つ目の的をクリアし、喝采を受けた。自分の腕は確かで、次の的にも命中させる自信が高まる。さて二つ目の的の近くに来た。射手の視覚の神経がいっそう変化を 来 ( きた ) し、的が極端にぼやけて見える。不整脈の症状も起こり、焦りが募る。そのとき的の手前に閃光が放たれた。

「ここか！」

　眩惑した射手が閃光に向かって放った鏑矢は、椅子に腰かけていた松谷の喉に当たった。

　明がクールに解説を行う。

「一次的に視力を麻痺させる薬を入れ、直人さんを使って射手に飲ませた。そして、松谷さんの後ろに忍び寄らせた亜矢さんが、強力な光を放つ。そこへ矢が飛んだのさ」

　あすかの言い方は 憎々 ( にくにく ) しげである。

「そのために二人を引き取ったの？」

「そう。疑われた場合は二人に罪を押し付け、自殺させる」

　 狡猾 ( こうかつ ) な人間にいいように利用されたことを知り、直人は拳で膝を叩いて憤りを覚える。

「悪人め！」

　無差別殺人は別として、事件には動機があるもので、それは事件を解く鍵に通じる。特に松谷と岩本勝の関係は重要だ。亜矢は被害者に話題を移した。

「同じ商売をしている、と教わった松谷さんは、どんな人だったんですか？」

「お土産や工芸品を扱う問屋の主人で、最近は勝の問屋より業績を上げていた。勝は、自分の店が衰退するのでは、と恐れたようだ」

　経済上の競争は、自由主義のどこの国にもある。メーカーは他社より優れた製品を開発しようとしのぎを削っているし、デパートは売り上げを伸ばそうと宣伝合戦をしている。しかし、いずれも法律が許す範囲内での競争だ。その点について亜矢は不思議に思う。

「なぜ殺したんです？商売敵くらいでやるなんて、ひどい！」

　明はテーブルを手で軽く叩いた。

「そのとおり、それだけではね。勝たちは密輸をやっていた。松谷さんに商売で水を開けられ、売り上げを挽回しようと始めたんだ。自分が由比ガ浜で見た舟は、密輸船の荷物を移し替えているところだった。箱の海草は、そんなときに付着したんだろうな」

　話は飛躍し、しかも佳境に入った。関心が高まった直人は、体をぐっと乗り出す。

「それがどうして？」

　説明はクライマックスに達した。鼻を人差し指で触り、臭いを嗅ぐ身振りで明が事件のきっかけを語る。

「怪しい行為を松谷さんに嗅ぎ付けられ、やめるよう忠告された」

　推理を働かせた亜矢にも、結果が見えてきた。

「ばれる、と思って 殺 ( や ) ったんですか？」

「そういうことになる」

　直人と亜矢は悪人を善人と思い込み、 狡知 ( こうち ) に 長 ( た ) けた誘いに乗って問屋に行った。そして、その人を心から尊敬し、忠誠を尽して働いていた。誤った判断をした自分たちの非を、直人は悔やむ。

「ほんとに俺たちばかだったんだ。大人をすぐ信用して」

　大人はこの世界に多くいる。不用意に言った直人に、亜矢が鋭い視線を向ける。

「直人、ここの人たちは別よ」

　愚かな発言を反省する直人は顔を上げ、目の前にいる例外の人を見た。 脆弱 ( ぜいじゃく ) な自分たちを助けてくれた信用できる人もいる。直人は明とあすかという良き先輩の知己を得て、人間的にも進歩した。

「勿論だよ、亜矢」

　現代の事件の真相が解明でき、次は中世の疑問解明に入る。テレパシーによって見せられた歴史物語について、亜矢が怖々と尋ねた。

「あの店でいろいろ話を聞かされた鎌倉時代の出来事、それも偽りですか？」

　これについて専門家である明が、しっかりとした口調で説明する。

「岩本が源氏の子孫という話は嘘っぱちとして、〝吾妻鏡〟や〝愚管抄〟という史記に載っているので、事件そのものは 信憑性 ( しんぴょうせい ) が高い。霊玉とやらの話には、かなり創作も入っているけどね」

　事件の 顛末 ( てんまつ ) の話は、これで出尽くした。では、昔起こった事件の教訓は何か？女性を弁護したいあすかが、これを基に歴史観を語る。

「将軍頼家の暴虐ぶりに手を焼いた北条一門や政子だって、鎌倉を守ろうと必死だった、と思う。それと、実朝暗殺の首謀者は北条義時ではなく、三浦義村という説が有力なのよ。義村の妻が 公暁 ( こうぎょう ) の乳母だったからね」

　こちらは歴史が専門となれば、対象範囲が広い。明が重々しく言い切った。

「人を生み、人を殺す。また、善を生み出し、悪も生み出す。それが歴史だ」

　歴史における進歩と後退、平和という安息と逆の戦いという恐怖を啓示している言葉を聞いたみんなは、一瞬しーんとなった。良い方向へ進んでいる歴史は、その過程において谷間もあるものだ。これからは、そんな谷間はなくしてもらいたい、と誰しも熱望する。

　食事もお茶も終わり、いよいよ事件の結末の日が始まる。立ち上がった明が手を叩いた。

「さあ！八幡宮へ行こう」

　鎌倉に馴染んできたあすかは、立って 檄 ( げき ) を飛ばす。

「がんばってやってみましょう！」

　失敗することばかり考えていると、失敗が本当に現実化するものだ。フィギュアスケートの選手にトリプルアクセルや四回転ジャンプをする直前に迷いが生じると、タイミングが狂い、回転不足に陥るか着氷が不安定になる。うまくいくことを頭に描き、思いっ切り足を蹴った方が良い結果に繋がるという。

　直人は拳を握って覚悟を決めた。

「はい。心臓がドキドキしてるけど、やってみます」

　純真な乙女に戻った亜矢は、両手を頬に当てて顔を隠す。

「わたし、恥ずかしい。･･････でも、何とかなるよね」

　人の前に立って何かをすることは、確かに恥ずかしい。あすかも初めて教壇に立って生徒の方を向いた際、言葉に詰まったものだ。もじもじした気持ちを吹き飛ばし「みなさん、おはよう！」と大きな声を発したら、新しい先生の顔色を窺っていた生徒たちから「おはようございまーす！」という何倍も大きな声の挨拶が返ってきた。それで一瞬にして堅い雰囲気が解けた。

　あすかは亜矢の後ろに回り、両肩に手を乗せて軽く押した。

「今度は天が味方する番よ」

　慎重派でなかなか自信を持ちにくい亜矢は、あすかの励ましの言葉を聞いて勇気が湧いてきた。こうなったら突き進むのみ、と思い、亜矢は一大決心をする。

「はい、やってみます。・・・・・・見てくれる人は、いい人ですよね」

　舞の未熟さをなじる人はいるとしても、危害を加える人はもういない。自分の周りは全員味方と思う直人は、勇気百倍だ。

「よーっし！存分にやるぞ」

　歓談はここまでとし、マンションを出発した四人は陽気に歩いて鶴岡八幡宮へ向かった。直人と亜矢は摺り足で歩きながら、手を上げたり横に流したりして尚も舞の練習をする。近くにいる人に変な目をされることは、いっこうに気にしない。それを見て、ずいぶん神経が太くなったものだ、と思い、明は感心した。

　直人と亜矢の舞　

　天候は良く、新緑が映える青空の朝に、朱色に塗られた鶴岡八幡宮の本宮が 燦然 ( さんぜん ) と輝いてひと際目立つ。石段の上に建てられていることと、鳥居を過ぎると遮る物がないことによって遠くからもよく見え、いかにも鎌倉の顔といった感じだ。若宮大路を 俯瞰 ( ふかん ) しているこの壮麗な神社は、元は源氏の武士たちの守護神であり、鎌倉の守護神でもある。

　きょうもここを多くの参拝者が訪れていた。神社の参拝者に年配者の比率が高いのは肯ける。敬老会が主催する団体の観光客やら、定年後、神社仏閣を巡ることに生きる価値を見い出した夫婦が多くいる一方、若い人も結構集まっていた。歴史を勉強している修学旅行中の初々しい生徒や「歴史のことなら任してください」と言わんばかりの歴女まで、様々な年齢層の人々でこの場が構成されている。

「鎌倉幕府が開かれたのは･･････〝 いいくに ( ・・・・ ) 〟作るで、一一九二年（一一八五年説もある）」

　と声高らかに男の生徒が、記憶力の良いことをアピールした。威張ることはない、これは年表の中でもっとも簡単な覚え方で、中学生の誰でも知っている。

　宮司の橋本が関係者に依頼し、静御前の衣装などを借りてくれた。これは明とあすかも考えていなかったことだ。現代の衣服で鎌倉時代を思い起こさせることは難しいため、この好意は嬉しい。

　白拍子の衣装に着替えた亜矢が南側の小さい階段を 上 ( のぼ ) り、高さが一メートルほどある舞殿にしずしずと登場した。 水干 ( すいかん ) に袴を身に付け、頭に立烏帽子を載せている。下げ髪こそ事件の日に見た踊り手の髪の長さに比べ短いが、亜矢は髪を後ろに垂らして雰囲気を出している。腰に太刀を差した男装の姿となっており、細身の若々しい体と香りを感じる端正な顔は、女らしい美しさがある。凛々しさと優美さ、その両方を亜矢は表していた。

　緊迫した空気の中、笛や鼓などの伴奏音楽を全てカットした状態で、亜矢が踊り始めた。まずは体をゆっくり前へ進め、次に手を 翳 ( かざ ) したり体を回したりする動作に移る。西洋のダンスと比較すると動作が遅い日本の踊りには、優美な 和 ( なご ) みが存在する。

　無伴奏の舞では舞台が静かで、衣服が床を 擦 ( す ) る音がよく聞こえる、と思いきや、それは雑踏の音にかき消された。参詣者の目は舞殿を通り越して奥に見える本宮や大イチョウに向けられ、口はそれを見た感想に使われている。中央に位置する建物といえ、事前の宣伝のない舞殿に注目する人は少ない。明とあすか、それと偶然舞殿に目をやった数人だけが、じっと亜矢を見守った。

　二、三分もすると舞殿の周りに人が集まった。自己顕示欲の強い人間が、のこのこと登場してファッションモデル気取りで衣装を見せびらかしている、と彼らは推察する。ここの神社で結婚式を挙げた花嫁が、お色直しをして華麗な姿を披露している、と推察する者もいた。だが、どうも違うらしい。素人風な若い女ながら立派な舞で、しかも腰に刀を差している。これは見る価値がある、と思い、参詣者たちは関心を寄せることになった。

　八幡宮の巫女たちも、毎年行われる催しとは一味異なる舞を社務所から固唾を呑んで見ていた。着物を着せるのを手伝った彼女たちは、亜矢の美しさに溜息をついた。そうなると、舞っている姿も見たくなるというものだ。

　 骨 ( こつ ) を掴めばこなせるもので、小学生のころバレエを習っていたという亜矢の身のこなし方、足の運び方は、日本舞踊にも通じた。要はいかに体を滑らかに動かし、姿勢の美しさを表現するかである。プロの格調ある身動きと差はあるとして、そこそこの踊り手だ、と良い方に間違える見物客が多くいた。

　華やかに踊っていた静御前は、離れ離れになった義経のことを思い出した。兄頼朝に追われた義経様は、どこへ落ち延びて行ったのだろう？「しずやしず　 賤 ( しず ) のおだまき繰り返し　昔を今に　なすよしもがな」の歌の意味を噛み締め、静御前は叶わぬ義経との再会を望んで悲しい表情を作る。

　リアルになってきた亜矢の踊りに、あすかはうっとりとする。

「見事ね！」

　思った以上の表現力に、明はほくほく顔だ。

「一夜漬けにしては上出来！それに、綺麗だね。彼女、まるで静の乗り移りだ」

　過大評価する明に対しては、あすかの得意な嫉妬が再現するというものだ。

「やっぱり亜矢さんに、気があるんじゃなーい？」

　あすかの性癖を思い起こした明は失敗に気付き、 急遽 ( きゅうきょ ) とぼける。

「あっ！焼き餅焼きの人がそばにいたんだっけ」

　にやっとしたあすかは、明の肩を指で小突いた。

「とっても嫉妬深い人がね」

　白のシャツに紺色のスカートの制服を身に付けた修学旅行中の女子高校生たち数人が、明とあすかのそばにやって来た。今から三十分間は自由行動だ。石段の上の八幡宮まで行ってみたいが、目の前の舞殿で何かある。やや遠くの上方を見ている明とあすかに感化され、彼女たちもその方向に目を向けた。

「あれなーに？」

「舞だよ」

「きょう、それをやるなんて、予定にあった？」

「わたしたちに見せようと、特別にやってくれたのかな？」

「そんなこと、してくれっこない」

　若い娘が数人寄れば賑やかだ。 古 ( いにしえ ) の舞を 彷彿 ( ほうふつ ) とさせる亜矢を見た高校生たちは、周りの人がいることも気にせず絶叫する。

「ねえ、見て。あれ静御前。すーっごく綺麗！」

「義経と別れて悲しみに暮れてるとこよ。うまいな！」

「ハートが痺れちゃう」

　胸の前で手を組んで見ていた女子高校生たちの心臓が、しだいにどきどきしてきた。まるで憧れている人気俳優に会って陶酔している心地だ。自分もあんな衣装を身に付けて舞台に立ってみたい、と欲を出す者もいる。

　緑色の 直垂 ( ひたたれ ) の衣装を身に付け、黒い侍烏帽子を冠った義経役の直人が、そろりと舞台に現れた。どうやらこの衣装は、審判員の物を借りたらしい。実際の義経はかなり荒武者だった、という説もあるが、映画や芝居では美男子が役を努める。そういうことからすると、直人は適役だ。その現代版義経が、気落ちした静の後ろから声をかける素振りをする。

　亜矢と比較して、アクションが少ない直人の踊りは簡単であるが、静を思う気持ちの表現は難しい。直人は自殺しかかった亜矢を案じたときの心情を思い出して踊った。感情が高揚してきた直人のしぐさは、真に迫っている。

　女子高校生の目が直人を捕らえた。

「あれー！男が現れた」

　ませた女子高校生の推測は早い。

「きっと義経よ。だって愛のしぐさだもの」

　予定外のイベントを見て、はしゃぎは拡大する一方だ。

「わー！すーっごくかっこいいじゃん」

　興奮した者は小さく跳ねて言った。

「義経も見れるなんて、かんげきー！」

　義経に誘われて表情が明るくなった静は、義経の胸に顔を埋める。夢か幻か、和歌に託した願いが叶った。これは歴史の事実と異なるハッピーエンドの場面である。

　二人は手を取り合い、晴れやかに、かつ、威勢良く踊った。正に事件解決後の直人と亜矢である。いつしか舞殿の周りにたくさんの人が集まると、 固唾 ( かたず ) を飲んで二人を見た。その代わり、本宮の近くは人がまばらになった。

　あすかが付け足しのストーリーを説明する。

「奥州で亡くなった義経は、静の愛の舞によって生き返り、結ばれる」

　映画では、制作に関わったスタッフの名前が字幕で表記されるが、ここでは、明が口頭で舞の振付師を紹介した。

「あすかの考えた〝新 義経記 ( ぎけいき ) 〟だ」

　オリジナルかというと、これには参考文献ならぬ、参考話があった。得意そうにあすかが、ネタの出所を披露する。

「みんな判官 贔屓 ( びいき ) 。義経は蒙古へ逃げ延びて生きていた、という伝説があるから、このくらい創作していいよね？」

　歴史学者は事実のみを認めるのが商売だ。その明がここでは妥協する。

「まあね」

　「マインドコントロールを完全に解くために、直人と亜矢に舞わせたい」と明は言った。今考えると、あすかには別の目的もあるように思える。

「結婚の儀式のつもりで、二人にあの舞をさせたんでしょう？」

　推察された明は、とぼけて逆に聞き返す。

「さあ、どうかな？･･････なぜそう思った？」

「二人は家出して問屋で同棲中、それに、亜矢さん『妊娠してる』と言ってた。こんな状態では、晴れがましい結婚式は無理。その代わりにと、舞を考えた。マインドコントロールを解く理由なら、舞台を貸してくれる、と見込んでね」

　さすが我が妻になる人と思い、明は舌を打って感服した。

「見事に読まれたか。偉い！」

　こういった配慮をする明を、あすかは誇らしく思った。

　社務所の中で袴姿の橋本が、二人の客を迎えていた。実名は伏されていたものの、事件を解決に導いた市民がいる、と新聞に掲載されていた記事を見た二人は、どうしてもその人の名前を聞き、会って礼を言いたい、と思って、宮司に相談に来たのだ。ちょうど良いときに来てくれたことを橋本は喜び、二人を舞殿に促した。

「その人たちが見えていますよ。さあ、行ってみましょう！」

　橋本が歩きだすと、神妙に構えていた二人は後に付いて行った。二人とも、きのうは最悪の日だった。一方は親を殺害され、他方は殺人の嫌疑をかけられた。こんなことは一生のうちで一度だけでよく、新たな苦境が続いては困る、と二人は思っていた。

　借りた衣装を巫女が着付けする様子を見ていた明とあすかは、準備が整うと舞殿の前に行って人混みに埋もれたので、その辺まで来るのはよいとして、大きく太い輪のどこに明とあすかがいるのか橋本はわからない。困った、と思い、じろじろと舞殿を取り囲んだ人の顔を 覗 ( のぞ ) きながら橋本は回った。人を掻き分けて進み、ちょうど半周した所で明とあすかを発見した橋本が、声をかけた。

「お 二方 ( ふたかた ) 、ここにおられましたか？」

　言い出しっぺの明が、冷や冷やしながら本音を漏らす。

「えゝ、どうなるか心配ですのでね」

　明を探している間に舞も見ていた橋本は、亜矢と直人の踊りを率直に評価する。

「なかなかうまいもんですな。『来年の本番にもお願いしたい』と声がかかりそうですよ」

　亜矢が片腕を水平にし、もう一方の手で扇子を斜め上に 翳 ( かざ ) すポーズを取った。こんなことはないだろうが、鶴が羽ばたいて片側の翼だけが反対側より高く上がった形だ。その姿の美しさに、見ている者たちは思わず唾を飲んだ。嬉しいあすかの口からジョークが発射する。

「二人に出演オーケーかどうか、聞いてみましょうか？」

　気が晴れている橋本も、ジョークで対抗する。

「ぜひそうしてください」

　逆に明はまじめである。

「宮司さんから讃辞をいただけるなんて、二人は喜ぶな」

　舞の鑑賞の話はそこまでとして、橋本が連れてきた男に手を向けた。

「こちら、当日流鏑馬の 射手 ( いて ) となった浅井さんと、亡くなった松谷さんの長男の透さんです」

　浅井は大柄な割に気が小さい男だった。不惑の四十代の大人も自分が射た矢で人を死に至らしめたとあって、びくびく震えつつ一夜を過ごした。その思いが丸めた背中に表れている。ブロンズ色のシャツを着た浅井が、深々と頭を下げた。

「浅井と申します。『故意でやった』と警察に疑われ、事情聴取されましたが、あなた方のおかげで殺人の汚名を脱いで暮らせます。ありがとうございます」

　馬を 駆 ( か ) ることができる人は少なく、まして疾走中に矢を射るとなると、更に限られる。その貴重な人が悪巧みによって減っては、鎌倉の名物行事が危うくなり、鎌倉市民になりたての明としてもそれは心苦しい。流鏑馬の大ファンである明が、浅井の手を取って言った。

「流鏑馬の名人として、また活躍してください」

　手を握り締めてあすかも依頼する。

「そうですとも。日本の良い伝統は、しっかりと守っていただきたいです」

　浅井は乗馬が好きだった。賢い馬は乗り手の気持ちを察して行動する。堂々としている乗り手には服従して 手綱 ( たづな ) 捌 ( さば ) きどおりに動き、いったん走れば自動車と同じくらいのスピードとなる。鞍の上に乗って風を切るのは実に爽快、更に馬上から矢を放ち、それが的に命中すれば最高の気分になれる。

　逆におどおどしている乗り手は、馬に知らんぷりをされる。この状態で「走れ！」と怒鳴っても、気分が乗らない馬はよそ見をしてちんたらちんたら歩く。馬を操るのは女房を操るのと同じで難しい、という誰かの言葉もあるほどだ。

　浅井は目を潤ませて答えた。

「光栄です。がんばります！」

　松谷透も深く頭を下げた。明と同じ年代の透は小柄ながらさっそうとしており、希望溢れるタイプである。服装はいかにも自信家らしい琥珀色のシャツだった。 明日 ( みょうにち ) の通夜、 明後日 ( みょうごにち ) の告別式を控えている透は、どうしても礼を言いたくて、ごった返している家を抜け出して来ている。

「父の無念を晴らしていただき、ありがとうございます。今後は父に代わって鎌倉を訪れる人のために、良い土産や工芸品をしっかり商っていきます」

　全員逮捕の岩本の問屋は閉鎖された。松谷の後継者も絶えると、鎌倉は大変なことになる。妹に記念となる品を買ってやろう、と考えている優しいお姉さんや、あすかのように両親にお土産をと考えている大人は困り果てることだろう。どうやら子息が問屋を守ってくれることで、観光客の悩みは避けられそうだ。

　明が胸を叩いて激励する。

「がんばってください。心強い問屋さんがいて、これで鎌倉も安泰です」

　あすかは自分が買った品物を、他の人にも買ってもらいたい。

「見事な鎌倉彫も扱ってくださいね」

　自分の店を宣伝する商売っ気がある松谷は、胸を張って答えた。

「えゝ、うちの問屋もいい鎌倉彫をたくさん扱ってますよ」

　鎌倉の繁栄は八幡宮の願いでもある。それを預かる橋本は、手を叩いて喜んだ。

「嬉しいですな！この鎌倉を盛り立ててくれる人がいて」

　舞が終わった直人と亜矢は手を取り合い、舞殿の縁を一周した。建物の端に爽やかな若者の顔が現れたとき、周囲の人たちの溜息が出た。それが落ち着くと、誰が何のために舞っていたのかわからないまま、素人の真剣な踊りに心を打たれたみんなが盛大な拍手を送った。急遽開催された舞が見られ、きょうは得をした、という顔をして。

　映画の撮影のために出演した踊り手は、静の舞に熟達していた分、年齢も上だった。初々しさに満ちている亜矢は、実際の静の年齢に近いこともあり、本当の静がいる、と明に思わせた。これが映画になったら、観客が殺到する、とプロデューサーの考えを明は 覗 ( のぞ ) かせる。

　最初は冷や冷や、後半はうっとりとして見ていた明とあすかは、手を高く上げて振った。明は声高らかに叫ぶ。

「ブラーヴィー！たいしたもんだ」

　舞の成功は精神上の成功でもある、とあすかは思う。

「すーっごく自信付いたよね」

　橋本、浅井、松谷を含む判官 贔屓 ( びいき ) 、かつ、静贔屓の五人は、多くの人たちに交じって拍手をし、過大評価された直人と亜矢は二人に向かって会釈をした。それぞれの顔には「やりましたよ」と「ご指導、ありがとうございました」という意味が込められている。素人の二人がカーテンコールに応じることはない。参詣者たちに祝福され、手を組んだままの二人が仲良く舞台を下りると、舞殿は寂しくなったものの、それでも、その周りではしばらく拍手が続いた。

　明とあすかは、舞殿を使用させてもらった感謝の意を宮司の橋本に述べ、借用したＤＶＤを返却した。こんなＤＶＤを一晩見ただけで、あれだけ見事に踊れたことに橋本は感嘆するばかりで「来年の本番にもお願いしたい」と前に言ったことが冗談でなくなったようだ。浅井も透も同感だ。若い者が気持ちを込めてやれば、かなりのことができる。自分たちも精一杯がんばろう、と思い、二人は奮起した。

　 自首　

　元の服に着替えた直人と亜矢を、明とあすかはマンションに連れて帰った。高い所、多くの人のいる所で全身全霊を傾けて舞った緊張と興奮が、二人に尚も継続している。何しろ目立つ舞殿で大それたことをしでかした。冷静になってここで振り返ると、二人はぞっと寒気がする。

　慣れてきた部屋に入り、直人と亜矢はくつろいだ状態になれた。それには別の訳もある。明とあすかが坐禅を教えたのだ。病院で行ったときには効果が半信半疑だった瞑想を再度行った結果、直人と亜矢は平常心に戻り、この二十分間で坐禅が精神を良い方向にコントロールしてくれることを十分認識できた。

　心が落ち着いたところで、全員で昼食の準備を始めた。直人がエビの殻を剥いてヌードにし、それをあすかが油で揚げて天ぷらにする。追いはぎに遭ったうえに釜茹での刑に処せられるとは、エビは岩本一家同様地獄行きだ。

　明は日本そばを茹でる。これは一番簡単な作業で、沸騰したお湯の入った鍋に細い棒状のそばを放り込み、後はときどき掻き回すだけだ。その間に亜矢はトマト、キューリ、茹でたアスパラガスにシーチキンを沿えたサラダを作る。こうして四人で食事を作っていると、家族の喜びを感じ取った直人と亜矢は、いつか自分たちもしっかりした家庭を築き、おいしい物を作りたい、と思う。

　みんなが手分けをしたので早くでき上がり、ゆっくりと天ザルの昼食を摂った。舞を無事にこなして自信が付いた直人と亜矢は緊張が 解 ( ほぐ ) れ、朝食よりたくさん食べた。舞ったことにより自分らしさを取り戻せるとともに、どんな誘惑にも対抗する強い力を得た喜びが二人にはある。すっかり自信が付いたとなれば、食欲も旺盛だ。

　一時間くらい休んだ後、直人と亜矢は明とあすかに別の所へ連れて行かされた。そこは前に地図で確認した場所で、位置は掴めている。その場所とは舞殿の華やかな舞台と正反対の鎌倉警察署であり、そこに行くことを予約しているので前にジョークで言ったとおりになった。その警察署の前に立った明が、二人に 毅然 ( きぜん ) として言い渡す。

「事件も再起も完結だ。さあ、勇気を出して行くんだ！」

　三か月前の教育者の顔に戻ったあすかが、力強く独自の主張をする。

「人間は自分の使命を全うするまでは死ねない。あなたたちは、生育してくれた両親や社会によってここまで大きくなった。今度はあなたたちが、両親や社会のために尽す使命があるの。それを逃げての家出や自殺は、卑怯者のすること。･･････まだ若いんだから、必ず立ち直ってね」

　自分たちは不運を理由に社会から逃避し、放縦な生活へと傾いていた、と直人と亜矢は考える。その社会とは、秩序や治安を維持する国や地方自治体であり、鉄道、道路、上下水道、電気、ガス、通信、放送、教育環境などを構築した国民が生活する場である。それらから空気のように当たり前のものとして、恩恵を受けていた。こんな状態の社会に仕上げるには膨大な費用と多くの年月が費やされており、先人たちや両親がその一役を担っていたのだ。

　直人は頭を下げて素直に従う姿勢を示す。

「そうします。ありがとうございました」

　叱責されたようでもある亜矢は、涙ぐんであすかの意を組み入れる。

「親の説教よりもきつーい。これまでで一番きつーい。･･････けど、ほんとによくわかりました」

　退職した後に昔取った 杵柄 ( きねづか ) を発揮したあすかを見て、にやりと笑い明が種明かしをする。

「あすかは、この前まで学校の教師をしてたもんな」

　直人は小学生のころを思い出した。話がうまかった担任の女の先生は「嘘つきは泥棒の始まりですよ。小さい嘘ならいいだろう、と思ってやっていると、だんだん大きいことが平気になっていきます。だから、最初に悪を退けることが大切です」と教えてくれた。理路整然と語ったあすかが、その先生に似ている、と直人は思う。

「なーんだ、そうでしたか。それで諭すのがうまいんだ」

　あすかは亜矢に手を向けて希望を持たせる。

「それと、あなたたち、 二十歳 ( はたち ) 前でしょう。そのお腹の子供が十歳になるとき、あなたたちは三十。もし生まれる子が男の子だったら、直人さん、百メートル競走でまだ勝てるかもよ。女の子の場合は、亜矢さん、お母さんの気分とお姉さんの気分、両方味わえる」

　強気の明もこの件については素直に負けを認める。

「そんなこと、僕らの年代じゃあ無理だもんな」

　意気込む直人は、短距離競走で両腕を振る真似をして言った。

「俺、百メートル、速いんだ。よーっし！十歳の子を負かしてやる」

　血縁関係を修正するという未曾有のことを、亜矢は浮き浮きして話す。

「わたし、一人っ子できょうだいの味、知らないの。そうだ、子供に『お姉さーん』って呼ばせちゃおう！」

　直人と亜矢は、生まれてくる子供の夢を追ってみた。明さんやあすかさんの成熟し、完成された精神と比べると、自分たちは子供みたいなものだ。そんな子供が親になったら、どうなるだろう？落第生の親になるかもしれない、いや、少しは親らしくなって、自立できるだろう。だって、子供にいろいろ教えてやるには、親として見本を示す必要がある。子供に教えることで、親も成長していける。舞が何とか成功したと同様、親としての仕事も成功する、と二人はこれまでの悲観的な思考をポジティブ思考に転換した。

　再び現実の世界に戻った直人が、感謝の気持ちを込めて挨拶をする。

「じゃあ行ってきます。お二人の結婚式を俺たちお祝いできるかどうかわかりませんけど、お幸せに」

　逆に亜矢はあすかの近い将来を期待する。

「あすかさん、いい子を産んでください」

　昔、殿様はお家存続のため側室を何人も抱えていて、彼女たちは、早く 後 ( あと ) 継 ( つ ) ぎを出産する、という競走のトラックに置かれていたことになる。自分がその側室に加わったわけではないが、若い亜矢に先を越されるあすかは、照れて答えた。

「芽はまだだけど、がんばってみる」

　いかなる罰が下ろうとも、それを受け入れて立ち直ろうとする直人と亜矢は、警察署の入り口へと向かった。舞殿での足の運び方は摺り足だったが、ここでは高く足を上げ、踏み出す力も強い。建物に入る直前に立ち止まった直人と亜矢が振り返って見ると、明とあすかがにこやかな顔をして見送っている。

　世の中で冷遇されていた自分たちを、明さんとあすかさんだけが高く評価してくれた。直人は拷問にも口を割らない勇気を称えられた。亜矢は容姿について周囲の人に褒められたことは多いが、人間性について評価されたことは初めてだ。つまり明さんとあすかさんは、社会の悪を拒絶する強い意志を褒めてくれた。その他人である二人が、最後の最後まで自分たちのことを案じている。二人の姿を確認した直人と亜矢はまた歩き、堅固な建物の中に入った。

　あの直人さんと亜矢さんはお互いに信頼し、愛し合っている。それはこちらも同じ、と明とあすかも思う。この事件により、明はあすかの、あすかは明の人間としての良さを再認識した。怖い思い、辛いことはあったものの、これは大きな収穫だ。

　じっと二人を見守っていたあすかは、鎌倉に来た日のことを思い出した。

「紫陽花寺にいたときとは、表情がまるで違う。大丈夫よね？」

　晴れ晴れとした明は、本当に最後となる行動を提案する。

「うん、もう立派な大人だ。良かった、良かった。さあ、もう一度八幡宮へ行って、お祈りしてこよう」

　何度も行くことには足が疲労するが、大きなけじめが付いたとなれば八幡宮に感謝し、この先のことを祈りたい。

「そうね、あの二人と、わたしたちの幸せのために」

「それ終わると、静岡へ帰る時刻だ。･･････次はいつ来る？」

　来週また来たい気持ちを抑えてあすかは答える。

「二週間後でいーい？」

　益々好きになったあすかと、二週間も別離状態となるのは辛いことだ。そうかといって、既に婚約しているあすかが、遠方より毎週来るのは負担になる。明は渋い顔で言った。

「ちょっと長いけど･･････まあいいか」

　あすかも我慢することにし、待つ辛抱は会うときに喜びを倍増させてくれる、とこちらも前向きに考えた。

　大イチョウ　

　二人は若宮大路の道を歩いた。鎌倉時代既にあったこの道は、八幡宮を起点に海岸線に向かって垂直に伸びる鎌倉のメインストリートで道幅は広く、中央には安全地帯がある。そこからは北の方向に赤い鳥居が見え、まっすぐ進めば八幡宮に辿り着く。

　あすかの諭しが気に入った明が、感心して褒め称える。

「あすかの話、なかなか説得力があったよ」

　この一週間に怖いことも辛いこともあった代わりに、得るものもあった。ほほ笑んだあすかが、隠していたことを紹介する。

「それが坐禅をしたわたしの悟りなの」

「えっ！悟り？」

　歴史の教師をしていたあすかは、伝記本をかなり読んでいる。その対象となると日本人は勿論、外国の人もそこに含まれる。それらの人物の業績を授業に活用したあすかは教師の気分に戻り、淡々と英雄と芸術家の例を挙げた。

「そう、源義経は三十歳、北条時宗は三十二歳、坂本龍馬は三十二歳、モーツァルトは三十五歳、シューベルトは三十一歳、ショパンは三十九歳、みんな極めて短命だった」

　これだけ並べられると、明は気味が悪くなった。

「全員三十代の若死にだ」

　あすかはそれらの人を代表して言った。

「そうかといって、使命をやり遂げるまでちゃんと生きてる」

　義経は平家を滅亡、時宗は襲来した蒙古を撃退、龍馬は薩長同盟を仲介、モーツァルト、シューベルト、ショパンは独自の美を有する音楽を残した。

「なるほど！自分の役目を果たしたり、自分の芸術を確立したりした後に亡くなってる」

　身を引き締めたあすかが、偉ぶって宗教論もぶつ。

「仏教では 現世 ( げんせ ) を空虚なものとしているけど、わたしも土に返るまでに何かを成し遂げたい」

　生きている間に呼吸をし、物を食べては寝る、それを死ぬまで繰り返すのが動物だ。人間であるからには、他の動物とひと味違うことをしたい、とあすかは考えた。仏になったようなあすかに、明は目をぱちくりさせた。

「 凄 ( すご ) い悟りだ。それで、あすかの使命は？」

　当人はいたって平静に答える。

「天才と違うわたしには、大それた使命はない。ただ･･････」

「何？」

　少し身を引き締め、あすかは堂々と宣言する。

「あなたの歴史の研究を助ける。そして、子供が生まれたら、一人前の社会人に育て上げる。子供がいつかちゃんとした考えを持てる年齢になったとき、歴史の教訓を教えてあげること。以上！」

　一一九二年に鎌倉幕府が創設された、とかいう歴史の出来事は、八幡宮で修学旅行の生徒が唱えていた例が示すとおり、学校で教わる。だが、それだけでは単なる年表の暗記だ。どういう背景でそれが生じ、真の目的は何だったか、どういう影響があり、どんな絡みがあったかを知ることが重要だ。そうすれば歴史が教訓となり、自分の人生に生かされる、いわゆる温故知新だ。例えば、先に挙げた頼朝と義経の確執の経緯や、義経と共に平氏打倒に尽力した和田義盛が北条義時の挑発に乗り滅びたこと、日清戦争や日露戦争での勝利の美酒に酔い続けた日本が、米国などの諸国を敵とする第二次世界大戦に足を踏み入れたことなどである。

　明はあすかの肩を軽く二回叩いた。

「あすか、それだって立派な使命だよ」

　思想は交わる人間によって影響を受け、交わる人間は〝出会い〟によって決まる。

「ありがとう。あなたに巡り逢え、坐禅をしたのでこの使命が決まったの」

　明は深く肯いた。あすかを立派な人間と認めると同様、あすかも自分を認めてくれている。これは嬉しい限りだ。 急遽 ( きゅうきょ ) 押し付けた坐禅で、こうもしっかりした悟りを得たあすかを明は誇りに思い、あすかの使命が達せられるよう自分も努力しよう、と決意を固めた。

　自分の主張を言い終わったあすかは、直人と亜矢のことが気になった。

「ところで、二人の服役、何年くらいかな？」

「何年だと思う？」

　裁判官や弁護士ならまだしも、これはあすかにとって難しい問いだ。手を顎の下に当てて考えたあすかの答えは単純だった。

「そうね、直接殺害していないけど、加担したのだから一年くらいってとこ？」

「残念」

「では、何年？」

　無表情な明が一言だけ発する。

「 無年 ( むねん ) 」

　これは変な言葉だ。眉をしかめてあすかが問い詰める。

「何？」

　全てを解決してほっとしている明のとぼけがエスカレートする。

「何年かって？･･････無年だよ。あすかは外れて〝残念無念〟」

　高尚な使命論から急転直下ジョークに話題を変えた明に、あすかは 御冠 ( おかんむり ) である。

「 洒落 ( しゃれ ) 言ってる場合じゃないでしょう」

　あすかは明の手の甲をつねった。真実を言った自分にお仕置きとは心外だ。漢字はいろいろの読み方がある。「それを理解してくれ！」と明は言いたげな顔をした。

「いててっ！洒落とは大違いだ。〝無し〟と書く無年、つまり、ゼロ年。服役はなしさ」

　 騙 ( だま ) されたとしても、犯罪に加担した者は罰を与えられるであろう。不思議そうな顔をしたあすかが攻め寄る。

「どうしてあなたがわかるの？まだ自首したばかりよ」

　そうか、そのことはまだ話してなかったか。ここで明がにこやかに根拠を説明する。

「実は逮捕の指揮を取った警察署長が、母方の叔父に当たる人でね」

「へーっ！そうだったの」

　一介の大学講師が単独で大事件に向かい合うことは、とても無理である。明には強力な味方がいたのだ。

「岩本の店が怪しい、と疑って以来、叔父と連絡を取り合っていたんだ。警察も岩本に目を付け、秘かに捜査をしていた。かなり確信を得られるところまでいき、家宅捜索のための令状を裁判所から貰っていた」

　そこまで操作が進展していたとなれば、あすかはもっともな注文をする。

「もっと早く捜索して欲しかった」

　これには訳があった。それをここで明が冷静に語る。

「警察は荷物が多く入る日を狙ってた。きょうがその日だ」

「えっ！」

　ここで明は仮定を立てた。しかも、恐ろしいことを。

「もし亜矢さんが連絡してくれなかったら、証拠は別の場所に移されているし、自分と直人さん、亜矢さんの三人は死体となって海の底に沈んでいることだろう」

　あすかは明が海底に沈んでいる姿を想像してみた。死後も明がわたしのことを思っていてくれる、とまずは都合良く考える。それとは逆に、亜矢さんと一緒にあの世に行った場合、亜矢さんと結ばれる、という例の嫉妬も出た。そう考えると、やはり明が生きていて良かった。

「きのう直人さんと亜矢さんが地下室を発見してくれ、明が乗り込んで何とかなったわけね？」

「そう、二人は立派。僕も見直したかい？」

　一介の助手たる明は、名探偵の働きぶりをした。明を見直したあすかは、すまして称える。

「残念なことに、予想以上の人でした」

　半分嬉しそうな、半分渋い顔を明は作る。

「残念は余計だな。･･････話を戻そう。電話で叔父に相談してみたんだ。『彼らはどれくらいの罰か？』って」

「それで？」

　社会的に 蔑 ( さげす ) まされた二人に同情しているのが明だ。

「あすかがさっき言ったとおり、直接殺害したわけではないが、悪事に加担したのは事実。一方、彼らだって被害者だ」

　人生には成功も、失敗もあるものだ。あすかは罪というマイナス面より、プラスの面を強調する。

「直人さんと亜矢さんには、正義感と勇気が備わっていた。事件の解決に貢献した二人は、 栄 ( は ) えある功労者よ」

　人差し指を振り、明は肯定を示す。

「それそれ。密輸品を発見したもんな」

　あすかは亜矢の真似をして明に抱き付き、もっと大事な功績を追加する。

「もう一つある。こうしてあなたをかばってくれた。命懸けの人命救助で表彰もの」

　今回の事件に三人が活躍した。では四人目の登場人物は無能者か？バッグを投げる振りをして、明が決定的なヒロインを挙げる。

「それと、あすかも亜矢さんの命を救った。おかげでこっちもここにこうして立っていられる」

　それはわかっていることだ。〝まぐれ〟という天の助けにより命中したので、あすかは自慢するには気が引ける。それより質問の答えを知りたいあすかは、明の服を引っぱって急かした。

「いったい何の罰？早く！」

　これをもったいぶっていた明が、晴れやかに答える。

「いろいろ取り調べは受けるだろうが、懲役は免れるってこと」

　これで明の服を離したあすかの顔がほころんだ。

「えっ！ほんと？嬉しい！」

「マインドコントロールされていた彼らは、操り人形になって手伝わされただけだ」

　正常な意識がある人間は罪を犯すと刑が下り、精神病者の犯行は罪を免れられるか、罰が軽減される。二人は一時的な精神病にかけられ、隷属されていただけだ。あすかはこの裁断を喜んだ。

「それも、そうね」

　一つは安心できた。そうなると、もっと身近な人のことも気になる。

「あなたは罪になるの？いくら悪人といえ、他人の家に忍び込んでるもの」

　二人の罪ばかり考慮し、自分のことがなおざりだった明は、一転して苦渋の顔になった。

「罪になる。困ったな。そうかといって、証拠を得るまで警察は逮捕に踏み切れなかったし」

「それで、あの家に行ったの？」

　闇雲に突入したのでは落とし穴に 填 ( は ) まるので、明には周到な計画があったのだ。

「まあね。僕が調べて何かわかった後に、警察とあすかにすぐ電話連絡する、という手段を取ったのさ」

　オウンゴールで相手に点を与えたサッカーの選手が、その後、ハットトリックをすることで前のミスは帳消しになる。明の手柄はこのハットトリックに相当する、と思い、にこにこ顔のあすかは楽観視した。

「きっと大目に見てくれるわよ。何しろ事件解決の立役者だもの」

　そうあって欲しいものだ。それでこそ正義が報われる。では、杓子定規に扱う裁判官がいるとすると･･････万が一の場合を考えた明の顔が、真っ青になった。

「じゃないと、結婚式を棒に振り、刑務所へ行くことになっちゃう。大変だぜ、それ」

　明が仮定を立てたことで、あすかは頭の中で監獄に入っている明を描いてみた。

「囚人服の明って、似合うかな？見てみたい」

　これは他人事ではない。前科一犯という称号は恥辱だ。明はあすかを脅しにかかる。

「結婚式を挙げる前に、あすかは未亡人みたいになるよ」

「やっぱりまずいか」

　と言ってあすかは笑った。

　真っ直ぐな道を北進すると、三の鳥居が近づいた。大きな赤い鳥居をくぐり、先ほど舞が披露された 舞殿 ( まいでん ) の脇を通る。親しみを感じたこの道を、今週何回通ったことであろうか。

　明の手を引っ張ってあすかが口を尖らせた。

「どうして自首させた？無罪ならそこまでしなくていいんじゃない？」

　厳格な顔付きをした明が、立ち止まって説明する。

「悪事に絡んだからにはけじめを付けなきゃあ。これ、二人の意志なんだ」

　自殺するという弱腰な面がある一方で、悪に立ち向かう勇気もある。更に罪を 懺悔 ( ざんげ ) しようとする二人の決意に、あすかは感銘を受けた。

「しっかりしたところがあるあの二人、きっと立ち直れるよね」

「勿論」

「それと、無実なら、わたしたちの結婚式に招待しましょうよ。亜矢さんの出産にはまだ日にちがあるので、来てくれる、と思うけど」

「平服でいいから気軽にってね」

「逆に二人に子供ができた際には、わたしたちが祝ってやりたいな」

　二人を自首させた明には、先ほど舞を見ているときに考えたことがあった。

「警察から解放されたら、僕が二人の両親の所へ行って、これまでの事情を説明してやる。そして、二人の過ちを許して支援するようお願いする。つまり、子供が生まれる前に結婚を認めてやり、亜矢さんを入籍させてやることをね」

　明とあすかは直人と亜矢に高校生時代の馴れ初め、失業、寮での偏見、岩本の家で受けた仕打ちまでの経緯を全て聞いていた。直人と亜矢はたまたま不運に遭遇したことと、純真なことに付け込まれ、勝に利用されただけである。若者の能力は未知であり、これから各種の世界で花開く可能性を秘めている。少しの脱線により発生した汚点を引きずることで、二人の将来に覆いを被せることは避けたい、と明とあすかは思う。

　二人の心の結婚式は舞殿での舞で代替したことで、豪華な結婚式も披露宴も新婚旅行も省いてよい。ただ亜矢さんを直人さんの戸籍に入れ、生まれる子供に正式の両親がいることを示してやりたい。未婚の母の子では非嫡出子扱いされ、子供の将来に傷が付く。そのために明は一肌脱ぐつもりでいる。

　恋敵となった者を援護することにいくらか異論があるあすかは、人情家の明の案に賛同する方に回った。

「さすが明ね。じゃあわたしも同行させて。証人が多いほど、やりやすいでしょう？」

「よし、考えてみよう」

　あすかはここで穴の開いたショルダーバッグを持ち上げた。これも証拠として没収される、と思ったが、警察は槍だけで立証は十分として返してくれた。

「それはそうと、このショルダーバッグ、だめになっちゃった。気に入ってたんだけどな」

　槍に見立てた指を、ショルダーバッグの穴に差し込んで明は諭す。

「これが亜矢さんを救ってくれた。立派な働きに感謝しなきゃあ」

　その働きを認めるとして、派手に穴が開いているバッグでは使い物にならない。

「家に帰って代わりの物を購入するまで、がんばって働いて」

　と言って、あすかはバッグに無理難題を押し付けた。

　あすかはショルダーバッグの中に入っている鎌倉のガイド本を手にし、ぱらぱらと紙面をめくって言った。

「鎌倉に住むので、このガイド本を買ったのよ。これ、見事に突き抜かれた」

　有無を言わさずに明はあすかから本を取り、 団扇 ( うちわ ) に見立てて扇ぐ振りをする。

「薄い本は槍で参ってしまったな」

　更にもう一冊の本を、あすかはおもむろに取り出し、

「槍は義経記の途中まで刺さって止まった。ほらここまで」

　と言って穴の開いたページを指差す。そのページの中程にある挿し絵には、頼朝ら鎌倉武士を前にして舞う黒一色で描かれた静の姿があり、胸のあたりに槍が刺した小さい穴が 空 ( あ ) いていた。それを見て明は閃いた。

「そこ、静の舞の場面だ！静が身代わりになり、亜矢さんを助けたんだ」

　しんみりとしたあすかも絵を見てみた。

「きっとそうね。時代を越えて静が守ってくれた」

　絵の中に住んでいる静に槍の先が達しており、それも、ガイド本とこの本の表紙を貫通してだ。勝の往生際のばか力にあきれるとともに、このバッグが亜矢さんの背中に当たっていなければ、明と亜矢さんは串刺しになっていた、と思い、あすかは身震いした。震えが止まると、あすかは感謝の気持ちを込め、静の絵をそっと撫でて傷を癒すしぐさをする。

　本宮の下に辿り着いた二人は、手を組んで石段に足を乗せた。上に行くにつれて舞殿や鎌倉市街が、少しずつ下になる。六十一段もある石段は元気な二人には軽いもので、すいすいと行って半分の位置に達した。これだけでもずいぶん高い所に立った感じがする。

　左には八幡宮のシンボルである「隠れイチョウ」と呼ばれる大イチョウの木が立っている。その真横に達したあすかは立ち止まり、木の幹に目をやった。樹齢千年と伝承されているだけあり、 皺 ( しわ ) が多い大イチョウは人間の世代交代を三十年とすると、三十三世代も生きている計算になる。ということは、この大イチョウは鎌倉幕府の創設を見ている。確かに町並に見られるイチョウよりはるかに大きく太い。どうしてこのイチョウがこんなに長寿を保てるのか不思議だ。これが神木というものか？

　顔を強張らせたあすかが、歴史を振り返って念を押す。

「ねえ、この大イチョウの陰から頼家の子、 公暁 ( こうぎょう ) が 長刀 ( なぎなた ) を持って現れ、将軍、実朝を殺害したのよね」

「そのとおり。約八百年前のことだけど」

　華麗な儀式や悲惨な事件を見下ろしていた歴史の 語部 ( かたりべ ) である大樹を指差し、あすかは 怯 ( おび ) える。

「いろいろあったので、あそこから誰か出て来る感じがする。長刀か槍を持ってさ」

　この場所で公暁が実朝を殺害したのは事実だ。でも、それは歴史上のことであり、現在の状況は当時と違いがある。それを明が指摘する。

「公暁が出て来たのは実朝が儀式を終え、石段を下りている最中。だから、 上 ( のぼ ) りは安全」

　明の論理はおかしい。石段は進む方向により、上りにも 下 ( くだ ) りにもなる双方向の道だ。 下 ( お ) りるときに転げ落ちる危険性がある、という筋ならわかるが、暗殺する場合は同じ条件となる。あすかがわざと困らせる質問をする。

「上った後は下りるよね。そのときは？」

　明がすまして答えた。

「出て来るけど、長刀や槍なんか持ってない」

　どうせジョークと思うあすかの質問が続く。

「じゃあ何を持って現れるの？」

「弓！」

　一昨日のことを思い出したあすかは、ひどく驚いた。

「弓？･･････流鏑馬の事件を起こしたあの矢が、またここでわたしたちを狙って？」

「 鏑矢 ( かぶらや ) とは別種だけど、あすかだけを狙って矢が･･････」

　明が左手で弓を持ち、右手で 弦 ( つる ) を絞る構えをすると、恐れをなしたあすかは腰を引いた。右手を十分引いたところで明が摘んでいた指をぱっと離し、その指を矢と見なしてあすかの心臓の前に当てるや、明はかわいい恨みを込めて呟く。

「夢の仇討ちだ」

　矢を射られたあすかは、明の夢をとんとご存じない。あすかは胸に触れている明の指を両手で押さえて問う。

「わたしだけを射るの？怖ーい。･･････だーれそれ？」

　明は指を戻し、黙って右手の平を自分の目の高さからゆっくりと胸のあたりまで下げていく。あすかはその意味が理解できず、けげんな顔をした。

「まあ、さんざんからかって。･･････ヒント頂戴！」

「オーケー。このくらいの高さ」

　あすかは少し考えた。身長を示したとすると、明の手の位置より大仏はずっと高いし、紫陽花の木もそれより高い。大人の三分の二の高さということは･･････

「あっ！わかった。小さい人ね？」

　あすかが正解を考えた、と期待する明は、手の平を前に出した。

「イエス、じゃあ言ってごらん」

　と言って催促したものの、明は考え直し、すぐに手を引っ込める。

「いや、一緒に言おう。当たっているかどうか、すぐわかる」

　さては自分と明との相性を確かめるつもりなのか？明を睨んだあすかは胸を張って言い切る。

「いいわよ、自信ある。あなたの性格、もう十分掴んじゃった」

　相手は自信たっぷりのようだ。それならばと、半身に構えて明が号令をかける。

「それは、それは。･･････では、いくぞ。せーの！」

　二人は一緒に唱えた。

「キューピッド」

「キューピッドちゃん」

　後ろに敬称が付いたあすかの方も、実質は同じだ。明は満足げに拍手をした。

「ご正解でした」

　勘は冴えていた。似たもの夫婦にもうなったのか、あすかは明のジョークをよく理解し、先の手も読めるようになった。長年連れ添った妻ならともかく、婚約中の者にとしてはなかなか立派である。しかし、正解をしたあすかに疑問が残った。

「わたしたちもう婚約してる。キューピッドの世話になる必要、まだあるの？」

　岩本らの悪事は、海草の付着した箱を人目に付く所に置いた失態により発覚し、その小さいミスが墓穴を掘った。あすかも今週、大失態を演じている。明がそこを突いてくる。

「ところがどっこい。あすかが東慶寺に駆け込んで縁を切ったので、あすかの愛は振り出しに戻ったんだ」

　明が迷信まがいのことを引き合いに出すとは、どうしたことだろう？これを聞いた途端に、あすかの目が丸くなった。

「そんなばかな！」

　日本の古いしきたりと、西洋のメルヘンを合体させるとは、珍しいことだ。明の理由付けに驚いたあすかの口が、開いたままとなった。

　まじめな顔をして明が、お決まりの解決案を教えてやる。

「もう一度キューピッドに矢を射られると、あすかに愛が戻るよ」

　この粋な解釈に、あすかはようやく納得した。

「そうか、じゃあキューピッドちゃんに射られに、行きましょう！」

　相手が自分のジョークにすっかり乗ってきた、となると、明のからかいがいっそう激しくなる。

「油断するな！キューピッドちゃん、すぐ逃げるぞ」

　冗談を立て続けに乱発した明を、あすかが糾弾する。

「あなた、ちっとも大学の講師に似合わない。大学首になったら、コメディアンか刑事になってはどう？」

　せっかく勉学に励み、大学の講師にまで昇り詰めた。それなのに、ここで首では困る。それも、フィアンセに言われるとなると問題だ。自分の適正を歪曲された明は、あすかを問い詰める。

「それ、僕がこっけいという意味？それとも、 頭脳 ( ずのう ) 明晰 ( めいせき ) だっていう意味？」

　あすかがつんとすまして答えた。

「こっけいは〝ノー〟、頭脳明晰は〝イエス〟よ」

　賞賛してもらい自信が付いた明だが、自信がなさそうにもっとも重要な質問をする。

「嫌いかい？こういうタイプ」

　この質問に対してあすかが声を張り上げた。

「いえ、大好き！この鎌倉一の男が」

　高く評価してくれて嬉しい明は、一転して要求もする。

「たった鎌倉一かい？世界一とまで言わないが」

　鎌倉は人口が約十七万人、そのうち男は約八万人もいる。その中で一番の地位に昇り詰めれば上出来のはずなのに、明の要求はずうずうしい。まてよ、明は事件解決の功労者だ、では褒美も大きい方が良い。明のジョークに 辟易 ( へきえき ) していたあすかは、咳払いをした後に歌舞伎のような見得を切った。

「むー･･････それでは･･････日本一でござりまーす！」

　市がはるかに大きな領域に拡大された。それも、何千倍、もしくは何万倍だ。禄高を上げるのは大学側の役目として、口頭での賛辞はお安い御用だ。あすかのとびっきりの奮発に明は満足した。

　あすかは明のアンバランスが好きだ。明の根はあすかと同じで、意志が堅くてくそまじめである。地道な研究を根気よく続ける大学の講師なら、 剛毅 ( ごうき ) さは当然と言ってしまえばそれまでだが、それ止まりではこちらの肩がこり、一緒にいるとさぞかし堅苦しく感じるだろう。そんな態度を一生続けられたら、伴侶として恐ろしい。

　幸いに、明には独特のユーモアがある。品のあるジョークやからかいを込めたジョークもあるし、下手な駄洒落のこともある。あすかは、今の明はまじめな明か、砕けた明かと迷う。まじめな話をしていると、突如としてユーモアが混入してくる。そのユーモアを解することがあすかは楽しいし、さあ、次はこっちの明だ、と先を読むことにわくわくする。最後まで話を聞くと、予想と逆のこともある。

　そうかといって「歴史上悪が栄えた試しはない」と大学内の講義でぶちながら、外部の講演会で得た所得を申告せずに脱税する二重人格者と明は異なる。明はきちんと納税しているし、社会的な規律を 遵守 ( じゅんしゅ ) している。研究以外の時間、明は人生を 謳歌 ( おうか ) しているのだ。難しい顔の延長や堅苦しい言葉の連射では、あすかも相手も葬式の参列者になる。だから、明るく楽しく振る舞う、それが明の特質だ。

　とびきりの堅物であるあすかは、まじめであるべきときと、砕けてよいときの頭の転換が極めて下手だった。一人で休んでいても、強張った顔になるほど気難し屋である。しかし、最近あすかの性格がだいぶ変化した。最適なトリガーを与えてもらうと緊張が 解 ( ほぐ ) れ、くそまじめな自分を離れられるようになった。そのトリガーを与えてくれるのが明で、明のそばにいることにより考えを転換し、あすかは万年堅物から脱却できる。

　苦虫を噛み潰した明が、あすかを促す。

「白々しいけど、まあいいや。さあ、行こう！」

　立ち止まっていては何事も進展しない。ここは素直にあすかが元気よく言った。

「はーい」

　幹が太く、枝も葉も多いイチョウの木は、大きな日陰を作って暑い日射しから二人を守ってくれる。途中で話し込んだ明とあすかは、肩をぴったり寄せ合って石段を 上 ( のぼ ) り、日陰を抜け出した。すると、再び 梅雨 ( つゆ ) の中休みとなる太陽の日差しが、容赦なく二人の背中に降り注いだ。これは事件の最後を飾るにふさわしい照明だ。

　石段の上に達した二人は、朱塗りが鮮やかな 楼門 ( ろうもん ) の前に立った。その奥に位置する本宮は朱色の太い柱が上部を支えている堂々とした建物で、柱の上の二階部分を横に走る 欄干 ( らんかん ) の色も朱色である。屋根の軒下には八幡宮と書かれた大きな看板が掛けられていて、その〝八〟の字は鳩のシルエットに似ていた。鳩は鎌倉時代に勝利をもたらす鳥として重宝がられたとか。平和の象徴の鳩が 戦 ( いくさ ) の守り神とは、現代の人は想像しがたい。

　二人は神聖なその場所で神妙に手を合わせた。明はあすかの崇高さと美しさを、あすかは一見ひ弱そうに見える明の真の勇気と智恵を誇りに思いつつ、九月に行われる結婚式の無事を祈った。

　今週、何回祈ったであろうか？円覚寺、明月院、銭洗弁天、高徳院、長谷寺、八幡宮とこれだけ多くの寺院や神社で祈った。小額のお賽銭も回数が多いとかなりの額になるので、回数に見合う 御利益 ( ごりやく ) を期待したくなるというものだ。もっともあすかはバッグがまぐれ当たりするという大きな恩恵を受けている。

　お祈りをする一方で、今週は重大事件が身近に勃発し、それを二人は無事解決した。何回も苦難が押し寄せるのが人生、恐れていては負ける。神や仏が味方してくれることを信じ、正義を貫いて乗り切ろう、とも二人は誓った。

　本宮で祈った二人は石段に戻った。さあ問題の 下 ( くだ ) りだ。ぐっと身を引き締めて歩み、中間地点まで到達した。いくらなんでも、ここで二人の愛を襲うような悪夢は、千年もの長い間歴史を刻み続けてきた大イチョウの陰から飛び出て来ないであろう。また、キューピッドの矢が放たれることも、現実の世界ではあり得ない。出て来るものは 長年日の光を浴びて成長した大イチョウ、その若葉によって生まれる香りである。それに誘われ、明とあすかは肩をぴったり寄せ合って石段を下りた。

　　　　　　　　　　　　　　　　　　完
